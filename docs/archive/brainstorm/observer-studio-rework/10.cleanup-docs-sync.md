# Cleanup Report: Runtime-Architecture Docs Sync

## Summary

The runtime-architecture docs (Phase 1) planned Luca Studio as a **separate `packages/luca-studio/` package** using **Bun.serve()** with **vanilla HTML/CSS**, **WebSocket** for state, **raw fs.watch** for file watching, and **Elk.js + SVG** for visualization. The brainstorm (Phase 2) supersedes all web-app decisions: Studio is the **renamed luca-observer** Next.js app using **React + shadcn + Tailwind**, **SSE** (no WebSocket), **chokidar v5** (no raw fs.watch), **TCP localhost sidecar** (not Unix sockets), **CodeMirror 6** (not Monaco), and **React Flow** for DAG editing.

Of the 12 files in `docs/runtime-architecture/`:

- **4 files are still valid** (DAG engine, adapter architecture, mastra evaluation, 3 of 4 decision docs)
- **3 files are partially superseded** (README, roadmap, architectural vision -- their Studio/visualization sections are outdated)
- **1 file is fully superseded** (research/dev-studio.md)
- **1 decision doc has a minor conflict** (backlog-integration-decisions.md Phase D sequencing)

The non-web-app content (DAG engine design, adapter architecture, typed step contracts, eval framework, iteration integration, behavioral equivalence criteria) remains valid and is **not contradicted** by the brainstorm.

### research/dev-studio.md

- **Status**: Fully Superseded
- **What's still valid**: Some individual technology evaluations may retain reference value:
  - The Elk.js evaluation (Section 2) is useful background, though the brainstorm chose React Flow instead
  - The UI design patterns research (Section 4, Evil Martians patterns) informed the brainstorm's UX decisions
  - The state machine visualization analysis (Section 3) is still relevant background
- **What's outdated**: Nearly everything about the recommended architecture:
  - **Server**: Recommends Bun.serve() with vanilla HTML -- brainstorm uses Next.js App Router
  - **Visualization**: Recommends Elk.js + raw SVG -- brainstorm uses React Flow (already in observer)
  - **Real-time**: Recommends SSE + WebSocket -- brainstorm uses SSE only
  - **File watching**: Recommends `fs.watch()` (Bun native) -- brainstorm uses chokidar v5
  - **UI**: Recommends vanilla HTML/CSS with CSS custom properties -- brainstorm uses React + shadcn + Tailwind
  - **Package structure**: Recommends new `packages/luca-studio/` -- brainstorm absorbs into existing observer
  - **Dependencies**: Recommends ~2 production deps (elkjs + xstate) -- brainstorm inherits observer's 77 components and full React ecosystem
  - **CSS approach**: Catppuccin-inspired dark theme via CSS custom properties -- brainstorm uses shadcn theming
- **Conflicts with brainstorm**:
  - "The technology landscape strongly favors a zero-framework approach" directly contradicts the brainstorm's decision that "Observer has 77 components, React Flow, shadcn -- rebuilding in vanilla JS would be regression"
  - "Bun 1.3's fullstack dev server is purpose-built for exactly this use case" -- brainstorm explicitly rejects this in favor of Next.js
  - File watcher section recommends `fs.watch()` -- brainstorm's R4 research found this unreliable on macOS and chose chokidar v5
- **Recommended action**: Add a prominent "SUPERSEDED" notice at the top pointing to the brainstorm docs. Archive but do not delete -- the technology evaluations (Elk.js comparison table, Mermaid analysis, Evil Martians patterns) have reference value for future decisions.
