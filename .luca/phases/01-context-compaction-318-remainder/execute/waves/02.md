  `packages/luca-cli/src/init/helpers/ensure-compact-instructions.ts` — the idempotency
  guard used a bare `content.includes(COMPACT_INSTRUCTIONS_HEADER)` substring test, so a
  deeper heading (`### Compact Instructions Notes`) false-positived and silently skipped
  the append. Replaced with a whole-line match (`content.split('\n').some(line =>

  trimmed-line semantics. Real cases unchanged.
- **FIX 2 (test-quality MEDIUM):** `ensure-compact-instructions.test.ts` —
  (a) added a no-trailing-newline case (`'# My Project'`) asserting the header starts on
  its own line (contains `'# My Project\n'`, not glued) and header count == 1;
  (b) strengthened the without-header case to assert header count == 1 and the blank-line
  separator (`'Some existing content.\n\n## Compact Instructions'`);
  (c) added a FIX-1 proof case: a CLAUDE.md with only `### Compact Instructions Notes`
  gets the block appended (guard does not false-positive; proven via block-unique
  `session:phase-boundary-handoff` content + a line-exact header check, since the deeper
  heading contains the substring).
