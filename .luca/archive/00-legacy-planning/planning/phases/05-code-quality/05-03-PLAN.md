# 05-03: Base Class Consolidation

## Objective
Extract duplicated formatting logic from the three base classes into a shared module.

## Tasks

### Task 1: Extract Shared Formatting Functions
**Current state:** `toCursorFormat()` and `toClaudeFormat()` are copy-pasted across:
- `src/agents/base/base-agent.ts`
- `src/skills/base/base-skill.ts`
- `src/rules/base/base-rule.ts`

**Target:**
- Create `src/shared/format.ts` with:
  - `toCursorFormat(config: { frontmatter: Record<string, unknown>; sections: Section[] }): string`
  - `toClaudeFormat(config: { frontmatter: { name: string; description: string }; sections: Section[] }): string`
- Import and delegate from each base class

### Task 2: Update Base Classes
- Each base class calls the shared formatting functions
- Keep the `toCursorFormat()`/`toClaudeFormat()` methods on the class interface
- Just change the implementation to delegate

### Task 3: Verify
- `bun test` — all compiler and base class tests must pass
- Output format must be identical (no whitespace changes)

## Exit Criteria
- Single source of truth for formatting logic
- All existing tests pass unchanged
- No logic duplication across base classes
