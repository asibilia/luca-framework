Ensure bridge CLI documentation is accurate (15 subcommands, read-ledger included) and add a --help flag for discoverability. The core doc fixes (JSDoc and architecture-overview.md) were already completed in a prior phase; this plan verifies that and adds the --help flag as a DX improvement.

@docs/architecture-overview.md — Bridge CLI section around line 129
@.planning/todos/pending/45-p2-bridge-docs-mismatch.md — original todo with 6 subtasks

### t2: Verify architecture-overview accuracy (verification only)

### t3: Add --help flag to bridge CLI

In the CLI dispatch section of bridge.ts (near the bottom where `process.argv` is parsed):

- Check for `--help`, `-h`, or no subcommand
- Print a formatted help message listing all 15 subcommands with descriptions
- Exit 0

Format:

```
luca-state — CLI bridge for the Luca workflow state machine

Usage: luca-state <subcommand> [options]

Read commands:
  read-status            Read comprehensive workflow status
  read-complexity        Read current complexity level
  read-oversight         Read current oversight level
  read-phase             Read current phase info
  read-field             Read an arbitrary context field (--field=path)
  read-ledger            Read session ledger entries (--tail=N, --session=id)

Write commands:
  set-field              Set a context field (--field=name --value=json)
  transition             Send workflow event (--event=TYPE [--data=json])

Lifecycle commands:
  ensure-init            Initialize state if not present ([--force])
  snapshot               Generate STATE.md from current state
  gate-check             Check if a gate is enabled (--gate=name)
  suspend                Suspend a phase (--phase=N [--reason=str])
  resume-phase           Resume a suspended phase (--phase=N)

Observability commands:
  emit-event             Emit observer event (--type=eventType [--session=id])
  emit-context-snapshot  Emit context snapshot (--session=id [--percent=N])
```

### t4: Improve unknown subcommand error

When an unrecognized subcommand is passed, include the list of valid subcommands in the error message so the user can self-correct.
