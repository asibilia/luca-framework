# Phase 153 Plan 1: PreCompact Checkpoint Hook

## Objective

Create a PreCompact hook that saves a 5-field checkpoint to MuninnDB REST API + filesystem when Claude Code fires the PreCompact event before compaction. This enables context preservation across compaction events.

## Context

@src/hooks/scripts/context-monitor.sh
@src/hooks/scripts/session-persist.sh
@src/hooks/\_\_helpers/hook-registry.ts
@.claude/settings.json
@.planning/phases/153-precompact-checkpoint-hook/153-RESEARCH.md

## Tasks

### 1. Create pre-compact-checkpoint.sh script

**Type:** auto
**TDD:** false
**Depends on:** none

Create `src/hooks/scripts/pre-compact-checkpoint.sh` following existing hook patterns.

The script must:

1. Use standard hook header: `#!/usr/bin/env bash`, `set -euo pipefail`, source `_lib/common.sh`, `guard_dedup "pre-compact-checkpoint" 10`
2. Read stdin JSON and extract `trigger` field (manual vs auto) using `printf '%s' "$INPUT" | bun -e` pattern
3. Read state from bridge (`run_bridge read-phase`, `run_bridge read-status`) with STATE.md fallback
4. Extract recent git activity: `git log --oneline -5`
5. Build 5-field checkpoint JSON using `bun -e` with env vars (NOT shell interpolation):
   - **position**: phase, task, complexity from bridge/STATE.md
   - **current_work**: goal, approach, next step from STATE.md
   - **key_decisions**: last 3 decisions from STATE.md
   - **completed_summary**: recent git log entries
   - **trigger**: manual vs auto from stdin
6. Write filesystem fallback: `Bun.write()` to `.planning/.context-checkpoint.json`
7. Write to MuninnDB REST API: `curl -s -o /dev/null --max-time 5 -X POST "${MUNINN_URL}/api/engrams"` with vault `luca-framework`, concept `session:checkpoint`
8. All operations wrapped in `|| true` — never block compaction
9. No stdout output (PreCompact hooks have no decision control)

**Security patterns:**

- Use `HOOK_VAR="$VAR" bun -e "process.env.HOOK_VAR"` for all JSON construction (SEC-02)
- MuninnDB URL from `${MUNINN_DB_URL:-http://127.0.0.1:8476}`, key from `${MUNINN_DB_API_KEY:-}`

**Files to create:**

- `src/hooks/scripts/pre-compact-checkpoint.sh` (make executable)

**Verification:**

- Script has correct shebang and sources `_lib/common.sh`
- No `jq` usage — only `bun -e`
- No shell variable interpolation in `bun -e` strings
- Script exits 0 always
