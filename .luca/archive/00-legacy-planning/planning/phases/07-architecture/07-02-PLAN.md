### Task 5: Update `build-cursor.ts` to include general skill compilation

**Goal**: Add general skill compilation to `build-cursor.ts` so it produces the same skill coverage as `build-claude.ts` and `build-all.ts`. Currently `build-cursor.ts` only compiles 4 entities (lu-executor agent, lu-planner agent, lu skill, lu-workflow rule) while the other build scripts compile those 4 plus all 37 general skills.

**File:** `scripts/build-cursor.ts`

**Changes:**
1. Add import for `skillRegistry` from `../src/skills/index` (matching `build-all.ts` line 16)
2. Add `import type { BaseSkill } from '../src/skills/types/skill.types';` (matching `build-all.ts` line 17)
3. After the existing lu-skill compilation block (after line 54), add a general skill compilation loop that:
   - Iterates over `Object.entries(skillRegistry)`
   - Instantiates each skill class
   - Compiles to Cursor format using `compiler.compileSkill(skillInstance, 'CURSOR')`
   - Creates the skill directory under `.cursor/skills/{skillName}/`
   - Writes the compiled content to `.cursor/skills/{skillName}/SKILL.md`
   - Logs each generated file
   - Catches and logs errors for individual skill failures (matching `build-all.ts` lines 113-146 pattern)
4. Add a summary log line showing the count of general skills compiled

**Pattern to follow** (from `build-all.ts` lines 109-148, adapted for Cursor-only):
```typescript
// Import at top of file
import { skillRegistry } from '../src/skills/index';
import type { BaseSkill } from '../src/skills/types/skill.types';

// After lu-skill compilation block
console.log('Generating Cursor format for all general skills...');
let skillCount = 0;

for (const [skillName, SkillClass] of Object.entries(skillRegistry)) {
  try {
    const skillInstance = new (SkillClass as new () => BaseSkill)();
    const cursorSkillContent = compiler.compileSkill(skillInstance, 'CURSOR');

    const generalSkillDir = path.join(cursorDir, 'skills', skillName);
    if (!fs.existsSync(generalSkillDir)) {
      fs.mkdirSync(generalSkillDir, { recursive: true });
    }

    const generalSkillOutputPath = path.join(generalSkillDir, 'SKILL.md');
    fs.writeFileSync(generalSkillOutputPath, cursorSkillContent);

    console.log(`Generated .cursor/skills/${skillName}/SKILL.md`);
    skillCount++;
  } catch (error) {
    console.error(`Failed to generate .cursor/skills/${skillName}/SKILL.md:`, error);
  }
}

console.log(`Generated Cursor format for ${skillCount} general skills`);
```
