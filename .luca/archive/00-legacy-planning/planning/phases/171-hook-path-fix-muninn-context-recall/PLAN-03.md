# Phase 171 Plan 3: Add generated-file-guard Rule

## Objective

Create a new rule `generated-file-guard.rule.ts` that prevents AI agents from directly editing generated `.sh` wrapper files in `.claude/hooks/` and `.claude/statusline.sh`. These files are generated by `bun run build:all` from TypeScript sources in `src/hooks/`. Direct edits are silently overwritten on next build and are a recurring source of confusion.

Also register the rule in `deploy-global.ts` UNIVERSAL_RULES so it is available in all projects.

## Context

@src/rules/general/no-tests.rule.ts (example of createRule pattern — follow this structure)
@src/rules/\_\_helpers/create-rule.ts (the createRule factory function)
@scripts/deploy-global.ts (lines 42-54: UNIVERSAL_RULES set — add the new rule here)

## Tasks

### 1. Create generated-file-guard.rule.ts

**Type:** auto
**TDD:** false
**Depends on:** none

Create `src/rules/general/generated-file-guard.rule.ts` following the exact same pattern as `no-tests.rule.ts`.

The rule should:

- Use `createRule` from `~/rules/__helpers/create-rule`
- Import `RuleConfig` type from `~/rules/__schemas/rule.schemas`
- Have `alwaysApply: true` in frontmatter
- Have a clear description: `Prevent direct edits to generated shell wrapper files`
- Explain in the content:
  - `.claude/hooks/*.sh` and `.claude/statusline.sh` are generated by `bun run build:all`
  - The source of truth is TypeScript files in `src/hooks/scripts/`
  - Direct edits to `.sh` files will be overwritten on next build
  - To modify hook behavior: edit `src/hooks/scripts/{hook-name}.ts`, then run `bun run build:all`
  - To modify shell wrapper generation: edit `src/hooks/__helpers/generate-shell-wrappers.ts`
  - NEVER edit files in `.claude/hooks/` or `.claude/statusline.sh` directly

Export as `generatedFileGuardRule`.

**Files to create/edit:**

- `src/rules/general/generated-file-guard.rule.ts` — NEW file

- Uses `createRule` pattern consistent with other rules in `src/rules/general/`
- Exported constant name is `generatedFileGuardRule`
- Content clearly explains the generated file pipeline and what to edit instead
