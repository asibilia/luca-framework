**Changes to the `selective_recall` step:**

Add an early check at the top of the step, before the existing tier gate:

```
**Check eager_recall flag (before tier gate):**

\`\`\`
IF agent.cognition.eager_recall == false (default):
    SKIP selective recall entirely
    Log: "Agent {name} uses deferred recall -- memory loaded on first skill request"
    Note in cognitive report: "Recall: DEFERRED (will be loaded by orchestrator skill on demand)"
    PROCEED directly to initialize_working (skip load_global_memory too)

    Continue with existing recall flow below (unchanged)
\`\`\`
```

Also update the `generate_report` step to include a "Recall: DEFERRED" note in the cognitive report when eager_recall is false, so downstream agents know memory will come from the skill orchestrator.

Additionally, set `eager_recall: true` in lu-cognition's own frontmatter cognition config (lu-cognition itself is always eager).
