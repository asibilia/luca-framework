### 1. Add eager_recall to CognitionConfigSchema

**Type:** auto
**TDD:** false
**Depends on:** none

Add `eager_recall: z.boolean().default(false)` to `CognitionConfigSchema` in `src/agents/__schemas/agent.schemas.ts`. This field controls whether an agent's memory is loaded eagerly during lu-cognition pre-flight (true) or deferred to first skill-level request (false).

### 2. Create recall-cache.ts module

**Type:** auto
**TDD:** false
**Depends on:** none

Create `src/shared/__helpers/recall-cache.ts` -- a new session-scoped recall cache module following the existing `formatCache` pattern in memory-context-builder.ts.

The module exports:

- `RecallCacheEntrySchema` (Zod schema for cached recall results)
- `RecallCacheEntry` type (inferred from schema)
- `getCachedRecall(sessionId: string): RecallCacheEntry | undefined`
- `setCachedRecall(sessionId: string, entry: RecallCacheEntry): void`
- `hasRecallCache(sessionId: string): boolean`
- `clearRecallCache(): void`

The cache is a module-scoped `Map<string, RecallCacheEntry>` keyed by session ID. It stores raw MuninnDB recall results (patterns, decisions, pitfalls, findings as string arrays) plus a `recalledAt` ISO 8601 timestamp.

Follow the research Example 2 for implementation. Use camelCase for internal schema fields (not API-facing). Include JSDoc comments per mandatory-documentation rule.

### 3. Add requestMemoryContext() to memory-context-builder.ts

**Type:** auto
**TDD:** false
**Depends on:** 2

Add `requestMemoryContext()` function and its config interface to `src/shared/__helpers/memory-context-builder.ts`. This function wraps the cache-read + format flow (it does NOT perform MuninnDB recall — the calling skill orchestrates the MCP call and stores results via `setCachedRecall()` before calling this function):

1. Check `getCachedRecall(sessionId)` for cached results
2. If no cache: log warning, return empty string (per CONTEXT.md Decision 3)
3. If cached: call existing `buildMemoryContextBlock()` with cached data, filtered by agent

The function signature from research Example 3:

```typescript
export interface RequestMemoryContextConfig {
  agentName: string;
  sessionId: string;
  memoryTags: string[];
  maxTokens?: number;
}

export function requestMemoryContext(
  config: RequestMemoryContextConfig,
): string;
```

Important: This function does NOT call MuninnDB itself (MCP calls are made by the LLM). It formats cached results. The skill prompt orchestrates the full flow: "recall via MCP if not cached, then format with requestMemoryContext()."
