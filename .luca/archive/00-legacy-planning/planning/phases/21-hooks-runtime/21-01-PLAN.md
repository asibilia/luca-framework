# Plan 21-01: Hook Registry and Build Pipeline Updates

## Objective

Add a `session-start` hook to the hook registry in `src/hooks/index.ts` and introduce `PLUGIN_EXCLUDED_HOOKS` filtering in `scripts/build-plugin.ts` so that the plugin build excludes development-only hooks (specifically `pre-commit-drift-check`) while including the new `session-start` hook. This ensures the plugin hooks.json, script copying, and manifest listing are all consistent.

## Context

@src/hooks/index.ts — Hook registry with `HookDefinition` interface and 6 existing entries (lines 38-101), plus `generateHooksConfig()` (lines 107-145) and `generateCursorHooksConfig()` (lines 157-181).

@scripts/build-plugin.ts — Plugin build script. `COMMAND_EXCLUDED_SKILLS` pattern at lines 74-81 serves as the model for `PLUGIN_EXCLUDED_HOOKS`. Hook script copy loop at lines 411-440. `generatePluginHooksConfig()` call at line 444. Manifest generation at lines 455-468 includes `hookNames` array.

@.planning/phases/21-hooks-runtime/21-RESEARCH.md — Section 7 (Build Pipeline Changes) details the filtering approach. Section 3.3 specifies the `session-start` hook definition.

## Tasks

### Task 1: Add `session-start` to hookRegistry

**Goal:** Register the new SessionStart hook so all build generators (Claude Code, Cursor, Plugin) automatically include it.

**Files:** `src/hooks/index.ts` (modify)

**Steps:**

1. Read `src/hooks/index.ts` and locate the `hookRegistry` object (line 38).
2. After the `session-persist` entry (line 100), add a new `session-start` entry:
   ```typescript
   "session-start": {
     event: "SessionStart",
     cursorEvent: "sessionStart",
     matcher: undefined,
     cursorMatcher: undefined,
     script: "session-start.sh",
     timeout: 15,
     async: false,
     statusMessage: "Initializing Luca...",
   },
   ```
3. Key design choices:
   - `event: "SessionStart"` — PascalCase per Claude Code convention
   - `cursorEvent: "sessionStart"` — camelCase per Cursor convention (forward-compatible even if Cursor does not yet support this event)
   - `matcher: undefined` / `cursorMatcher: undefined` — always fires on session start, no filtering
   - `timeout: 15` — allows up to 15 seconds for directory creation, file checks, and auto-detection (typical: < 5s)
   - `async: false` — must complete before session proceeds so `.planning/` files are available
   - `statusMessage: "Initializing Luca..."` — shown in Claude Code UI during hook execution

**Verification:**

- [ ] `hookRegistry` has 7 entries (6 existing + `session-start`)
- [ ] The `session-start` entry has `event: "SessionStart"` and `script: "session-start.sh"`
- [ ] TypeScript compiles without errors: `bunx --bun tsc --noEmit`

**Files:** `scripts/build-plugin.ts` (modify)

**Steps:**

1. Read `scripts/build-plugin.ts` and locate the `COMMAND_EXCLUDED_SKILLS` constant (line 74-81).
2. After `COMMAND_EXCLUDED_SKILLS` (after line 81), add the `PLUGIN_EXCLUDED_HOOKS` constant:

    * Hooks excluded from plugin builds.

     "pre-commit-drift-check",

### Task 3: Filter hook registry in plugin build pipeline

**Goal:** Apply `PLUGIN_EXCLUDED_HOOKS` filtering so excluded hooks are not copied, not in hooks.json, and not in the manifest.

**Files:** `scripts/build-plugin.ts` (modify)

**Steps:**

1. Locate the `// --- Hook Scripts ---` section (line 407).
2. Before the hook copy loop (line 411), create a filtered registry:
   ```typescript
   // Filter hooks for plugin context (exclude development-only hooks)
   const pluginHookRegistry = Object.fromEntries(
     Object.entries(hookRegistry).filter(
       ([name]) => !PLUGIN_EXCLUDED_HOOKS.has(name),
     ),
   );
   ```
3. Replace `hookRegistry` with `pluginHookRegistry` in the hook copy loop (line 411):
   - Change `for (const [hookName, hookDef] of Object.entries(hookRegistry))` to `for (const [hookName, hookDef] of Object.entries(pluginHookRegistry))`
4. Replace `hookRegistry` with `pluginHookRegistry` in the `generatePluginHooksConfig()` call (line 444):
   - Change `generatePluginHooksConfig(hookRegistry)` to `generatePluginHooksConfig(pluginHookRegistry)`
5. Log excluded hooks for build visibility:
   ```typescript
   if (PLUGIN_EXCLUDED_HOOKS.size > 0) {
     console.log(
       `  Excluded ${PLUGIN_EXCLUDED_HOOKS.size} hook(s): ${[...PLUGIN_EXCLUDED_HOOKS].join(", ")}`,
     );
   }
   ```

**Verification:**

- [ ] Running `bun ./scripts/build-plugin.ts` produces a `dist/plugin/scripts/` directory without `pre-commit-drift-check.sh`
- [ ] Running `bun ./scripts/build-plugin.ts` produces a `dist/plugin/hooks/hooks.json` without any `pre-commit-drift-check.sh` references
