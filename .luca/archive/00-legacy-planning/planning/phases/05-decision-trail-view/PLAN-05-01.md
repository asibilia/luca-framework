## Tasks

### Wave 1: Hook and Loading Fix (parallel, no dependencies)

#### 1. Create useDecisionTrail hook

**Type:** auto
**TDD:** false
**Depends on:** none

Create `packages/luca-observer/hooks/use-decision-trail.ts` following the
`useSessionExplorer` pattern exactly.

**Data fetching:**

- Fetch from `/api/muninn/engrams?type=decision&limit=200`
- Use `fetchingRef` to prevent double-fetch in React strict mode
- Use `Promise.allSettled` with 503 graceful degradation (NotConfiguredError)
- Manual refresh only (no polling)
- Set loading state during fetch

**Parsing logic:**

- Extract decision name from concept suffix (e.g., `decision:use-bun-runtime` becomes `use-bun-runtime`)
- Map engram fields to a `DecisionInfo` interface:
  - `decision_id: string` — concept suffix
  - `name: string` — concept suffix, formatted for display
  - `content: string` — full engram content (the decision rationale)
  - `confidence: number` — engram confidence score
  - `tags: string[]` — engram tags
  - `created_at: number` — epoch timestamp
  - `concept: string` — full concept string
  - `memory_type: string` — should be "decision"
- Sort decisions by `created_at` descending (most recent first)

**Detail fetching:**

- Provide `fetchDecisionDetail(concept: string)` that calls
  `/api/muninn/find-by-entity` POST with `{ entity_name: concept }` to fetch
  related engrams for expansion
- Returns `MuninnEntityEngram[]`

**Exported interface:**

```typescript
export interface DecisionInfo {
  decision_id: string;
  name: string;
  content: string;
  confidence: number;
  tags: string[];
  created_at: number;
  concept: string;
  memory_type: string;
}

export interface DecisionTrailData {
  decisions: DecisionInfo[];
  loading: boolean;
  error: string | null;
  refresh: () => void;
  lastUpdated: Date | null;
  fetchDecisionDetail: (concept: string) => Promise<MuninnEntityEngram[]>;
}
```
