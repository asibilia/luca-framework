# Phase 06 Plan 03: Update Rules, Documentation, and Complexity Gating Rule

## Objective

Update the complexity-gating rule (both the `.claude/rules/complexity-gating.md` generated output and its `src/rules/` source), the `rule-complexity-gating.skill.ts` reference skill, and the complexity-gating documentation to reflect the new always-run + model-routing paradigm. The old skip/run matrix is replaced with a model-routing table.

This plan ensures all developer-facing documentation, rules, and reference material is consistent with the new behavior established in Plan 02.

@src/rules/general/complexity-gating.rule.ts

## Tasks

### 1. Rewrite complexity-gating.rule.ts

**Type:** auto
**TDD:** false
**Depends on:** none

Rewrite `src/rules/general/complexity-gating.rule.ts` to replace the step-skipping matrix with the model-routing paradigm. The rule should:

1. **Keep complexity levels** -- TRIVIAL/SIMPLE/MODERATE/COMPLEX/CRITICAL are still valid for effort estimation, model routing, and iteration count scaling
2. **Replace the skip/run matrix** with a model-routing table showing which model tier each agent category gets at each complexity level
3. **Keep the always-on steps** -- still list them, but note that ALL steps are now always-on
4. **Update the "How to Apply" section** -- instead of "if the step says Skip, skip it", guide agents to resolve model tier from the routing table
5. **Keep override mechanisms** -- flag-based overrides (`--skip-review`, `--skip-uat`) still exist for explicit opt-out

New matrix format (replacing the skip/run matrix):

| Agent Category                           | TRIVIAL | SIMPLE | MODERATE | COMPLEX | CRITICAL |
| ---------------------------------------- | ------- | ------ | -------- | ------- | -------- |
| Classifiers (lu-cognition, lu-learner)   | haiku   | haiku  | haiku    | haiku   | sonnet   |
| Routers (lu-router, lu-router-fast)      | haiku   | haiku  | sonnet   | sonnet  | sonnet   |
| Orchestrators (lu-executor, lu-planner)  | haiku   | sonnet | sonnet   | opus    | opus     |
| Deep analysis (lu-verifier, lu-debugger) | haiku   | sonnet | opus     | opus    | opus     |
| Reviewers (dx-advocate, code-simplifier) | haiku   | sonnet | opus     | opus    | opus     |

Plus keep the non-deprecated scaling fields:

| Parameter                    | TRIVIAL | SIMPLE | MODERATE | COMPLEX | CRITICAL   |
| ---------------------------- | ------- | ------ | -------- | ------- | ---------- |
| Cognitive pre-flight         | Lite    | Lite   | Full     | Full    | Full       |
| Plan verification iterations | 1       | 1      | 1        | 2       | 3          |
| Harness fix iterations       | 1       | 2      | 2        | 2       | 3          |
| Verify fix iterations        | 1       | 1      | 1        | 1       | 2          |
| Verification mode            | Quick   | Quick  | Standard | Full    | Full+Human |

**Files to create/edit:**

- `src/rules/general/complexity-gating.rule.ts`

**Verification:**

- No "skip" values in the rule's matrix content
- Model-routing table is present with correct tier assignments
- Non-deprecated scaling fields are preserved and accurate
- `bunx --bun tsc --noEmit` passes
