# Phase 1 Plan 1: Rename luca-observer to luca-studio

## Objective

Rename the `packages/luca-observer` package to `packages/luca-studio` across the entire active codebase. This must happen first (Wave 1) because all subsequent Studio feature work depends on the new name being in place. A painful rename later with more dependent code is the specific risk this avoids.

## Context

@packages/luca-observer/package.json
@package.json (root workspace references)
@tsconfig.json
@.planning/phases/01-bootstrap-quick-wins/01-CONTEXT.md
@.planning/phases/01-bootstrap-quick-wins/01-PREMORTEM.md

## Tasks

### 1. Pre-rename grep sweep (pre-mortem constraint)

**Type:** auto
**TDD:** false
**Depends on:** none

Run a comprehensive grep sweep to identify ALL "luca-observer" string literals across the codebase. This is a pre-mortem requirement because localStorage keys, string constants, and non-import references are invisible to TypeScript type checking and may survive a bulk find/replace that only targets import paths.

**Command:**

```bash
grep -rn "luca-observer" --include="*.ts" --include="*.tsx" --include="*.json" --include="*.md" --include="*.toml" --include="*.lock" . | grep -v node_modules | grep -v '.planning/milestones/'
```

**Output:** A complete list of files and line numbers containing "luca-observer". This list drives all subsequent tasks. Save the output for reference during verification.

**Key areas to watch:**

- `packages/luca-observer/stores/vault.ts` (localStorage keys)
- `packages/luca-observer/stores/theme.ts` (localStorage keys)
- `packages/luca-observer/app/layout.tsx` (possible string literals)
- `packages/luca-observer/package.json` (package name field)
- Root `package.json` (workspace references)
- `tsconfig.json` / `tsconfig.paths.json` (path aliases)
- `packages/luca-framework/src/emitter/__helpers/emit-functions.ts`
- `packages/luca-framework/src/emitter/__helpers/muninn-http.ts`
- `src/workflow/__helpers/dag-visualizer.ts`

**Verification:**

- Grep output captured and reviewed
- Every hit categorized as: (a) must rename, (b) historical/archived -- skip
