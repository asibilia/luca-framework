## Tasks

### 1. Create use-entity-deep-dive hook

**Type:** auto
**TDD:** false
**Depends on:** none

Create `packages/luca-observer/hooks/use-entity-deep-dive.ts` following the exact pattern from `use-decision-trail.ts`:

**Hook signature:** `useEntityDeepDive(entityName: string): EntityDeepDiveData`

**Return interface (EntityDeepDiveData):**

- `entity: MuninnEntity | null` -- entity aggregate from `/api/muninn/entity/[name]`
- `timeline: MuninnTimelineEntry[]` -- chronological timeline from `/api/muninn/entity/[name]/timeline`
- `coOccurrences: Array<{ entity_name: string; count: number }>` -- filtered from `/api/muninn/entity-clusters`
- `loading: boolean` -- true during fetch
- `error: string | null` -- error message on failure
- `refresh: () => void` -- manual refresh trigger
- `lastUpdated: Date | null` -- timestamp of last successful fetch

**Implementation details:**

1. Use `fetchingRef` guard to prevent double-fetch in React strict mode
2. Use `Promise.allSettled` for 3 parallel fetches:
   - `GET /api/muninn/entity/${encodeURIComponent(entityName)}` -> entity aggregate
   - `GET /api/muninn/entity/${encodeURIComponent(entityName)}/timeline` -> timeline entries
   - `GET /api/muninn/entity-clusters` -> all clusters (filter client-side)
3. Handle `NotConfiguredError` (503 responses) gracefully -- set empty results, not error state
4. Filter entity-clusters response client-side: keep only clusters where `entity_a` or `entity_b` matches `entityName`, then map to `{ entity_name, count }` format where `entity_name` is the OTHER entity in the pair
5. Sort co-occurrences by count descending
6. Re-fetch when `entityName` changes (add to useEffect/useCallback dependency array)
7. Use `"use client"` directive at top of file

**Local fetchJson helper:** Copy the `fetchJson` and `createNotConfiguredError` helpers from use-decision-trail.ts (same pattern).

**Files to create:**

- `packages/luca-observer/hooks/use-entity-deep-dive.ts`

**Verification:**

- File exists and exports `useEntityDeepDive` function and `EntityDeepDiveData` interface
- `bunx --bun tsc --noEmit` passes with no type errors
- Hook follows fetchingRef + Promise.allSettled pattern
- All three API endpoints are called in parallel
- Co-occurrence filtering logic maps MuninnEntityCluster to the expected shape
