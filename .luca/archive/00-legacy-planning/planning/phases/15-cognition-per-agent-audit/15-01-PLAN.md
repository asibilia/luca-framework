## Tasks

### Task 1: Build Current-State Audit Matrix (COGN-01)

**Goal:** Create the full 25-agent audit matrix documenting what cognition features each agent currently uses.

**Files to read:** All 25 agent `.md` files in `.claude/agents/`

For each agent, document:

- Agent name and file path
- BRAIN: YES / NO / INDIRECT
- MEMORY: YES / NO / INDIRECT
- WORKING: YES / NO / INDIRECT
- Pre-flight: YES / NO / RECEIVES / IS_PREFLIGHT
- Learning: YES / NO / IS_EXTRACTOR
- Current tier classification (T0/T1/T2/T3) based on features present
- Line count (as proxy for agent complexity)
- Notes (any nuance, e.g., "has working_memory section but no cognition wiring")

Output the matrix as a Markdown table with 25 rows. Use the research findings from 15-RESEARCH.md as the primary data source, but verify by spot-checking at least 5 agents directly.

### Task 2: Define Ideal-State Cognition Profiles (COGN-02)

**Goal:** For each agent, determine what cognition tier it SHOULD be at, based on its role and impact on output quality.

Use these criteria to assign ideal tiers:

**T3 (Fully-Cognitive) criteria:**

- Participates in full cognitive loop (read + write + learn)
- Manages or orchestrates cognition for other agents
- Agent output directly shapes learning extraction

**T2 (Session-Aware) criteria:**

- Writes code or creates artifacts that benefit from memory recall
- Maintains session state that informs downstream agents
- Agent output quality demonstrably improves with past context

**T1 (Memory-Reader) criteria:**

- Validates or reviews work where past patterns inform quality
- Receives decisions/pitfalls that prevent repeated mistakes
- Read-only memory access with no session tracking needed

**T0 (Stateless) criteria:**

- Pure rule-following with no benefit from historical context
- Short review agents that follow design system rules
- Fresh perspective is preferred over memory-informed perspective
- Deterministic checks that don't benefit from past experience

For each agent, document:

- Recommended tier (T0/T1/T2/T3)
- Promotable-to ceiling (maximum tier under complexity promotion)
- Memory tags (domain tags this agent would filter by)
- Rationale (1-2 sentences explaining why this tier)

### Task 3: Gap Analysis (COGN-02)

**Goal:** Compare current-state (Task 1) vs ideal-state (Task 2) and classify gaps by severity.

Produce three gap categories:

**Critical gaps** (agent impact is high, tier delta >= 2):

- List each agent with current tier, recommended tier, and specific missing cognition features
- Explain the business impact of the gap (e.g., "lu-executor writes all code but has zero memory of past patterns")

**Moderate gaps** (agent impact is medium, tier delta == 1):

- Same format as critical gaps
- Note whether the gap should be addressed now or deferred

**No change needed** (agent is at correct tier):

- List with rationale for keeping current tier

### Task 4: Produce COGNITION-AUDIT.md Report

**Goal:** Synthesize Tasks 1-3 into the comprehensive audit report.
**Output:** `.planning/phases/15-cognition-per-agent-audit/COGNITION-AUDIT.md`

The report must include:

1. **Executive Summary** -- Key findings in 3-5 bullet points
2. **Tier System Definition** -- Full specification of T0/T1/T2/T3 with capabilities matrix (COGN-03)
3. **Current-State Audit Matrix** -- 25-agent table with all cognition features (COGN-01)
4. **Ideal-State Recommendations** -- 25-agent table with recommended tiers and memory tags
5. **Gap Analysis** -- Critical, moderate, and no-change categories (COGN-02)
6. **Distribution Summary** -- How many agents per current tier vs recommended tier
7. **Memory Tag Vocabulary** -- The 14 domain tags with definitions and example matching entries
8. **Tier Promotion Rules** -- How complexity-driven promotion works (with examples)
9. **Implementation Priority** -- Ordered list of agents to update, based on gap severity and impact
