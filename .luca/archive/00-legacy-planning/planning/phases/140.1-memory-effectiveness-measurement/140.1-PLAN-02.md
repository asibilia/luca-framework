### 2. Insert Step 7.1 — Memory Feedback after Verification

**Type:** auto
**TDD:** false
**Depends on:** 1

In `src/skills/general/phase-execute.skill.ts`, insert a new Step 7.1 between the existing Step 7 (lu-verifier) and Step 7.2 (calibration engram). This step:

1. **Reads recalled engrams** from the recall cache (`getCachedRecall(SESSION_ID).recalledEngrams`)
2. **Determines feedback** using the simple heuristic:
   - If verification passed: all recalled engrams are `useful: true`
   - If verification failed: all recalled engrams are `useful: false`
   - (Applied/ignored granularity comes from executor output if available)
3. **Calls `muninn_feedback`** for each recalled engram:

```
### Step 7.1: Memory Feedback

After verification returns, provide feedback on recalled engrams to MuninnDB.
This feeds the SGD-based scoring system that improves future recall quality.

**Skip if:** No engrams were recalled (recalledEngrams is empty) or --skip-memory flag.

Read the recalled engrams from the session cache. For each engram:

VERIFICATION_PASSED = (verifier result is "passed" or "passed_with_notes")

For each engram in recalledEngrams:
  mcp__muninn__muninn_feedback(
    vault: "default",
    engram_id: engram.engramId,
    useful: VERIFICATION_PASSED
  )

Log the feedback summary:
"Memory feedback: {count} engrams marked as useful={VERIFICATION_PASSED}"

Track feedback results for metrics:
FEEDBACK_ENTRIES = [
  { engram_id, concept, useful, phase, verification_passed, feedback_at }
  ...
]
```

4. **Computes memory metrics** after feedback:

```
After feedback, compute memory effectiveness metrics for this phase:

TOTAL_RECALLED = recalledEngrams.length
TOTAL_APPLIED = (from executor applied-engrams output, or TOTAL_RECALLED if verification passed)
RECALL_PRECISION = TOTAL_APPLIED / TOTAL_RECALLED (0 if none recalled)
HIT_RATE = FEEDBACK_ENTRIES.filter(useful).length / TOTAL_RECALLED

Store metrics as MuninnDB engrams:
mcp__muninn__muninn_remember(
  vault: "default",
  concept: "metric:memory-recall-precision-{milestone}-phase-{phase}",
  content: JSON.stringify({
    value: RECALL_PRECISION,
    total_recalled: TOTAL_RECALLED,
    total_applied: TOTAL_APPLIED,
    memory_tokens_injected: MEMORY_TOKENS_INJECTED,
    phase: PHASE,
    milestone: MILESTONE,
    computed_at: new Date().toISOString()
  })
)

mcp__muninn__muninn_remember(
  vault: "default",
  concept: "metric:memory-hit-rate-{milestone}-phase-{phase}",
  content: JSON.stringify({
    value: HIT_RATE,
    useful_count: FEEDBACK_ENTRIES.filter(useful).length,
    total_count: TOTAL_RECALLED,
    phase: PHASE,
    milestone: MILESTONE,
    computed_at: new Date().toISOString()
  })
)
```

This step runs BEFORE the calibration engram (Step 7.2) so feedback data is available for calibration.
