## Backward Compatibility

One-version fallback is implemented at two layers:

1. **lu.skill.ts**: `(c.lu ?? c.autopilot)?.X` -- reads `lu` first, falls back to `autopilot`
2. **State machine initializeContext**: `get(config, "lu") ?? get(config, "autopilot")` -- same fallback
3. **skip_uat field**: `lu?.skip_uat ?? lu?.skip_uat_in_autopilot` -- handles both old and new field names

Users with existing `config.autopilot` will continue to work until they update.
