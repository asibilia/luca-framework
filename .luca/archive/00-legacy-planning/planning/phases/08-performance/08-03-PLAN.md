## Tasks

### Task 1: Fix SIGINT handler accumulation
**Goal**: Prevent duplicate SIGINT handlers from being registered if `setupCleanupHandler()` is called multiple times (e.g., in tests or programmatic reuse).
**File:** `packages/luca-framework/src/utils/files.ts`
**Changes:**
1. Replace `process.on('SIGINT', ...)` with `process.once('SIGINT', ...)` at line 79. This ensures the handler fires at most once and is automatically removed after execution, preventing accumulation.

**Before (lines 78-84):**
```ts
export function setupCleanupHandler() {
  process.on('SIGINT', async () => {
    p.cancel('\nInstallation cancelled.');
    await cleanupFiles();
    process.exit(1);
  });
}
```

**After:**
```ts
export function setupCleanupHandler() {
  process.once('SIGINT', async () => {
    p.cancel('\nInstallation cancelled.');
    await cleanupFiles();
    process.exit(1);
  });
}
```

**Verification:**
- Call `setupCleanupHandler()` twice in a test; verify `process.listenerCount('SIGINT')` does not increase beyond the expected count
- `bun test` passes
- `luca init` still handles Ctrl+C correctly

### Task 2: Reset `createdPaths` at the start of `generateFiles()`
**Goal**: Prevent stale state from a previous call to `generateFiles()` from leaking into subsequent calls within the same process.
**File:** `packages/luca-framework/src/utils/files.ts`
**Changes:**
1. Add `createdPaths.length = 0;` as the first line inside the `generateFiles()` function body, before any file operations begin.

**Before (lines 119-124):**
```ts
export async function generateFiles(options: {
  config: LucaConfig;
  cwd?: string;
}): Promise<{ success: true; data: LucaManifest } | { success: false; error: string }> {
  const { config, cwd = process.cwd() } = options;
  const templatesDir = getTemplatesDir();
```

**After:**
```ts
export async function generateFiles(options: {
  config: LucaConfig;
  cwd?: string;
}): Promise<{ success: true; data: LucaManifest } | { success: false; error: string }> {
  // Reset tracked paths from any previous invocation
  createdPaths.length = 0;

  const { config, cwd = process.cwd() } = options;
  const templatesDir = getTemplatesDir();
```

**Verification:**
- Calling `generateFiles()` twice in succession does not carry over paths from the first invocation
- `bun test` passes
- The success path still clears `createdPaths` at line 217 (no change needed there, the reset at start is defensive)
