# Plan 08-01: Startup Optimization

## Frontmatter
- **ID**: 08-01
- **Title**: Startup Optimization
- **Wave**: 1
- **Depends on**: none

## Objective
Reduce CLI startup time by converting eager top-level imports to lazy dynamic imports. Currently, running any command (including `luca doctor`) loads the entire dependency tree of ALL commands — `init`, `update`, `doctor` — plus the 1.0MB `update-notifier` module. After this plan, only `citty` and the invoked command's dependencies are loaded at startup.

## Context
- `packages/luca-framework/src/index.ts` -- CLI entry point that eagerly imports all 3 commands and `checkForUpdates` (lines 1-5)
- `packages/luca-framework/src/utils/version-check.ts` -- `update-notifier` imported at module level (line 1), `readFileSync` used synchronously (line 33)
- `packages/luca-framework/src/commands/doctor.ts` -- Already uses dynamic imports internally via `executeDoctor()` — model pattern to follow
- `packages/luca-framework/src/commands/init.ts` -- Exports `initCommand` and `runInit` (lines 9, 117)
- `packages/luca-framework/src/commands/update.ts` -- Exports `updateCommand` (line 374)

## Tasks

### Task 1: Convert subcommand imports to lazy loading
**Goal**: Defer loading of command modules until the specific command is invoked, so `luca doctor` does not load `init` or `update` dependency trees.
**File:** `packages/luca-framework/src/index.ts`
**Changes:**
1. Remove static imports of command modules (lines 2-4) and replace `subCommands` with lazy resolver functions.
2. Keep the `runInit` re-export working by using a dynamic re-export pattern.

**Before (lines 1-18):**
```ts
import { defineCommand, runMain as cittyRunMain } from 'citty';
import { initCommand, runInit } from './commands/init';
import { updateCommand } from './commands/update';
import doctorCommand from './commands/doctor';
import { checkForUpdates } from './utils/version-check';

const main = defineCommand({
  meta: {
    name: 'luca',
    version: '0.0.1',
    description: 'Luca - Agentic development framework for Cursor IDE',
  },
  subCommands: {
    init: initCommand,
    update: updateCommand,
    doctor: doctorCommand,
  },
});
```

**After:**
```ts
import { defineCommand, runMain as cittyRunMain } from 'citty';

const main = defineCommand({
  meta: {
    name: 'luca',
    version: '0.0.1',
    description: 'Luca - Agentic development framework for Cursor IDE',
  },
  subCommands: {
    init: () => import('./commands/init').then(m => m.initCommand),
    update: () => import('./commands/update').then(m => m.updateCommand),
    doctor: () => import('./commands/doctor').then(m => m.default),
  },
});
```

**Verification:**
- `bun run packages/luca-framework/src/index.ts` still shows CLI help
- `bun test` passes all existing tests
- Each subcommand (`init`, `update`, `doctor`) still resolves correctly when invoked

### Task 2: Make `checkForUpdates` use dynamic import for `update-notifier`
**Goal**: Defer the 1.0MB `update-notifier` module load until `checkForUpdates()` actually executes, and convert synchronous `readFileSync` to async `readFile`.
**File:** `packages/luca-framework/src/utils/version-check.ts`
**Changes:**
1. Remove top-level `import updateNotifier from 'update-notifier'` (line 1) and `import { readFileSync } from 'fs'` (line 2).
2. Add `import { readFile } from 'fs/promises'` for async file reading.
3. Make the function async and dynamically import `update-notifier` inside the function body.
4. Replace `readFileSync` with `await readFile`.

**Before (lines 1-4, 17, 31-33):**
```ts
import updateNotifier from 'update-notifier';
import { readFileSync } from 'fs';
import { join, dirname } from 'pathe';
import { fileURLToPath } from 'url';

export function checkForUpdates(): void {
  // ...
      try {
        pkg = JSON.parse(readFileSync(pkgPath, 'utf-8'));
        break;
      } catch {
```

**After:**
```ts
import { readFile } from 'fs/promises';
import { join, dirname } from 'pathe';
import { fileURLToPath } from 'url';

export async function checkForUpdates(): Promise<void> {
  try {
    const { default: updateNotifier } = await import('update-notifier');

    const currentDir = dirname(fileURLToPath(import.meta.url));

    const possiblePaths = [
      join(currentDir, '..', '..', 'package.json'),
      join(currentDir, '..', 'package.json'),
    ];

    let pkg: { name: string; version: string } | null = null;

    for (const pkgPath of possiblePaths) {
      try {
        pkg = JSON.parse(await readFile(pkgPath, 'utf-8'));
        break;
      } catch {
        // Try next path
      }
    }

    if (!pkg) {
      return;
    }

    const notifier = updateNotifier({
      pkg,
      updateCheckInterval: 1000 * 60 * 60 * 24,
    });

    notifier.notify({
      message: `Update available: {currentVersion} -> {latestVersion}\nRun: npx luca update`,
      defer: false,
    });
  } catch {
    // Silently ignore version check errors
  }
}
```

**Verification:**
- The function signature changes from `void` to `Promise<void>`, but the caller in `index.ts` already calls it without `await` (fire-and-forget), so no caller changes needed
- `bun test` passes
- No TypeScript errors from `bun run build` in the framework package

### Task 3: Fix `runInit` re-export for lazy loading compatibility
**Goal**: Ensure `runInit` (used by `create-luca` package) still works after removing the static import of `init` from `index.ts`.
**File:** `packages/luca-framework/src/index.ts`
**Changes:**
1. Replace the static re-export `export { runInit }` with a dynamic wrapper function.
2. Also dynamically import `checkForUpdates` to avoid pulling in `version-check.ts` at module level.

**Before (lines 20-26):**
```ts
export const runMain = () => {
  // Non-blocking version check runs in background
  checkForUpdates();
  return cittyRunMain(main);
};

export { runInit };
```

**After:**
```ts
export const runMain = () => {
  // Non-blocking version check runs in background
  import('./utils/version-check').then(m => m.checkForUpdates());
  return cittyRunMain(main);
};

export const runInit = () =>
  import('./commands/init').then(m => m.runInit());
```

**Verification:**
- `runMain()` still triggers version check in background
- `runInit()` still works for `create-luca` consumers
- TypeScript compiles without errors
- `bun test` passes
