# Plan 133-01: Rename SpacetimeDB memory fields from *Json to *Md

## Objective

Rename the 4 memory-related fields in the SpacetimeDB `MemoryFiles` table from `*Json` to `*Md` since they store markdown content, not JSON. This was flagged as issue #65 in the v2.8.0 audit.

Fields to rename:

- `brainJson` -> `brainMd`
- `memoryJson` -> `memoryMd`
- `workingJson` -> `workingMd`
- `proceduresJson` -> `proceduresMd`

## Context

These fields store markdown file contents (BRAIN.md, MEMORY.md, WORKING.md, procedures) but are misleadingly named `*Json`. The rename improves semantic clarity.

Affected files (10 total):

- `packages/luca-spacetime/spacetimedb/src/schema.ts` — table definition
- `packages/luca-spacetime/spacetimedb/src/index.ts` — reducer definitions
