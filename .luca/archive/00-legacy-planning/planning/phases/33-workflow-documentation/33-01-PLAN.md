# Plan 33-01: Mermaid Workflow Diagrams + Documentation Placement

## Objective

Create comprehensive Mermaid diagrams documenting the full Luca workflow, agent orchestration, cognition flow, and complexity gates. Place all diagrams in `docs/diagrams/` so they render on GitHub.

## Tasks

### Task 1: Create docs/diagrams/ directory and workflow overview diagram

**Goal:** Create a full workflow mind map showing the complete Luca lifecycle: project-new → milestone-new → phase-plan → phase-execute → verify → learn → milestone-complete.

**Files:** `docs/diagrams/workflow-overview.md` (create)

### Task 2: Create agent orchestration diagram

**Goal:** Show how skills spawn agents and how agents chain together. Include: autopilot → phase-plan → lu-planner/lu-plan-checker, phase-execute → lu-executor → lu-test-writer/lu-verifier/lu-learner, phase-discuss → lu-discuss-researcher.

**Files:** `docs/diagrams/agent-orchestration.md` (create)

### Task 3: Create cognition flow diagram

**Goal:** Show the two-tier memory system: BRAIN.md (project identity) → MEMORY.md (long-term learning) → WORKING.md (session memory). Include cognitive pre-flight, session tracking, and learning extraction.

**Files:** `docs/diagrams/cognition-flow.md` (create)

### Task 4: Create complexity gates diagram

**Goal:** Show the five complexity levels (TRIVIAL through CRITICAL) and which workflow steps activate at each level. Include: research, discussion, plan verification, harness iterations, code review, UAT, learning capture.

**Files:** `docs/diagrams/complexity-gates.md` (create)

### Task 5: Build and verify

**Goal:** Build all artifacts and verify diagrams exist with valid Mermaid syntax.

## Success Criteria

- [ ] docs/diagrams/ directory exists with 4 diagram files
- [ ] Each diagram contains valid Mermaid syntax (```mermaid blocks)
- [ ] Workflow overview covers the full plan-execute-verify-learn cycle
- [ ] Agent orchestration shows skill-to-agent spawning hierarchy
- [ ] Cognition flow shows BRAIN/MEMORY/WORKING pipeline
- [ ] Complexity gates show 5 levels with step activation matrix
- [ ] Build succeeds
