# Phase 151 Plan 1: Expand Canonical Hook Events from 5 to 18

## Objective

Expand the hook type system to support all 18 Claude Code lifecycle events by adding 13 new entries to the `CANONICAL_EVENTS` enum and updating all six platform event maps across five files. This is a pure type system expansion -- no new hooks are registered, no new scripts are created.

## Context

@src/hooks/**schemas/hook.schemas.ts
@src/hooks/adapters/claude.adapter.ts
@src/hooks/adapters/cursor.adapter.ts
@src/hooks/adapters/pi.adapter.ts
@src/hooks/**helpers/platform-adapters.ts
@.planning/phases/151-update-hook-schemas/151-CONTEXT.md
@.planning/phases/151-update-hook-schemas/151-RESEARCH.md
