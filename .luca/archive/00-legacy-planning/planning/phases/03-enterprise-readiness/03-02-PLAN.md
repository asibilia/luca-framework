    Create security questionnaire template in .planning/ directory for enterprise procurement teams:

    Structure:
    1. Header: "# Luca Framework - Security Questionnaire"
    2. Introduction: "Pre-filled answers to common enterprise security questions"
    3. Question/Answer format:

    Categories to cover:
    - **Data Residency & Privacy**
      Q: Where is data stored? A: 100% local — .planning/ and .cursor/luca/ directories only
      Q: Is data transmitted to vendor servers? A: No — no SaaS component, no telemetry
      Q: What data is collected? A: None — no analytics, no tracking

    - **Access Control**
      Q: How is access to the tool controlled? A: Filesystem permissions — runs as current user
      Q: Does it require elevated privileges? A: No — standard user permissions sufficient
      Q: How are credentials managed? A: Uses existing git/CLI credentials (gh, jira via env vars)

    - **Supply Chain**
      Q: How is the software distributed? A: NPM registry with signed packages
      Q: Are dependencies audited? A: Yes — lock files ensure reproducible builds
      Q: Is there auto-execution on install? A: No — explicit user invocation required

    - **Audit & Compliance**
      Q: Is there an audit trail? A: Yes — Git history tracks all changes
      Q: SOC 2 alignment? A: Aligns with SOC 2 Type II principles for data security
      Q: Penetration testing performed? A: Not formally — open source, community reviewed

    - **Incident Response**
      Q: Security contact? A: security@lucaframework.dev or GitHub Security Advisories
      Q: Response time SLA? A: Best effort — community-driven project
      Q: Vulnerability disclosure policy? A: Coordinated disclosure preferred

    Format as ready-to-copy answers that security teams can paste into their questionnaires.
    Keep answers concise (1-2 sentences each). No fluff.
