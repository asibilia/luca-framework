## Overview

Established the enforcement and verification foundation that all future workflow improvements build on. The build pipeline compiles everything from source (closing the dogfooding gap), hooks provide deterministic quality gates, an automated harness replaces manual verification, and complexity gates scale workflow with task scope.

**Goal:** Make quality enforcement automatic and unavoidable — advisory instructions become deterministic gates.

**Motivation:** v1.0.1 hardened the code; v1.1.0 hardens the workflow. All quality enforcement was advisory (agents remembering to check). This milestone made it automatic.

## Milestone Summary

**Key Accomplishments:**

1. **Registry-driven build pipeline** — All entities compiled from source via typed registries. No hardcoded entity lists. Dogfooding gap closed.
2. **Deterministic quality hooks** — 5 hooks across 2 platforms (Claude Code + Cursor) replace advisory enforcement with automatic gates.
3. **Automated verification harness** — 4-parser pipeline with failure-to-fix loops integrated into phase execution. Structured JSON output for agent consumption.
4. **Complexity-scaled workflow** — 5-level system with 3 behavioral tiers. Core steps always run; optional steps scale with task scope. Agents self-gate via always-apply rule.
5. **123 new tests** — 29 (Phase 10) + 13 (Phase 11) + 65 (Phase 12) + 29 (Phase 13) = 136 net new. Final suite: 579 pass.

**Key Decisions:**

- v1.1.0 as minor version (new workflow features, no breaking changes)
- Sequential phase dependencies (pipeline -> hooks -> harness -> gates)
- 4 todos -> 4 phases for 1:1 traceability
- Hooks on both Claude Code and Cursor (dual-platform)
- Two-layer verification (hooks for fast feedback, harness for comprehensive checks)
- 5-level complexity with 3 behavioral tiers (N > M compression)
- Soft enforcement via self-gating rules (not hard-coded conditionals)

**Issues Resolved:**

- Build output was partially manual; now fully generated from source
- Quality enforcement was advisory; now deterministic via hooks
- Verification was manual agent work; now automated with structured output
- Workflow was one-size-fits-all; now scales with task complexity
