## Tech Debt (Non-Blocking)

1. **Dead Cursor fallback branches** in hook-io.ts — vestigial from pre-Phase 159 multi-platform support. Harmless but dead code.
2. **`_lib/` naming convention** — should be `__helpers/` per domain architecture. Mechanical rename.
3. **Schema-first parsing gaps** in hooks — readStdinJson() bypasses Zod safeParse for most hooks. Should migrate to parseHookInput() per schema-first rule.
4. **Stale SAFE_CLEAN_ROOTS** in build-utils.ts — `.cursor` and `.pi` remain in allowlist but are never targeted.
5. **Hardcoded vault name** in context-check-throttled.ts prompt message — correct for this repo but not dynamically resolved.
6. **Hook file path validation** — 3 hooks need project-dir boundary checks on stdin paths.
