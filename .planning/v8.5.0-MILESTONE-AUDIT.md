### MEDIUM Findings

3. **DRY-003: ABORT_TRANSITION constant duplicated** (code-simplifier)

4. **DRY-004: Orchestrator pattern drift** (code-simplifier)

   - Fix: Standardize via orchestrator template factory

5. **SEC-001: Loose skill name matching** (security-auditor)

6. **SEC-002: JSON.parse without Zod validation in hooks** (security-auditor)

   - Fix: Add Zod safeParse for context file state validation

7. **SEC-003: World-writable /tmp context files** (security-auditor)
   - Context files created without permission restrictions
   - Fix: Set 0o600 permissions or move to $HOME/.luca/

8. **SEC-004: Bridge args unvalidated** (security-auditor)
   - runBridge() spreads arguments without whitelist
   - Fix: Add argument validation/allowlist
