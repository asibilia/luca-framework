## Tech Debt Summary

### DRY Violations (actionable)

1. **onComplete/sendMessage pattern**: Identical ~40-line callback blocks in luca-subagents.ts (x2), luca-teams.ts, luca-purpose-gating.ts. Extract `sendFollowUpMessage()` helper to \_\_helpers/.
2. **COMPLEXITY_TIER vs COMPLEXITY_TIERS**: Duplicate constant; import from \_\_helpers/status.ts.
3. **ctx?.ui?.notify guard**: 21 occurrences across 5 files; extract `notifySafe(ctx, msg, level)` to \_\_helpers/.
4. **Safety pattern-matching**: ~30 lines duplicated between tool handler and event handler; extract `matchesRule()`.
5. **Brain injection**: Identical body in session_start and before_agent_start; extract `injectBrain(ctx)`.

### Security Hardening (recommended)

1. **exec.ts shell injection surface**: Add `shell: false` or command allowlist for untrusted input.
2. **Safety gate default**: Consider changing default gateMode from "warn" to "block" for critical rules.
3. **Path sanitization**: Apply `sanitizeName()` in luca-teams.ts agent path lookups.
4. **Input length limits**: Cap task string, max_iterations, timeout parameters.

### Incomplete Deployment

1. **luca-work-tracking.ts**: Exists in source, has 20 passing unit tests, but not in PI_EXTENSION_FILES. Either deploy it or explicitly document why it's excluded.
