## Code Quality Findings

### HIGH (5 unique findings)

1. **DRY: sections-to-markdown triplicated** — `sectionsToMarkdown()` / `concatenateSections()` / `compileSectionsToBody()` are identical across 3 adapters. Extract to `src/adapters/__helpers/compile-sections.ts`.

2. **DRY: emit stub triplicated** — Identical stub returning `{ filesWritten: 0, filesPaths: [], warnings: [] }` in all 3 adapters. Extract to shared helper.

3. **SECURITY: Path traversal in compatibility-validator** — `readFileContent()` accepts paths from `EmitResult.filesPaths` without project-root boundary check. Add Zod refinement + path validation.

4. **ARCHITECTURE: Deep shared imports** — Cursor, Windsurf, VS Code adapters import `Section` from `~/shared/__helpers/format` bypassing the barrel. Export `Section` from `~/shared` barrel instead.

5. **ARCHITECTURE: Unused BaseAgent import** — windsurf-adapter.ts imports `BaseAgent` but never uses it (compileAgent returns "" unconditionally). Remove.
