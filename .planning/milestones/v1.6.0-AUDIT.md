## 5. Tech Debt Summary

All CRITICAL/HIGH findings are **tech debt**, not functional gaps. The milestone is functionally complete.

### Priority 1: State Machine Duplication (CRITICAL)

`src/state-machine/` retains a full copy (~2000 lines) of the extracted package. While preserved intentionally for backward compatibility during the rewire, all consumers now point to `packages/luca-state/`. The old directory should be reduced to a thin shim or removed entirely.

**Impact:** Divergence risk — any future edits must be applied in two places.
**Recommendation:** Replace `src/state-machine/` with re-exports from `packages/luca-state/` or delete entirely.

### Priority 2: Utility Duplication (CRITICAL)

`cli-utils.ts` is copied 6 times across the codebase. Bridge internal STATE.md regeneration logic is repeated 5 times.

**Impact:** Bug fixes must be applied in multiple places.
**Recommendation:** Consolidate to single shared utility, import from package.

### Priority 3: Class-Based Rule Factories (HIGH)

Rule factories in `src/rules/profiles/` use class-based patterns (`BaseRule`, `createRuleFactory`), which violates the project's no-classes convention.

**Impact:** Convention inconsistency.
**Recommendation:** Refactor to functional factories in a future phase.

### Priority 4: Result Type Duplication (HIGH)

`Result<T>` pattern is defined independently in multiple modules.

**Impact:** Type inconsistency risk.
**Recommendation:** Define once in shared types, import everywhere.
