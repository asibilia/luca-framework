## Critical Learnings

### Bun Runtime Requirement (2026-02-23)

**Mistake Made:** When Copilot suggested "Bun APIs won't work in Node, revert to node:fs", I started reverting Bun APIs instead of fixing the shebang.

**Root Cause:** Pattern-matched on surface problem without questioning assumptions. Accepted external suggestion without checking project conventions.

**Correct Fix:** Change `#!/usr/bin/env node` to `#!/usr/bin/env bun` in bin/luca.js

**Key Principle:** When external feedback says "X won't work in Y runtime", check if the runtime declaration is wrong before changing the code.

### Generated Files — Never Edit Directly (2026-03-03)

**Mistake Made:** Edited `.cursor/hooks/session-start.sh` directly instead of source `src/hooks/scripts/session-start.sh`.

**Root Cause:** `.claude/`, `.cursor/`, `.pi/` are generated from `src/` via `bun run build:all`.

**Correct Approach:** Always edit source in `src/`, then `bun run build:all`.

## Project Patterns

- **Generated output dirs**: `.claude/`, `.cursor/`, `.pi/` — never edit directly, edit `src/` instead
- **Isolated domains**: luca-framework, luca-state, src/ cannot cross-import
- **sanitizeJsonParse**: 3 copies with NOTE comments linking locations
- **VALID_TRACKERS**: Single source of truth in wizard.ts
- **Shared build utilities**: scripts/ directory for DRY extraction

## v2.7.0-Specific Patterns

- **SpacetimeDB dual-write**: Always write to both SpacetimeDB and JSON for backward compatibility
- **Observer hooks use useTable()**: All observer data comes via SpacetimeDB subscriptions, not API routes
- **useFilteredTable factory**: Standard pattern for table filtering/sorting/slicing across 5 hooks
- **readWithFallback**: Generic SpacetimeDB-primary + JSON-fallback pattern for bridge reads
- **safeJsonParse**: Centralized safe JSON parsing utility used by 6 hooks
- **SSRF allowlist**: Localhost-only with hostname normalization for zero-padded IPs
- **CSP dynamic config**: connect-src derived from NEXT_PUBLIC_SPACETIMEDB_URI env var
