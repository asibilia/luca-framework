## Goal

Close convention gaps and tech debt identified by v2.6.1 milestone audit. Two phases: mechanical fixes (barrel imports, convention alignment, security hardening), then DRY pattern extraction.

## Key Accomplishments

1. **Barrel import compliance**: Fixed 5 Rule 4 violations — `complexity/__helpers/` and `complexity/__schemas/` direct imports replaced with `~/complexity` barrel. Removed 39 lines of dual-exported tribunal symbols from `agents/index.ts`.
2. **Convention alignment**: `.sort()` → lodash `orderBy`, `.parse()` → `.safeParse()`, `sanitizeForTemplate()` hardened with complete `${...}` stripping and Unicode bidi control character defense, bare `"crypto"` → `"node:crypto"`.
3. **countResolutions() helper**: Extracted from 3 duplicated filter patterns (upheld/withdrawn/modified) across `tribunal-rebuttals.ts` and `milestone-debate.ts`.
4. **Diagnostic prompt factory**: Deduplicated 3 prompt builders in `verification-tribunal.ts` (~36 lines of template duplication eliminated) into `buildDiagnosticPrompt()` with `DiagnosticPromptConfig`.
5. **safeParseOrThrow() utility**: Extracted from 4-case switch in `metrics-collector.ts`, reducing each case from 7 lines to 1 line.
6. **lodash groupBy migration**: Replaced manual "iterate, get-or-create array in Map, push" idiom in 4 files with `groupBy()`, converting Map return types to Record where needed.
