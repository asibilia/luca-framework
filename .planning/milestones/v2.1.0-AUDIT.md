**Note:** The execSync CRITICAL issues are inherent to the Pi extension design — these tools execute user-specified commands by design (verification loops, harness checks). The risk is mitigated by Pi's own permission model which requires user approval for tool execution. These should be documented as accepted risks with a defense-in-depth approach (input validation + Pi's permission layer).
