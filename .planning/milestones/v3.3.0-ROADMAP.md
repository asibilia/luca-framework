# v3.3.0 — Cognitive Maturity & Observer Depth

**Shipped:** 2026-03-09
**Theme:** Self-tuning agents, learning loops, advanced observer views.
**Stats:** 6 phases, 12 plans, 78 commits, 94 files changed (+11,930/-169)

## Key Accomplishments

1. **Closed the learning loop** — Apply-Measure-Refine cycle with MuninnDB calibration engrams comparing predicted vs actual complexity
2. **Adaptive complexity self-tuning** — Reassessment at 4 execution checkpoints (phase start, wave boundary, harness boundary, learning capture) with automatic promotion signals
3. **Deferred/lazy recall** — Session-scoped recall cache with cache-first pattern, eliminating eager memory loads for faster cognitive pre-flight
4. **Knowledge Graph Explorer** — Force-directed graph visualization (react-force-graph-2d) with semantic zoom (3 levels), cluster supernodes, connection highlighting, time range slider with histogram
5. **Semantic Search + Contradictions** — On-demand search with advanced options + inline explain score breakdown; contradiction view with side-by-side cards, forget functionality, and cross-view navigation
6. **Entity Deep Dive** — Dynamic /entities/[name] route with 4-tab interface (Timeline, Relationships, Engrams, Co-occurrences), entity type badges, and deep entity navigation
