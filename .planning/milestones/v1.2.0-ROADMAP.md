## Overview

Transformed Luca's agent system from static, one-shot execution into an intelligent, self-correcting engine with context-aware scheduling. Audit-first approach: audited current systems (execution, verification, cognition), then built modular architecture, iterative loops, and usage-aware planning.

**Goal:** Make agents smarter — audit, modularize, iterate, plan.

**Motivation:** v1.1.0 built the enforcement foundation (hooks, harness, complexity gates). v1.2.0 makes the agents themselves smarter — they audit their own effectiveness, isolate context, iterate on failures, and plan within usage constraints.

## Milestone Summary

**Key Accomplishments:**

1. **Verification Signal Taxonomy & Goal-Backward Checking** — 38 signals classified T1-T4. Specification anchoring prevents goal drift by re-injecting PLAN.md at verification checkpoints.
2. **4-Tier Cognition System with Selective Memory Recall** — 25-agent audit matrix. Tag-based memory filtering (14 domain tags). YAML frontmatter for runtime config. Complexity-driven tier promotion.
3. **Context-Modular Sub-Agent Architecture** — Context isolation per sub-agent. Writer/reviewer separation. Universal result envelope with fallback-to-raw. Independent context/cognition promotion tracks.
4. **Iterative Agent Loops (Ralph Wiggum)** — External loop control via decision-support utilities. Multi-signal convergence. Checkpoint/rollback via git tags. Budget enforcement. HITL/AFK modes.
5. **Usage-Aware Sprint Planner** — WSJF scoring with LLM-inferred inputs. Big Rock First scheduling. Quality zone awareness. Weekly allocation. Read-only PM agent archetype.
6. **343 new tests** across v1.2.0 modules (planner 174, iteration 75, complexity 29, harness 65). Final suite: 845 pass.

**Key Decisions:**

- Audit-first approach: audit existing systems before building new features
- Sequential phase dependencies (audit -> cognition -> context -> iteration -> planning)
- 4-tier cognition profiling (T0 Stateless through T3 Fully-Cognitive)
- N-to-M compression pattern reused from v1.1.0 (5 levels -> 3 tiers -> 4 cognition tiers)
- Advisory budget enforcement (iteration count proxy, not token counting)
- WSJF with LLM-inferred BV/TC/RR (T3 signal, acceptable for advisory planning)
- Read-only agent archetype via tools whitelist

**Issues Resolved:**

- Verification relied on LLM self-assessment; now anchored to PLAN.md specifications
- Agent cognition was ad-hoc; now profiled and configured via metadata
- Context was shared across all agents; now isolated per sub-agent role
- Execution was one-shot; now iterative with convergence detection and rollback
- Session planning was manual; now automated with WSJF optimization

**Issues Deferred:**

- Procedural memory layer (4th memory type)
- TDD-first verification pattern
- Additional stack templates (Python, Node.js, Next.js)
- Agent marketplace / sharing registry
- Cross-IDE support (VS Code)
- Code review polish items (DX advocate: silent parse failures, getArg dedup)

**Technical Debt Incurred:**

- Pre-existing 83 TypeScript errors (packages/ and test files, not in new modules)
- `effortPointsSchema` accepts any positive int (should be Fibonacci: 1,2,3,5,8)
- Weekly allocation sum not validated to equal 100%
- Overlapping `estimateContextCost` / `getColdStartCost` functions
- Unused `EFFORT_POINTS` constant in types.ts
- Hardcoded complexity level arrays in cost-model.ts
