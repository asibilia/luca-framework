# Milestone v1.3.0: Claude Code Plugin Distribution

**Status:** IN PROGRESS
**Phases:** 19-23
**Requirements:** 25
**Source Todo:** claude-code-plugin-packaging.md

## Overview

Package the Luca framework as a Claude Code plugin for cross-platform distribution. Extends the existing dual-compiler pipeline (Cursor + Claude) with a third target: self-contained plugin package. Distribution via GitHub marketplace.

**Goal:** Install Luca on Claude Code with `/plugin marketplace add` — working in 2 minutes.

**Motivation:** v1.2.0 made agents intelligent. v1.3.0 makes Luca distributable beyond Cursor IDE. The existing compiler infrastructure (`src/` → `.claude/` + `.cursor/`) naturally extends to a plugin compilation target.

## Key Architectural Decisions

| Decision                                       | Rationale                                                                            |
| ---------------------------------------------- | ------------------------------------------------------------------------------------ |
| Third compiler target (not replacing .claude/) | Maintains backward compatibility; supports both direct and plugin workflows          |
| GitHub marketplace over npm                    | npm distribution not yet implemented in Claude Code; GitHub is the reliable path     |
| Rules-as-skills conversion                     | Plugins cannot inject CLAUDE.md or .claude/rules/; skills are auto-invoked by Claude |
| SessionStart for initialization                | No plugin lifecycle hooks available; SessionStart runs every session start           |
| `${CLAUDE_PLUGIN_ROOT}` for all paths          | Plugin files are cached; absolute paths break after installation                     |
| Plugin name: "luca"                            | Short, memorable; namespaces as `luca:skill-name`, `luca:agent-name`                 |

## Key Constraints

1. **No CLAUDE.md injection** — Critical rules converted to skills
2. **No lifecycle hooks** — SessionStart is the only initialization point
3. **Plugin cached on install** — All paths must be self-contained and relative
4. **npm not ready** — GitHub marketplace is primary distribution
5. **Context budget** — Skill descriptions must be concise for lazy loading
