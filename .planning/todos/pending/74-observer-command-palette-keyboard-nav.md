## Context

Power user experience is missing. No keyboard shortcuts, no quick navigation, no search, no export capabilities.

## Task

- Command palette (Cmd+K): quick navigation to any page, search across events/decisions/agents
- Keyboard shortcuts: number keys to switch pages, Esc to close panels, arrow keys in tables
- Global search: search across events, decisions, agents, notes
- Export/share: export dashboard state as PNG or share a permalink
- Fullscreen mode for any chart or panel
- Consider using cmdk library for command palette

## Notes

Priority 9 — power user experience. Makes the tool feel like a professional IDE-grade dashboard.
