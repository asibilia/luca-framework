## Tech Debt

### Security (Priority: HIGH)

1. **No authentication layer** across 14 API routes — POST endpoints accept writes from any network client
2. **Unbounded in-memory event store** — no eviction, DoS surface
3. **SSE connection limits** — no cap, heartbeat, or idle timeout
4. **Symlink path traversal** — resolveProjectDir doesn't resolve symlinks before prefix check
5. **Missing CSP header** in next.config.ts

### DRY (Priority: MEDIUM)

1. **Extract `usePollingFetch<T>` generic hook** — eliminates ~350 lines across 9 hooks
2. **Extract `readJsonSnapshot<T>` helper** — collapses 3 identical functions in file-watcher.ts
3. **DRY resolveProjectDir** — export from file-watcher.ts, remove duplicate in notes/route.ts
4. **Extract API route factory** — 6 routes share identical GET handler structure

### Convention Alignment (Priority: LOW)

1. **Bun.file preference** — file-watcher.ts and notes/route.ts use node:fs/promises
2. **lodash orderBy** — 7 instances of Array.sort/reverse to replace
3. **Tailwind table headers** — 2 tables have inconsistent header styling
4. **Schema-first parsing** — 1 destructuring default, 2 type assertions
