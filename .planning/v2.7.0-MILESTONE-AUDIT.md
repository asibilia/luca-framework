## Security Assessment

**Overall Posture:** Solid — no exploitable vulnerabilities found

**Strengths:**

- Defense-in-depth SQL injection prevention in ledger (validation + escaping + allowlists, 27 test cases)
- SSRF protection with localhost-only allowlist consistently applied
- Migration to SpacetimeDB subscriptions eliminated API route attack surface
- CSP headers configured (blocks eval, prevents clickjacking)
- Fire-and-forget observer pattern prevents error propagation

**Hardening Recommendations:**

1. (MEDIUM) SSRF allowlist missing `0.0.0.0` and numeric IP representations
2. (MEDIUM) Production CSP `connect-src` hardcodes `ws://localhost:3000`
3. (MEDIUM) `unsafe-inline` in style-src
4. (LOW) Error messages reflect raw input; shell injection surface in `luca-observer.js` open command
