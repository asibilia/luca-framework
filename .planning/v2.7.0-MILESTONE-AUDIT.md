## Tech Debt

### Security (Priority: HIGH)

1. **GET endpoints lack auth** — 5 GET routes bypass the auth middleware that protects POST routes. Read-only data exposure risk.
2. **Timing-unsafe API key comparison** — `===` comparison leaks key length via timing analysis. Use `crypto.timingSafeEqual()`.
3. **CSP weakness** — `unsafe-eval` and `unsafe-inline` in Content-Security-Policy negate much of CSP's XSS protection value.

### Convention Alignment (Priority: MEDIUM)

4. **Harness schemas camelCase** — Internal harness schemas use camelCase but are documented as API schemas. Either migrate to snake_case or clarify they are internal-only.
5. **Bare "path" imports** — 2 files use `"path"` instead of `"node:path"`.
6. **statusColors duplication** — Same color map in 2 components.
7. **Format utility duplication** — `formatTimestamp`, `formatChars`/`formatSize` duplicated across components.

### Styling (Priority: LOW)

8. **Dark mode hardcoded** — Layout forces `className="dark"` with no user preference.
9. **event-\* tokens missing dark variants** — Colors render incorrectly in dark mode.
10. **color-mix srgb vs oklab** — 16 instances use perceptually uneven color space.
