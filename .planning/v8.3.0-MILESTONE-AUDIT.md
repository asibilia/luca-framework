### Integration Gap Detail

**DiffPreview not consumed:** The `current_content` field is returned by entity PUT 409 responses, and the `DiffPreview` component is exported from `components/shared/index.ts`, but no save hook or entity page renders it. `use-entity-save.ts` catches 409 and throws a plain string error, discarding `current_content`. The component is built and ready — only the wiring in the save hook is missing.

### HIGH Findings

1. **Host header spoofing on SSE endpoint** — `events/route.ts:74-84`. Host header is attacker-controlled; any client setting `Host: localhost` bypasses the guard. Fix: bind Next.js to 127.0.0.1 at process level. [security-auditor, cross-phase]

2. **Host header spoofing on git publish** — `git/publish/route.ts:63-70`. Same class as above but more dangerous — guarded operation (git commit) is destructive. [security-auditor, cross-phase]

### MEDIUM Findings

1. **DiffPreview integration gap** — Built but not wired to entity save hooks [integration-checker]
2. **Missing localhost guard on compile route** — Three other routes have it, compile does not [code-architect]
3. **STUDIO_PATH_PREFIXES duplicated** — Same array in publish + revert routes [code-architect]
4. **SIDECAR_URL/PORT duplicated** — Magic literal in 3 modules [code-architect]
5. **Commit message injection surface** — Filenames in git status could inject trailer lines [security-auditor]
6. **`.passthrough()` on metadata schema** — Unvalidated keys reach writeEntityFile [security-auditor]
7. **Internal error message disclosure** — Raw error.message forwarded to client in compile proxy [security-auditor]
