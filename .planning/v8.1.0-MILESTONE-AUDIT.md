## Security Findings

| Severity | Count | Key Finding                                                         |
| -------- | ----- | ------------------------------------------------------------------- |
| HIGH     | 1     | Git revert route has no path allowlist                              |
| MEDIUM   | 3     | commit_sha accepts revspecs; ETag leaked in 409; no localhost guard |
| LOW      | 2     | Git log parsing edge case; publish 409 leaks file paths             |

### HIGH: Git Revert Path Allowlist Gap

**File:** `app/api/git/revert/route.ts:22`
The publish route correctly restricts to `STUDIO_PATH_PREFIXES`, but the revert endpoint accepts any file path — including `.env`, API route source, or paths outside Studio-managed directories. **Must fix before shipping.**

### MEDIUM: commit_sha Accepts Revspecs

**File:** `app/api/git/revert/route.ts:23`
Schema validates `min(4)` but not hex-only. Accepts `HEAD~100`, `main`, branch names. Add `z.string().regex(/^[0-9a-f]{4,40}$/i)`.

### MEDIUM: ETag Leaked in 409 Response

**File:** `lib/config-section-handler.ts:181`
The 409 response includes `currentEtag`, allowing any caller to bypass concurrency protection. Remove from response body.

### MEDIUM: No Localhost Guard on Git Write Endpoints

**File:** `app/api/git/*`
Port 3456 is not restricted to loopback. Add hostname restriction or localhost header check.

### CRITICAL: Entity Hook Triplication (DRY)

`use-agent-detail.ts`, `use-skill-detail.ts`, `use-rule-detail.ts` — 345 lines that should be ~135. Same for save hooks (384 lines → ~180) and list hooks (204 lines → ~100). **~530 lines of pure duplication.**
**Fix:** Extract `useEntityDetail`, `useEntitySave`, `useEntityList` generic hooks.

### CRITICAL: node:fs in config-section-handler

**File:** `lib/config-section-handler.ts:27`
Uses `readFile` and `access` from `node:fs/promises` instead of `Bun.file()`.

### HIGH: Schema-First Violations (3 save hooks)

Metadata objects built with manual `(draft.field as string) ?? ''` destructuring defaults instead of Zod schemas. Repeated in agent/skill/rule save hooks.

### HIGH: Dead Undo Destructuring (3 pages)

`canUndo`, `canRedo`, `undo`, `redo` destructured but never used in agents/skills/rules pages.

### HIGH: Hardcoded Colors (5+ components)

Green/amber success/warning colors hardcoded (`text-green-700 dark:text-green-400`) instead of CSS variable tokens. Spans save-bar, settings page, config-history, vault-config, and all 3 tab containers.

### HIGH: Duplicate Cmd+S Handler

`use-pipeline-save.ts` registers its own Cmd+S listener, competing with the centralized `useKeyboardShortcuts` hook.
