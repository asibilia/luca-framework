## Code Quality Findings

### HIGH Severity (2)

**H1. Double SQL escaping in audit-findings.ts** (cross-phase: Phases 122/123)

- **File:** `packages/luca-framework/src/state/__helpers/audit-findings.ts`
- **Lines:** 193, 206, 210, 217, 251, 257, 297
- **Issue:** `validateFilterString()` already calls `escapeSqlString()` internally, but returned values are then escaped again with `.replace(/'/g, "''")`. This double-escapes quotes, potentially breaking query semantics.
- **Fix:** Remove the redundant `.replace(/'/g, "''")` calls. Use `validateFilterString()` return value directly.
- **Found by:** Code Simplifier + Security Auditor (corroborated)

**H2. Duplicate circuit breaker pattern** (cross-phase: Phase 128)

- **File:** `packages/luca-framework/src/state/__helpers/observer-emitter.ts` + `spacetimedb-client.ts`
- **Issue:** Both files implement identical circuit breaker logic with same cooldown (30,000ms), just different variable names (`_emitterLastFailureAt` vs `_lastFailureAt`).
- **Fix:** Extract shared `createCircuitBreaker()` utility to a common module.
- **Found by:** Code Simplifier
