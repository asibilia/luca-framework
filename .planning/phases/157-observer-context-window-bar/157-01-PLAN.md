# Phase 157 Plan 1: Observer Context Window Bar

## Objective

Add a live context window usage bar to the observer header that reads `.planning/.context-metrics.json` (written by Phase 154) and displays zone-colored progress with polling.

## Context

@packages/luca-observer/components/layout/header.tsx
@packages/luca-observer/components/ui/progress.tsx

@packages/luca-observer/app/api/todos/route.ts
@packages/luca-observer/components/memory/context-usage-bar.tsx
@.planning/phases/157-observer-context-window-bar/157-RESEARCH.md

## Tasks

### 1. Create API route for context metrics

**Type:** auto
**TDD:** false
**Depends on:** none

Create `packages/luca-observer/app/api/context-metrics/route.ts`.

Pattern: Copy from `app/api/todos/route.ts` — file-system reader with Zod validation.

**IMPORTANT:** The zone enum must be `["peak", "good", "degrading", "stop"]` — matching what `context-check-throttled.sh` actually writes (NOT "poor").

- Read `.planning/.context-metrics.json` using `readFile` from `node:fs/promises`
- Use `LUCA_PROJECT_DIR` or `WORKSPACE_ROOT` env var for workspace root resolution, fallback to `process.cwd()`
- Validate with Zod safeParse
- Return 404 when file doesn't exist
- Return 502 on invalid format
- No cache headers (real-time data)

### 2. Create polling hook

**Type:** auto
**TDD:** false
**Depends on:** 1

Create `packages/luca-observer/hooks/use-context-metrics.ts`.

Pattern: Copy from `use-todos.ts` — `useCallback` + `useEffect` + `useState` + `setInterval` + `fetchingRef` guard.

- Poll `/api/context-metrics` every 10 seconds
- Return `{ metrics, loading, error, refresh }`
- Use Zod safeParse on response
- Handle 404 (no metrics file) gracefully — set metrics to null, no error
- Use `fetchingRef` guard against StrictMode double-fetch

### 3. Create context-window-bar component

**Type:** auto
**TDD:** false
**Depends on:** 2

Create `packages/luca-observer/components/layout/context-window-bar.tsx`.

Compact inline bar for header. Must be "use client".

- Use `useContextMetrics()` hook
- Show nothing (`null`) when metrics is null (no active session)
- Show a compact inline display:
  - Small brain icon (`lucide-react` Brain, size 3.5)
  - Progress bar (w-20, h-1) with zone-colored fill
  - Percentage text (font-mono text-xs)
  - Zone badge (optional — text-xs with zone name)

Zone colors using CSS custom properties:

- peak: `var(--color-success)` (green)
- good: `var(--color-info)` (blue)
- degrading: `var(--color-warning)` (amber)
- stop: `var(--color-destructive)` (red)

For the Progress indicator color: either extend the Progress component with an `indicatorClassName` prop, or use inline style with a CSS custom property. The simplest approach: use a custom `div` progress bar instead of the Radix Progress to avoid modifying the shared component.

### 4. Integrate into header

**Type:** auto
**TDD:** false

Edit `packages/luca-observer/components/layout/header.tsx`.

Add the `ContextWindowBar` component in the header. Place it between the flex-1 spacer and the vault/theme controls. Add a Separator before the vault dropdown.

Import `ContextWindowBar` from `./context-window-bar`.
