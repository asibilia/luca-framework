# Plan 22-04: Drift Detection Extension for Plugin Output

## Objective

Extend the drift detection system to cover all `dist/plugin/` output files -- agents, skills, commands, hook scripts, hooks.json, plugin.json, marketplace.json, and README.md. This adds plugin output generation to `check-drift.ts`, adds plugin freshness and orphan detection tests to `check-drift.test.ts`, and extends the pre-commit hook staged file pattern to include `dist/plugin/*`. After this plan, any manual edit to `dist/plugin/` is caught by both the pre-commit hook and the test suite. This plan depends on 22-03 because the drift check must generate plugin content the same way `build-all.ts` does, so the consolidated build must exist first.

## Context

@scripts/check-drift.ts -- Current drift detection script (270 lines). `generateToTemp()` function at line 46 builds a `Map<string, string>` of expected file contents for `.claude/` and `.cursor/` outputs (~189 entries). The `main()` function at line 162 compares each entry against the committed file. This plan extends `generateToTemp()` to also generate all `dist/plugin/` entries.

@scripts/check-drift.test.ts -- Drift detection tests (425 lines). Three test suites: "Output Freshness" (lines 132-256), "Registry Completeness" (lines 262-339), "No Orphan Outputs" (lines 345-425). This plan adds a new "Plugin Output Freshness" suite and a new "Plugin No Orphan Outputs" suite.

@src/hooks/scripts/pre-commit-drift-check.sh -- Pre-commit hook (95 lines). Staged file pattern at line 55 checks for `.claude/*`, `.cursor/*`, and `src/*` paths. This plan adds `dist/plugin/*` and `src/compilers/*` to the pattern.

@scripts/build-all.ts -- After Plan 22-03, this is the consolidated build script. It imports shared constants and functions from `scripts/build-shared.ts`.

@scripts/build-shared.ts -- Shared module (created by Plan 22-03) exporting: `COMMAND_EXCLUDED_SKILLS`, `PLUGIN_EXCLUDED_HOOKS`, `SKILL_CATEGORIES`, `AGENT_CATEGORIES`, `generatePluginHooksConfig()`, `generateCommandMarkdown()`, `readVersion()`, `generateReadme()`. Both `build-all.ts` and `check-drift.ts` import from this module to ensure identical output.

@src/compilers/plugin.compiler.ts -- PluginCompiler class used by the build to compile agents/skills for the plugin target.

@src/compilers/plugin.types.ts -- `generatePluginManifest()` function used by the build to create plugin.json.

@.planning/phases/22-distribution/22-RESEARCH.md -- Section 3 covers the drift detection extension in detail. Section 3.2 lists what is currently NOT covered. Section 3.3 provides the extension approach with code examples. Section 6.3 warns about determinism requirements. Section 6.5 discusses orphan detection complexity.
