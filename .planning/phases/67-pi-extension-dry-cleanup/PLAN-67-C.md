# Plan 67-C: Unify Build Config to Single Source of Truth

## Objective

Eliminate the drift risk identified in the architecture audit: `generatePiSettings()` (line 542-566) and `generatePiOutputs()` (line 568-605) in `scripts/build-shared.ts` maintain separate, manually-synchronized lists of Pi extension files. Additionally, the `__helpers/` directory is not copied to `.pi/extensions/`, which means deployed extensions have broken imports. Fix both issues.

## Context

**Current state in `scripts/build-shared.ts`**:

1. **`generatePiSettings()`** (lines 542-566): Returns a settings object with an `extensions` array listing 12 files:

   ```typescript
   extensions: [
     ".pi/extensions/luca-hooks.ts", // generated by build, not from src/
     ".pi/extensions/luca-state.ts",
     ".pi/extensions/luca-memory.ts",
     ".pi/extensions/luca-harness.ts",
     ".pi/extensions/luca-complexity.ts",
     ".pi/extensions/luca-roles.ts",
     ".pi/extensions/luca-teams.ts",
     ".pi/extensions/luca-chain.ts",
     ".pi/extensions/luca-tilldone.ts",
     ".pi/extensions/luca-query-experts.ts",
     ".pi/extensions/luca-safety-rules.ts",
     ".pi/extensions/luca-purpose-gating.ts",
   ];
   ```

2. **`generatePiOutputs()`** (lines 568-605): Copies extension source files from `src/hooks/pi-extensions/` with a separate `extensionFiles` array listing 11 files (excludes `luca-hooks.ts` which is generated differently):

   ```typescript
   const extensionFiles = [
     "luca-state.ts",
     "luca-memory.ts",
     // ... 9 more
   ];
   ```

3. **Missing**: `__helpers/*.ts` files are NOT copied to `.pi/extensions/__helpers/`. After Plans 67-A and 67-B, all 11 extensions import from `./__helpers/`, so the deployed `.pi/` extensions would have broken imports.

**Drift risk**: Adding a new extension requires updating BOTH lists independently. Forgetting either causes silent breakage.

## Task 1: Extract `PI_EXTENSION_FILES` constant

**Goal**: Create a single source of truth for the list of Pi extension source files.

**File**: `scripts/build-shared.ts`

**Changes**:

1. Add a new exported constant near the top of the file (after `PLUGIN_EXCLUDED_HOOKS` on line 51):

   ```typescript
   /**
    * Pi extension source files that are copied from src/hooks/pi-extensions/
    * to .pi/extensions/ during build.
    *
    * This is the SINGLE SOURCE OF TRUTH for which extensions exist.
    * Both generatePiSettings() and generatePiOutputs() derive from this list.
    *
    * NOTE: "luca-hooks.ts" is NOT in this list because it is generated
    * from the hook registry (not copied from source). It is added
    * to settings.json separately by generatePiSettings().
    */
   export const PI_EXTENSION_FILES: readonly string[] = [
     "luca-state.ts",
     "luca-memory.ts",
     "luca-harness.ts",
     "luca-complexity.ts",
     "luca-roles.ts",
     "luca-teams.ts",
     "luca-chain.ts",
     "luca-tilldone.ts",
     "luca-query-experts.ts",
     "luca-safety-rules.ts",
     "luca-purpose-gating.ts",
   ] as const;
   ```

2. **Also export `PI_HELPER_FILES`** for the \_\_helpers directory:

   ```typescript
   /**
    * Pi extension helper files that are copied from
    * src/hooks/pi-extensions/__helpers/ to .pi/extensions/__helpers/.
    *
    * These are shared utilities imported by multiple extensions.
    * Must be copied alongside extensions for imports to resolve.
    */
   export const PI_HELPER_FILES: readonly string[] = [
     "sanitize.ts",
     "response.ts",
     "frontmatter.ts",
     "exec.ts",
     "registry.ts",
   ] as const;
   ```

**Verification**: `bunx --bun tsc --noEmit scripts/build-shared.ts`

## Task 3: Update `generatePiOutputs()` to derive from constant

**Goal**: Replace the hardcoded `extensionFiles` array and add `__helpers/` copying.

**File**: `scripts/build-shared.ts`

**Changes** (in `generatePiOutputs()`, lines 568-605):

Before:

```typescript
async function generatePiOutputs(
  generated: Map<string, string>,
): Promise<void> {
  generated.set(
    ".pi/settings.json",
    JSON.stringify(generatePiSettings(), null, 2) + "\n",
  );

  const extensionsDir = path.join(
    process.cwd(),
    "src",
    "hooks",
    "pi-extensions",
  );
  const extensionFiles = [
    "luca-state.ts",
    "luca-memory.ts",
    // ... 9 more hardcoded entries
  ];

  for (const fileName of extensionFiles) {
    const srcPath = path.join(extensionsDir, fileName);
    const srcFile = Bun.file(srcPath);
    if (await srcFile.exists()) {
      generated.set(`.pi/extensions/${fileName}`, await srcFile.text());
    }
  }
}
```

After:

```typescript
async function generatePiOutputs(
  generated: Map<string, string>,
): Promise<void> {
  generated.set(
    ".pi/settings.json",
    JSON.stringify(generatePiSettings(), null, 2) + "\n",
  );

  const extensionsDir = path.join(
    process.cwd(),
    "src",
    "hooks",
    "pi-extensions",
  );

  // Copy extension source files (derived from PI_EXTENSION_FILES constant)
  for (const fileName of PI_EXTENSION_FILES) {
    const srcPath = path.join(extensionsDir, fileName);
    const srcFile = Bun.file(srcPath);
    if (await srcFile.exists()) {
      generated.set(`.pi/extensions/${fileName}`, await srcFile.text());
    }
  }

  // Copy shared helper files (required for extension imports to resolve)
  const helpersDir = path.join(extensionsDir, "__helpers");
  for (const fileName of PI_HELPER_FILES) {
    const srcPath = path.join(helpersDir, fileName);
    const srcFile = Bun.file(srcPath);
    if (await srcFile.exists()) {
      generated.set(
        `.pi/extensions/__helpers/${fileName}`,
        await srcFile.text(),
      );
    }
  }
}
```

**Verification**:

- `bun run build:all --force` succeeds
- `.pi/extensions/__helpers/sanitize.ts` exists after build
- `.pi/extensions/__helpers/response.ts` exists after build
- All 5 helper files are present in `.pi/extensions/__helpers/`

## Task 6: Verify settings.json determinism

**Goal**: Confirm that the generated `.pi/settings.json` is byte-identical before and after the refactoring.

**Steps**:

1. Before applying changes: `cp .pi/settings.json /tmp/pi-settings-before.json`
2. Apply changes and run `bun run build:all --force`
3. `diff /tmp/pi-settings-before.json .pi/settings.json` -- must be empty (no diff)

**Why this matters**: The `extensions` array order in settings.json determines Pi's extension loading order. The refactored code must produce the same order. The spread operator `...PI_EXTENSION_FILES.map(...)` preserves array order, so as long as `PI_EXTENSION_FILES` matches the original order, this is guaranteed.
