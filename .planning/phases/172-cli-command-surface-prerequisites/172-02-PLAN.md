### 2. Restructure init.ts as global setup orchestrator

**Type:** auto
**TDD:** false
**Depends on:** 1

Transform `packages/luca-framework/src/commands/init.ts` from a per-project wizard into a global setup orchestrator that guides users through first-time Luca installation.

Critical constraints:

- MUST preserve `initCommand` named export (consumed by cli.ts)
- MUST preserve `runInit` named export (consumed by index.ts -> bin/luca.js)
- Export shape must remain: `{ initCommand, runInit }`

Implementation:

- Keep the `defineCommand` structure with meta `{ name: "init", description: "Set up Luca globally and initialize your first project" }`
- Remove old args (quick, config, name, prefix, stack, tracker, harness, preset, no-tour)
- Add new args:
  - `skip-prerequisites`: `{ type: "boolean", description: "Skip prerequisite checks", default: false }`
  - `skip-vault`: `{ type: "boolean", description: "Skip per-project initialization", default: false }`
- New `run()` implementation follows a multi-step orchestration flow:
  1. Show intro with `@clack/prompts` intro message
  2. Call `detectRuntimeContext()` to determine global vs dev mode
  3. Unless `--skip-prerequisites`: call `checkPrerequisites()` from prerequisites.ts
     - If Bun not installed or below minimum: call `promptBunInstall()`, abort if user declines
  4. Call `ensureLucaHome()` to create `~/.luca/` directory structure
  5. Print success message showing what was created
  6. Unless `--skip-vault`: suggest running `luca vault:init` to set up a project
     - If user is in a directory that looks like a project (has package.json), offer to run vault:init now
  7. Show outro with next steps
- Import from utilities created in Wave 1: `detectRuntimeContext`, `checkPrerequisites`, `promptBunInstall`, `ensureLucaHome`
- Import `logger` and `@clack/prompts`
- Keep `runInit` export: `export const runInit = () => runMain(initCommand);`

Key behavior difference from old init:

- Old init: refused to run if `context.hasLuca` was true (per-project check)
- New init: this is a global orchestrator, so hasLuca check does NOT apply here
- The hasLuca guard now lives in vault-init.ts (created in Wave 1)

**Files to edit:**

- `packages/luca-framework/src/commands/init.ts`

**Verification:**

- `initCommand` and `runInit` are still exported with same names
- Old per-project args removed (quick, config, name, etc.)
- New args added (skip-prerequisites, skip-vault)
- Imports resolve to Wave 1 utilities
- `hasLuca` check is NOT present (it moved to vault-init.ts)
- `bunx --bun tsc --noEmit` passes
