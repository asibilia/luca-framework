### 1. Create runtime-context.ts utility

**Type:** auto
**TDD:** false
**Depends on:** none

Create `packages/luca-framework/src/utils/runtime-context.ts` that detects whether Luca is running from a global npm install or from the monorepo in dev mode.

Implementation:

- Use `import.meta.dir` to get the absolute directory of the running script
- If the resolved path contains `packages/luca-framework/` -> dev mode (monorepo)

- Define a Zod schema for the return type (`RuntimeContextSchema`)
- Export `detectRuntimeContext()` function returning `{ mode: 'global' | 'dev', packageDir: string, homeDir: string }`
- Use `homedir()` from `node:os` for home directory
- Add comprehensive JSDoc documentation

### 3. Create prerequisites.ts utility

**Type:** auto
**TDD:** false
**Depends on:** none

Create `packages/luca-framework/src/utils/prerequisites.ts` that checks for required prerequisites (Bun runtime, OS/arch info).

Implementation:

- Define Zod schemas for `BunPrerequisite` and `PlatformInfo` and `PrerequisiteResult`
- Export `checkBunPrerequisite()` function:
  - Check `typeof Bun !== "undefined"` for runtime detection
  - Use `Bun.version` for version string
  - Use `Bun.which("bun")` for binary path
  - Use `semver.gte()` for minimum version check (MIN_BUN_VERSION = "1.0.0")
  - Return `{ installed, version, path, meetsMinimum }`
- Export `checkPlatform()` function:
  - Use `process.platform` for OS ('darwin', 'linux', 'win32')
  - Use `process.arch` for architecture ('arm64', 'x64')
  - Use `homedir()` for home directory
  - Return `{ os, arch, homeDir }`
- Export `checkPrerequisites()` function that combines both checks
- Export `promptBunInstall()` function using @clack/prompts:
  - Show clear install instructions
  - Prompt user to continue or abort
  - Return boolean (user chose to continue)
- Add JSDoc documentation

**Files to create:**

- `packages/luca-framework/src/utils/prerequisites.ts`

**Verification:**

- File exports `checkBunPrerequisite`, `checkPlatform`, `checkPrerequisites`, `promptBunInstall`
- Zod schemas defined for all return types
- Uses `semver` package (already a dependency)
- Uses `@clack/prompts` for interactive prompts (already a dependency)
- `bunx --bun tsc --noEmit` passes
