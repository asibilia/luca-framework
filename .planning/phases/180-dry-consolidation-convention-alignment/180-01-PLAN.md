2. Add the following function after `MUNINNDB_DEFAULT_PORT`:

```typescript
/**
 * Resolve the MuninnDB port from an explicit value, environment variable, or default.
 *
 * Priority: explicit port > MUNINNDB_PORT env var > MUNINNDB_DEFAULT_PORT (8476).
 *
 * @param port - Explicit port override, or undefined to use env/default.
 * @returns Resolved port number.
 */
export function resolveMuninndbPort(port?: number): number {
  return (
    port ??
    (process.env.MUNINNDB_PORT

}

### 2. Extract resolveMonorepoRoot() to runtime-context.ts (DRY-3)

**Type:** auto
**TDD:** false
**Depends on:** none

The walk-up-to-monorepo-root pattern (while loop checking for `packages/luca-framework/`) is duplicated three times across two files. Extract to `runtime-context.ts` which already exports `detectRuntimeContext()`.

**What to do:**

1. Read `packages/luca-framework/src/utils/runtime-context.ts`.
2. Add the following function (ensure `existsSync` from `node:fs`, `dirname` and `join` from `pathe` are imported -- they likely already are):

```typescript
/**
 * Walk up from a starting directory to find the monorepo root.
 *
 * Identifies the monorepo root by checking for the presence of
 * `packages/luca-framework/` in each ancestor directory. Returns
 * the starting directory unchanged if the marker is never found
 * (i.e., reaches filesystem root).
 *
 * @param startDir - Directory to start walking up from.
 * @returns Absolute path to the monorepo root, or startDir if not found.
 */
export function resolveMonorepoRoot(startDir: string): string {
  let dir = startDir;
  while (dir !== "/" && !existsSync(join(dir, "packages/luca-framework"))) {
    dir = dirname(dir);
  }
  return dir;
}
```

### 3. Extract extractErrorMessage() utility (DRY-6)

**Type:** auto
**TDD:** false
**Depends on:** none

The pattern `err instanceof Error ? err.message : "fallback"` appears 10+ times across the codebase. Create a small shared utility. For this phase, only create the utility and update consumers in `muninndb-service.ts` (the most impacted file).

**What to do:**

1. Create new file `packages/luca-framework/src/utils/error-utils.ts`:

````typescript
/**
 * Safely extract an error message from an unknown caught value.
 *
 * Returns the `.message` property if the value is an Error instance,
 * otherwise returns the provided fallback string.
 *
 * @param err - The caught value (unknown type from catch blocks).
 * @param fallback - Message to return if err is not an Error instance.
 * @returns The error message string.
 *
 * @example
 * ```typescript
 * try {
 *   await riskyOperation();
 * } catch (err) {
 *   const msg = extractErrorMessage(err, "Operation failed");
 *   console.error(msg);
 * }
 * ```
 */
export function extractErrorMessage(err: unknown, fallback: string): string {
  return err instanceof Error ? err.message : fallback;
}
````

2. Update `muninndb-service.ts` to use the utility at its 2 call sites (~lines 115-116 and 209-210).
3. Add import: `import { extractErrorMessage } from "./error-utils"`.
4. Run `bunx --bun tsc --noEmit` to verify.
