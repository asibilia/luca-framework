# Plan 130-01: Cross-session procedure replay and adaptive complexity

## Objective

Implement cross-session procedure replay (#12) and adaptive complexity self-tuning (#13). Both build on existing memory infrastructure.

## Context

Existing infrastructure:

- `src/memory/__helpers/procedure-lifecycle.ts` — procedure lifecycle management
- `src/memory/__helpers/procedure-parser.ts` — procedure parsing
- `src/memory/__helpers/procedure-recall.ts` — procedure recall
- `src/memory/__schemas/memory.schemas.ts` — memory schemas including procedures
- `src/complexity/__schemas/complexity.schemas.ts` — complexity levels and gating

## Tasks

### Task 1: Cross-session procedure replay engine (#12)

- Read existing procedure infrastructure in `src/memory/__helpers/procedure-*.ts`
- Add `procedure-replay.ts` to `src/memory/__helpers/` with:
  - `replayProcedure(procedureId: string, context: ReplayContext): ReplayResult` — replays a stored procedure in a new session context
  - `findReplayableProcedures(taskDescription: string): ProcedureMatch[]` — finds procedures from past sessions that match current task
  - `adaptProcedureToContext(procedure: Procedure, newContext: object): AdaptedProcedure` — adjusts procedure steps for new context
- Add `ProcedureReplaySchema` to memory schemas
- Export from `src/memory/index.ts` barrel
- Add tests

### Task 2: Adaptive complexity self-tuning (#13)

- Read `src/complexity/__schemas/complexity.schemas.ts` for current complexity model
- Create `src/complexity/__helpers/self-tuning.ts` with:
  - `assessComplexityAccuracy(predicted: ComplexityLevel, actual: ComplexityMetrics): AccuracyResult` — compares predicted vs actual complexity
  - `tuneComplexityModel(history: AccuracyResult[]): TuningRecommendation` — recommends threshold adjustments based on historical accuracy
  - `ComplexityMetrics` type: actual file count, actual scope, time taken, issues encountered
- Export from `src/complexity/index.ts` barrel
- Add tests
