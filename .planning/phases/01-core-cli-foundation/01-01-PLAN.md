# Monorepo Package Structure

## Context

This is a greenfield setup within an existing Luca development repo. The goal is to create a dual-package monorepo structure where `create-luca` (thin scaffolder) delegates to `luca-framework` (main CLI).

Research has established:
- UnJS ecosystem: citty, consola, unbuild
- Bun workspaces for monorepo management
- `#!/usr/bin/env node` for cross-platform compatibility

## Goal

Create the monorepo foundation with:
- Root workspace configuration
- `create-luca` package skeleton with bin entry
- `luca-framework` package skeleton with bin entry
- unbuild configured for ESM output

After completion: `bun install` works, both bin entries are callable (though they don't do much yet).

## Tasks

### Task 1: Create Root Workspace Configuration

**Goal:** Configure Bun workspaces to manage both packages from root.

**Files:**
- `package.json` (modify existing)

**Steps:**

1. Update root `package.json` to add workspace configuration:
   ```json
   {
     "name": "luca-monorepo",
     "private": true,
     "workspaces": ["packages/*"],
     "scripts": {
       "build": "bun run --filter '*' build",
       "commit": "bunx --bun @alecsibilia/commit"
     },
     "devDependencies": {
       "@alecsibilia/commit": "^1.0.8",
       "@types/bun": "latest",
       "unbuild": "^3.5.0"
     },
     "type": "module"
   }
   ```

2. Create `packages/` directory

**Verification:**
- [ ] `packages/` directory exists
- [ ] Root `package.json` has `workspaces` field

### Task 2: Create create-luca Package

**Goal:** Set up the thin scaffolder package that users invoke with `npx create-luca`.

**Files:**
- `packages/create-luca/package.json`
- `packages/create-luca/bin/create-luca.js`
- `packages/create-luca/src/index.ts`

**Steps:**

1. Create `packages/create-luca/package.json`:
   ```json
   {
     "name": "create-luca",
     "version": "0.0.1",
     "description": "Create a new Luca project",
     "type": "module",
     "bin": {
       "create-luca": "./bin/create-luca.js"
     },
     "files": ["bin", "dist"],
     "exports": {
       ".": {
         "import": "./dist/index.mjs",
         "require": "./dist/index.cjs"
       }
     },
     "scripts": {
       "build": "unbuild"
     },
     "dependencies": {
       "luca-framework": "workspace:*"
     },
     "keywords": ["luca", "cli", "scaffolding", "cursor", "ai"]
   }
   ```

2. Create `packages/create-luca/bin/create-luca.js`:
   ```javascript
   #!/usr/bin/env node
   import { runInit } from 'luca-framework';
   runInit();
   ```

3. Create `packages/create-luca/src/index.ts`:
   ```typescript
   // Re-export for programmatic usage
   export { runInit } from 'luca-framework';
   ```

4. Create `packages/create-luca/build.config.ts`:
   ```typescript
   import { defineBuildConfig } from 'unbuild';

   export default defineBuildConfig({
     entries: ['src/index'],
     clean: true,
     declaration: true,
     rollup: {
       emitCJS: true,
     },
   });
   ```

**Verification:**
- [ ] `packages/create-luca/package.json` exists with correct bin field
- [ ] `packages/create-luca/bin/create-luca.js` has shebang line
- [ ] `packages/create-luca/src/index.ts` exports runInit

### Task 3: Create luca-framework Package

**Goal:** Set up the main CLI package with command structure foundation.

**Files:**
- `packages/luca-framework/package.json`
- `packages/luca-framework/bin/luca.js`
- `packages/luca-framework/src/index.ts`
- `packages/luca-framework/build.config.ts`

**Steps:**

1. Create `packages/luca-framework/package.json`:
   ```json
   {
     "name": "luca-framework",
     "version": "0.0.1",
     "description": "Luca - Agentic development framework for Cursor IDE",
     "type": "module",
     "bin": {
       "luca": "./bin/luca.js"
     },
     "files": ["bin", "dist", "templates"],
     "exports": {
       ".": {
         "import": "./dist/index.mjs",
         "require": "./dist/index.cjs"
       },
       "./commands/*": {
         "import": "./dist/commands/*.mjs"
       }
     },
     "scripts": {
       "build": "unbuild"
     },
     "dependencies": {
       "citty": "^0.2.1",
       "consola": "^3.4.0",
       "@clack/prompts": "^0.10.0",
       "pathe": "^2.0.3",
       "defu": "^6.1.4",
       "pkg-types": "^2.1.0",
       "fs-extra": "^11.3.0"
     },
     "devDependencies": {
       "@types/fs-extra": "^11.0.4"
     },
     "keywords": ["luca", "cli", "ai", "cursor", "agent", "framework"]
   }
   ```

2. Create `packages/luca-framework/bin/luca.js`:
   ```javascript
   #!/usr/bin/env node
   import { runMain } from '../dist/index.mjs';
   runMain();
   ```

3. Create `packages/luca-framework/src/index.ts`:
   ```typescript
   import { defineCommand, runMain as cittyRunMain } from 'citty';
   import consola from 'consola';

   // Placeholder init command - will be expanded in Plan 02
   const initCommand = defineCommand({
     meta: {
       name: 'init',
       description: 'Initialize a new Luca project',
     },
     run() {
       consola.info('Init command - to be implemented');
     },
   });

   const main = defineCommand({
     meta: {
       name: 'luca',
       version: '0.0.1',
       description: 'Luca - Agentic development framework for Cursor IDE',
     },
     subCommands: {
       init: initCommand,
     },
   });

   export const runMain = () => cittyRunMain(main);
   export const runInit = () => cittyRunMain(initCommand);
   ```

4. Create `packages/luca-framework/build.config.ts`:
   ```typescript
   import { defineBuildConfig } from 'unbuild';

   export default defineBuildConfig({
     entries: ['src/index'],
     clean: true,
     declaration: true,
     rollup: {
       emitCJS: true,
       inlineDependencies: true,
     },
     externals: ['citty', 'consola', '@clack/prompts', 'pathe', 'defu', 'pkg-types', 'fs-extra'],
   });
   ```

5. Create `packages/luca-framework/src/commands/` directory (empty for now)

**Verification:**
- [ ] `packages/luca-framework/package.json` exists with dependencies
- [ ] `packages/luca-framework/bin/luca.js` has shebang line
- [ ] `packages/luca-framework/src/index.ts` exports runMain and runInit
- [ ] `packages/luca-framework/build.config.ts` configures unbuild

## Notes

- Using `workspace:*` for internal dependency (create-luca → luca-framework)
- unbuild configured to externalize dependencies (smaller bundle, faster installs)
- Shebang uses `#!/usr/bin/env node` for maximum compatibility (works with Node, Bun)
- The init command is a placeholder — full implementation comes in Plan 04
