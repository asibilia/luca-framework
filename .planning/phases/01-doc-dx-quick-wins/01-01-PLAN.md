# Document observability domain in rule source files and fix domain count

## Goal

Close documentation drift for the `src/observability/` domain. The architecture-overview.md already documents observability correctly (directory tree, tier table, Section 5), but two rule source files under `src/rules/general/` omit it from their T1 Core tier listings. Additionally, the domain count on line 50 of architecture-overview.md says "14 domains" when there are actually 13 directories under `src/`.

## Context

@docs/architecture-overview.md — already lists observability at line 60 and in tier table at line 87
@src/rules/general/module-boundary.rule.ts — line 22 omits observability from T1 Core
@src/rules/general/domain-architecture.rule.ts — line ~92 omits observability from T1 Core tier table

## Tasks

### t1: Update module-boundary rule source

Edit `src/rules/general/module-boundary.rule.ts` line 22:

- **Before**: `T1 Core: context, planner, harness, iteration, memory (import T0 only)`
- **After**: `T1 Core: context, planner, harness, iteration, memory, observability (import T0 only)`

### t2: Update domain-architecture rule source

Edit `src/rules/general/domain-architecture.rule.ts` line ~92:

- **Before**: `| T1 Core | context, planner, harness, iteration, memory | Import T0 only |`
- **After**: `| T1 Core | context, planner, harness, iteration, memory, observability | Import T0 only |`

Also add observability to the Archetype B Core Domains table in the same file if it is listed there.

### t3: Fix domain count in architecture-overview.md

Edit `docs/architecture-overview.md` line 50:

- **Before**: `Domain source (14 domains across 4 tiers)`
- **After**: `Domain source (13 domains across 4 tiers)`

### t4: Rebuild generated output

Run `bun run build:all` to regenerate `.claude/rules/` and `.cursor/rules/` from the updated source.

## Verification

1. `grep -c 'observability' .claude/rules/module-boundary.md` returns >= 1
2. `grep -c 'observability' .claude/rules/domain-architecture.md` returns >= 1
3. `grep '13 domains' docs/architecture-overview.md` matches
4. `bunx --bun tsc --noEmit` passes
5. `bun run check:drift` passes
