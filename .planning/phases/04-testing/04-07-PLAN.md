### Task 1: Schema Validation Sweep -- Agent Files
**Goal**: Dynamically discover and validate all agent definition files.
**Files**: Create `__tests__/src/schema-validation.test.ts`
**Details**:

This test file discovers all `.agent.ts` files in `src/agents/`, dynamically imports each one, finds the exported class, instantiates it, and asserts that no `ZodError` is thrown during construction.

```typescript
import { describe, test, expect } from 'bun:test';
import { readdirSync } from 'fs';
import { join } from 'path';

const AGENTS_DIR = join(import.meta.dir, '../../src/agents');
const SKILLS_DIR = join(import.meta.dir, '../../src/skills');
const RULES_DIR = join(import.meta.dir, '../../src/rules');
```

**Pattern for agent discovery:**

```typescript
function discoverFiles(baseDir: string, pattern: RegExp): string[] {
  const results: string[] = [];
  function walk(dir: string) {
    const entries = readdirSync(dir, { withFileTypes: true });
    for (const entry of entries) {
      const fullPath = join(dir, entry.name);
      if (entry.isDirectory() && entry.name !== 'base' && entry.name !== 'types') {
        walk(fullPath);
      } else if (entry.isFile() && pattern.test(entry.name)) {
        results.push(fullPath);
      }
    }
  }
  walk(baseDir);
  return results;
}
```

**Agent test block:**

```typescript
describe('Agent schema validation', () => {
  const agentFiles = discoverFiles(AGENTS_DIR, /\.agent\.ts$/);

  // Verify we found a reasonable number of files
  test('discovers agent files', () => {
    expect(agentFiles.length).toBeGreaterThanOrEqual(20);
  });

  for (const filePath of agentFiles) {
    const fileName = filePath.split('/').pop()!;
    test(`${fileName} passes schema validation`, async () => {
      const module = await import(filePath);
      // Find the exported class (first export that is a constructor function)
      const ExportedClass = Object.values(module).find(
        (exp) => typeof exp === 'function' && exp.prototype
      ) as new () => unknown;

      expect(ExportedClass).toBeDefined();

      // Instantiation triggers Zod validation in the constructor
      const instance = new ExportedClass();
      expect(instance).toBeDefined();

      // Verify basic properties
      if ('name' in (instance as any)) {
        expect(typeof (instance as any).name).toBe('string');
        expect((instance as any).name.length).toBeGreaterThan(0);
      }
      if ('description' in (instance as any)) {
        expect(typeof (instance as any).description).toBe('string');
        expect((instance as any).description.length).toBeGreaterThan(0);
      }
    });
  }
});
```

### Task 2: Build Script Smoke Tests
**Goal**: Verify that each of the 9 build scripts executes without throwing uncaught errors.
**Files**: Create `__tests__/scripts/build-smoke.test.ts`
**Details**:

There are two approaches for smoke testing build scripts:

**Approach A (Subprocess -- preferred):** Run each script as a subprocess with `Bun.spawn`. This is the most realistic test -- it validates the full execution path.

**Approach B (Import-only fallback):** If subprocess approach is too slow or flaky, simply dynamically import each script and verify the import does not throw. This catches broken import chains and class instantiation errors.

Use Approach A for the primary scripts and Approach B as fallback:

```typescript
import { describe, test, expect } from 'bun:test';
import { join } from 'path';

const SCRIPTS_DIR = join(import.meta.dir, '../../scripts');

const buildScripts = [
  'build-cursor.ts',
  'build-claude.ts',
  'build-all.ts',
];

const compileScripts = [
  'compile-to-cursor.ts',
  'compile-all-to-cursor.ts',
];

const generateScripts = [
  'generate-agents-from-cursor.ts',
  'generate-skills-from-cursor.ts',
  'generate-rules-from-cursor.ts',
];

const utilScripts = [
  'prepare-compilation.ts',
];
```

**Subprocess smoke test pattern:**

```typescript
async function runScript(scriptName: string): Promise<{ exitCode: number; stderr: string }> {
  const proc = Bun.spawn(['bun', 'run', join(SCRIPTS_DIR, scriptName)], {
    cwd: join(import.meta.dir, '../..'),
    stdout: 'pipe',
    stderr: 'pipe',
    env: {
      ...process.env,
      // Ensure scripts don't accidentally modify real project
      NODE_ENV: 'test',
    },
  });

  const stderr = await new Response(proc.stderr).text();
  const exitCode = await proc.exited;

  return { exitCode, stderr };
}
```

**Test cases:**

For each script category, create a `describe` block:

```typescript
describe('Build scripts', () => {
  for (const script of buildScripts) {
    test(`${script} runs without error`, async () => {
      const { exitCode, stderr } = await runScript(script);
      // Exit code 0 means success
      // Some scripts may write to stderr for logging -- that's OK
      expect(exitCode).toBe(0);
    }, { timeout: 30000 }); // Build scripts may take a few seconds
  }
});
```

3. **build-all.ts exits with code 0**
4. **compile-to-cursor.ts exits with code 0**
5. **compile-all-to-cursor.ts exits with code 0**
6. **prepare-compilation.ts exits with code 0**
7. **generate-agents-from-cursor.ts exits with code 0**
8. **generate-skills-from-cursor.ts exits with code 0**
9. **generate-rules-from-cursor.ts exits with code 0**

**Important notes:**
- Build scripts write files to `dist/`, `.cursor/`, and `src/` directories. Since we are running from the actual project root, these writes will happen for real. If this is undesirable, the test should be skipped in CI or run in a temp copy of the project.
- Set a generous timeout (30 seconds) since some scripts process many files.
- If any script fails, capture stderr in the test failure message for debugging.
- The generate-from-cursor scripts read from `.cursor/agents/*.md` etc. -- if these files don't exist (they're gitignored or not built), those scripts may fail. If so, note the dependency and mark those tests as skippable.

**Alternative (simpler) if subprocess is too fragile:**

Instead of running scripts as subprocesses, verify that each script's imports resolve and its main logic can be loaded:

```typescript
describe('Build scripts (import check)', () => {
  test('build-cursor.ts can be imported', async () => {
    // This verifies all transitive imports resolve
    await expect(import('../../scripts/build-cursor.ts')).resolves.toBeDefined();
  });
});
```

This is weaker but still catches broken import chains, which is the most common failure mode.

**Verification**: `bun test __tests__/scripts/build-smoke.test.ts` -- all 9 scripts pass smoke test.
