# Plan 04-02: Adapter Tests

## Frontmatter
- **ID**: 04-02
- **Title**: Adapter Tests (GitHub, Jira, Placeholder, Factory, Contract)
- **Wave**: 2
- **Depends on**: 04-01

## Objective

Write comprehensive unit tests for all three work tracker adapters (GitHub, Jira, Placeholder), the adapter factory, and a shared contract test suite. Adapters are the I/O boundary where most bugs live -- they handle external CLI tools, REST APIs, error parsing, and type mapping. These tests mock external dependencies (`execa`, `fetch`) and validate every documented edge case.

## Context

- `packages/luca-framework/src/adapters/github-adapter.ts` -- `createGitHubAdapter()`, internal helpers: `inferTypeFromLabels`, `inferPriorityFromLabels`, `parseGhError`
- `packages/luca-framework/src/adapters/jira-adapter.ts` -- `createJiraAdapter()`, internal helpers: `mapJiraType`, `mapJiraPriority`, `extractAdfText`, `checkConfig`, `buildAuthHeader`
- `packages/luca-framework/src/adapters/placeholder-adapter.ts` -- `createPlaceholderAdapter()` (pure logic, no mocking needed)
- `packages/luca-framework/src/adapters/index.ts` -- `createWorkTrackerAdapter()` factory
- `packages/luca-framework/src/contracts/work-tracker.ts` -- `WorkTrackerContract` interface, `AdapterResult<T>`, `WorkTicket`, `WorkTicketType`, `WorkTicketPriority`
- `__tests__/utils/mock-execa.ts` -- shared execa mock factory (from 04-01)
- `__tests__/utils/mock-fetch.ts` -- shared fetch mock factory (from 04-01)
- `__tests__/utils/fixtures.ts` -- `validGitHubIssueResponse`, `validGitHubIssueResponseMinimal`, `validJiraIssueResponse`, `validJiraIssueResponseMinimal` (from 04-01)

## Tasks

### Task 1: GitHub Adapter Tests
**Goal**: Test all `createGitHubAdapter()` methods and edge cases using mocked `execa`.
**Files**: Create `__tests__/packages/luca-framework/src/adapters/github-adapter.test.ts`
**Details**:

Since `mock.module()` must be called BEFORE the module under test is imported, use this pattern:

```typescript
import { describe, test, expect, beforeEach, mock } from 'bun:test';
import { createExecaMock, installExecaMock } from '../../../../utils/mock-execa';
import { validGitHubIssueResponse, validGitHubIssueResponseMinimal } from '../../../../utils/fixtures';
```

For each test case, install the mock then dynamically import the module:

```typescript
// Example pattern:
installExecaMock(createExecaMock({ stdout: JSON.stringify(validGitHubIssueResponse) }));
const { createGitHubAdapter } = await import('../../../../../../packages/luca-framework/src/adapters/github-adapter');
```

**Test cases for `getTicket()`:**

1. **Success with `#` prefix**: Call `getTicket('#42')` with mock returning `validGitHubIssueResponse`. Assert:
   - `result.success === true`
   - `result.data.id === '#42'`
   - `result.data.title === 'Fix the login bug'`
   - `result.data.type === 'bug'` (from `bug` label)
   - `result.data.priority === 'high'` (from `high` label)
   - `result.data.assignee === 'octocat'`
   - execa called with `['gh', ['issue', 'view', '42', '--json', ...]]` (# stripped)

2. **Success without `#` prefix**: Call `getTicket('42')` -- same assertions, verify `42` passed directly.

3. **Success with minimal response**: Use `validGitHubIssueResponseMinimal` (no labels, no assignees, null body).
   - `result.data.type === 'task'` (default when no labels match)
   - `result.data.priority === 'medium'` (default)
   - `result.data.assignee === undefined`
   - `result.data.description === ''` (null body mapped to empty string)

4. **Label mapping -- enhancement**: Mock response with `labels: [{ name: 'enhancement' }]`. Assert `type === 'story'`.

5. **Label mapping -- feature**: Mock response with `labels: [{ name: 'feature' }]`. Assert `type === 'story'`.

6. **Label mapping -- epic**: Mock response with `labels: [{ name: 'epic' }]`. Assert `type === 'epic'`.

7. **Priority mapping -- critical**: Mock with `labels: [{ name: 'critical' }]`. Assert `priority === 'highest'`.

8. **Priority mapping -- urgent**: Mock with `labels: [{ name: 'urgent' }]`. Assert `priority === 'highest'`.

9. **Priority mapping -- priority label**: Mock with `labels: [{ name: 'priority' }]`. Assert `priority === 'high'`.

10. **Priority mapping -- low**: Mock with `labels: [{ name: 'low' }]`. Assert `priority === 'low'`.

11. **gh CLI not installed**: Mock execa to throw `Error` with message containing `ENOENT`. Assert:
    - `result.success === false`
    - `result.error` contains `'not installed'`

12. **Not authenticated**: Mock execa to throw error containing `not logged in`. Assert error contains `'not authenticated'`.

13. **Issue not found**: Mock execa to throw error containing `not found`. Assert error contains `'not found'`.

14. **Unknown error**: Mock execa to throw `Error('something broke')`. Assert error contains `'GitHub CLI error'`.

**Test cases for `createBranch()`:**

15. **Primary success via `gh issue develop`**: First execa call succeeds. Assert `result.data === 'feature/my-branch'`.

16. **Fallback to `git checkout -b`**: First call (gh issue develop) throws, second call (git checkout) succeeds. Use `callConfigs` array in mock. Assert success.

17. **Both methods fail**: Both calls throw. Assert `result.success === false`, error contains `'Failed to create branch'`.

**Test cases for `linkPR()`:**

18. **Always returns success**: Call `linkPR('#42', 'https://...')`. Assert `result.success === true` and `result.data === undefined`.

**Test cases for `validate()`:**

19. **Authenticated**: Mock stdout containing `'Logged in to github.com'`. Assert `result.success === true`.

20. **Active account variant**: Mock stdout containing `'active account: true'`. Assert success.

21. **Not authenticated (stdout does not contain logged in)**: Mock stdout `'not logged in'`. Execa does not throw but stdout doesn't match. Assert `result.success === false`.

22. **gh not installed (ENOENT)**: Mock throws ENOENT. Assert error contains `'not installed'`.

23. **Other error**: Mock throws generic error. Assert error contains `'validation failed'`.

**Test cases for `name` property:**

24. **Adapter name**: Assert `adapter.name === 'github'`.

**Verification**: `bun test __tests__/packages/luca-framework/src/adapters/github-adapter.test.ts` -- all tests pass.

### Task 2: Jira Adapter Tests
**Goal**: Test all `createJiraAdapter()` methods including config resolution, fetch mocking, ADF extraction, and error handling.
**Files**: Create `__tests__/packages/luca-framework/src/adapters/jira-adapter.test.ts`
**Details**:

Use the shared fetch mock factory. Since Jira adapter reads config from params OR `process.env`, tests need to either pass config explicitly or set environment variables.

```typescript
import { describe, test, expect, beforeEach, afterEach } from 'bun:test';
import { createFetchMock, installFetchMock } from '../../../../utils/mock-fetch';
import { validJiraIssueResponse, validJiraIssueResponseMinimal } from '../../../../utils/fixtures';
```

Import the module directly (no mock.module needed since we mock globalThis.fetch):

```typescript
import { createJiraAdapter } from '../../../../../../packages/luca-framework/src/adapters/jira-adapter';
```

Use explicit config params to avoid needing process.env manipulation for most tests:

```typescript
const validConfig = {
  baseUrl: 'https://test.atlassian.net',
  userEmail: 'test@example.com',
  apiToken: 'test-token-123',
};
```

**Test cases for `getTicket()`:**

1. **Missing config (no baseUrl)**: Create adapter with `{}` and clear env vars. Assert `result.success === false`, error contains `'Missing: JIRA_BASE_URL'`.

2. **Missing config (partial)**: Config with only `baseUrl`. Assert error mentions missing `JIRA_USER_EMAIL` and `JIRA_API_TOKEN`.

3. **Config from explicit params**: Adapter with `validConfig`. Verify fetch called with `https://test.atlassian.net/rest/api/3/issue/PROJ-123...`.

4. **Config from process.env fallback**: Create adapter with `{}`, set `process.env.JIRA_BASE_URL`, `JIRA_USER_EMAIL`, `JIRA_API_TOKEN`. Verify it uses env values. Clean up env vars in `afterEach`.

5. **Auth header construction**: Verify fetch called with `Authorization: Basic <base64(email:token)>`.

6. **Success with full response**: Mock 200 with `validJiraIssueResponse`. Assert:
   - `result.data.id === 'PROJ-123'`
   - `result.data.title === 'Implement dark mode'`
   - `result.data.description` contains `'dark mode for accessibility'` (extracted from ADF)
   - `result.data.type === 'story'` (from `mapJiraType('Story')`)
   - `result.data.priority === 'high'` (from `mapJiraPriority('High')`)
   - `result.data.status === 'In Progress'`
   - `result.data.assignee === 'Jane Doe'`
   - `result.data.url === 'https://test.atlassian.net/browse/PROJ-123'`

7. **Success with minimal response**: Mock 200 with `validJiraIssueResponseMinimal`. Assert:
   - `result.data.type === 'task'` (undefined issuetype defaults to task)
   - `result.data.priority === 'medium'` (undefined priority defaults to medium)
   - `result.data.status === 'Unknown'` (undefined status)
   - `result.data.assignee === undefined`
   - `result.data.description === ''` (null description)

8. **ADF extraction with nested content**: Mock response with multi-paragraph ADF body. Verify text is extracted and joined.

9. **ADF extraction with null**: Already covered by minimal response.

10. **ADF extraction with non-object**: Mock description as string `'plain text'`. Verify `extractAdfText` returns `''`.

11. **401 response**: Mock fetch returning status 401. Assert error contains `'authentication failed'`.

12. **404 response**: Mock fetch returning 404. Assert error contains `'not found'`.

13. **Other HTTP error (500)**: Mock fetch returning 500. Assert error contains `'Jira API error: 500'`.

14. **Network error (fetch throws)**: Mock fetch to throw `Error('ECONNREFUSED')`. Assert error contains `'request failed'`.

**Type mapping test cases (tested via getTicket responses):**

15. **mapJiraType: Bug -> bug**
16. **mapJiraType: Task -> task**
17. **mapJiraType: Epic -> epic**
18. **mapJiraType: Sub-task -> subtask**
19. **mapJiraType: unknown -> task** (default)
20. **mapJiraPriority: Highest -> highest**
21. **mapJiraPriority: Medium -> medium**
22. **mapJiraPriority: Lowest -> lowest**
23. **mapJiraPriority: unknown -> medium** (default)

**Test cases for `validate()`:**

24. **Missing config**: Assert `result.success === false`.
25. **401 response**: Assert error contains `'authentication failed'`.
26. **Non-ok response**: Mock 500. Assert error contains `'validation failed'`.
27. **Network error**: Mock throw. Assert error contains `'connection failed'`.
28. **Success (200)**: Assert `result.success === true`, `result.data === true`.

**Test cases for adapter properties:**

29. **Adapter name**: Assert `adapter.name === 'jira'`.
30. **No createBranch method**: Assert `adapter.createBranch === undefined`.
31. **No linkPR method**: Assert `adapter.linkPR === undefined`.

**Verification**: `bun test __tests__/packages/luca-framework/src/adapters/jira-adapter.test.ts` -- all tests pass.

### Task 5: Contract Test Suite
**Goal**: Create a parameterized test suite that validates every adapter implements `WorkTrackerContract` uniformly.
**Files**: Create `__tests__/packages/luca-framework/src/adapters/work-tracker-contract.test.ts`
**Details**:

This test validates structural compliance, not behavior (which is covered in individual adapter tests).

```typescript
import { describe, test, expect } from 'bun:test';
import { createPlaceholderAdapter } from '../../../../../../packages/luca-framework/src/adapters/placeholder-adapter';
import { createGitHubAdapter } from '../../../../../../packages/luca-framework/src/adapters/github-adapter';
import { createJiraAdapter } from '../../../../../../packages/luca-framework/src/adapters/jira-adapter';
import type { WorkTrackerContract } from '../../../../../../packages/luca-framework/src/contracts/work-tracker';
```

**Parameterized tests for each adapter:**

Create an array of adapter configs and loop:

```typescript
const adapters: Array<{ name: string; factory: () => WorkTrackerContract; expectedName: string }> = [
  { name: 'Placeholder', factory: () => createPlaceholderAdapter(), expectedName: 'none' },
  { name: 'GitHub', factory: () => createGitHubAdapter(), expectedName: 'github' },
  { name: 'Jira', factory: () => createJiraAdapter({ baseUrl: 'https://test.atlassian.net', userEmail: 'test@test.com', apiToken: 'token' }), expectedName: 'jira' },
];
```

For each adapter:

1. **Has `name` property**: Assert `typeof adapter.name === 'string'`.
2. **Name matches expected**: Assert `adapter.name === expectedName`.
3. **Has `getTicket` method**: Assert `typeof adapter.getTicket === 'function'`.
4. **`getTicket` returns Promise**: Call `getTicket('TEST-1')`. Assert result is a Promise (for Placeholder this resolves immediately; for GitHub/Jira it will fail due to no mock, but the Promise is still returned).
5. **AdapterResult shape on success (Placeholder only)**: Call Placeholder's `getTicket('TEST-1')`. Assert result has either `{ success: true, data: ... }` or `{ success: false, error: ... }`.
6. **Optional methods are undefined or functions**: Assert `adapter.createBranch === undefined || typeof adapter.createBranch === 'function'`.
7. **validate is undefined or function**: Assert `adapter.validate === undefined || typeof adapter.validate === 'function'`.

**Verification**: `bun test __tests__/packages/luca-framework/src/adapters/work-tracker-contract.test.ts` -- all tests pass.
