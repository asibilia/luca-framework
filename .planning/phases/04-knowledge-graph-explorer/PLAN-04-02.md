# Phase 4 Plan 2: Graph Canvas, Node Rendering, and Sidebar

## Objective

Build the visual heart of the Knowledge Graph Explorer: the ForceGraph2D canvas component with custom node rendering (cluster supernodes and individual nodes), the detail sidebar panel, the cluster legend, and wire everything into the page. After this plan, the user can see the graph, click nodes to open the sidebar, double-click clusters to expand them, and hover for tooltips.

## Tasks

### 1. Create GraphCanvas component

**Type:** auto
**TDD:** false
**Depends on:** none (uses types from Plan 1)

Create `packages/luca-observer/components/knowledge-graph/graph-canvas.tsx` — the core ForceGraph2D wrapper.

**CRITICAL:** Must use `next/dynamic` with `{ ssr: false }` to avoid Canvas SSR crash (Pitfall 1).

**Implementation:**

- Dynamic import: `const ForceGraph2D = dynamic(() => import("react-force-graph-2d").then(mod => mod.default), { ssr: false })`
- Accept props: `graphData`, `width`, `height`, `onNodeClick`, `onNodeDoubleClick`, `onNodeHover`, `selectedNodeId`, `hoveredNodeId`
- Use `useRef<ForceGraphMethods>()` for imperative graph access
- Configure ForceGraph2D:
  - `nodeCanvasObject` — custom Canvas 2D rendering (see Task 2)
  - `nodeCanvasObjectMode={() => "replace"}` — fully custom node drawing
  - `enableNodeDrag={true}`, `enableZoomInteraction={true}`
  - `autoPauseRedraw={true}` — stop Canvas redraw when simulation settles (Pitfall 2)
  - `cooldownTicks={100}` — limit simulation iterations
  - `backgroundColor="transparent"` — let CSS theme handle background
  - `linkColor={() => "rgba(255,255,255,0.15)"}` — subtle link lines
  - `linkWidth={(link) => Math.max(0.5, Math.min(3, link.weight / 2))}` — weight-based link thickness
  - `onNodeClick` — single click handler
  - `onNodeHover` — hover handler
- Handle double-click via separate event listener on the Canvas element (ForceGraph2D does not have a built-in double-click prop). Use a click timer pattern: if second click within 300ms of first on same node, call `onNodeDoubleClick` instead of `onNodeClick`.
- Use `useCallback` for all handler props to prevent re-renders
- Expose a `zoomToFit()` method via `useImperativeHandle` or provide a `resetZoom` callback prop

**Verification:**

### 2. Implement nodeCanvasObject rendering

**Type:** auto
**TDD:** false
**Depends on:** 1

Implement the custom node rendering function inside `graph-canvas.tsx`. This is the visual identity of the graph.

**Cluster supernode rendering (is_cluster=true):**

- Larger circle: radius = `Math.sqrt(child_count) * 4` (scales with member count)
- Fill: type color at 0.4 alpha (semi-transparent fill)
- Stroke: type color at full opacity, 1.5px width
- Count badge: white text centered in circle, font size adapts to globalScale
- At zoom < 0.5: show only circle + count (no label)
- At zoom 0.5-1.5: show circle + count + type label below
- At zoom > 1.5: show circle + count + type label + "click to expand" hint

**Individual node rendering (is_cluster=false):**

- Small circle: radius = 4px (constant)
- Fill: type color at full opacity
- Selected state: add 2px white ring around node
- Hovered state: add 1px dashed ring + slight scale-up
- At zoom < 0.5: dot only (no label)
- At zoom 0.5-1.5: dot + truncated name (max 20 chars)
- At zoom > 1.5: dot + full name + engram count badge

**Recency highlighting:**

- Nodes with `last_seen` within last 24 hours: add pulsing glow effect using `ctx.shadowColor` and `ctx.shadowBlur`
- The glow uses the node's type color

**Implementation:**

- Define the rendering function with `useCallback([], [selectedNodeId, hoveredNodeId])` dependencies
- Use `TYPE_COLORS` from `graph-types.ts` for consistent coloring
- Use `globalScale` parameter for semantic zoom level detection

**Files to edit:**

- `packages/luca-observer/components/knowledge-graph/graph-canvas.tsx`

**Verification:**

- Cluster nodes render as large circles with count badges
- Individual nodes render as small colored dots
- Zoom level changes visible detail (semantic zoom with 3 levels)
- Selected/hovered nodes have visual distinction

### 6. Wire components into the page

**Type:** auto
**TDD:** false
**Depends on:** 1, 2, 3, 4, 5

Update `app/knowledge-graph/page.tsx` to replace the placeholder with real components.

**Page layout:**

```
PageContainer
  div.flex.h-[calc(100vh-12rem)]
    div.flex-1.relative              ← graph area
      GraphCanvas                    ← full size, fills container
      ClusterLegend                  ← absolute bottom-left
      GraphControls                  ← absolute top-right
    div.w-80.border-l (conditional)  ← sidebar (when node selected)
      GraphSidebar
```

**Responsive sizing:**

- Use a `useRef` + `ResizeObserver` pattern to measure the graph container div
- Pass measured `width` and `height` to GraphCanvas
- When sidebar opens/closes, the graph container width changes; ResizeObserver detects this and GraphCanvas re-sizes

**Empty state:**

- If graphData has 0 nodes after loading: show `EmptyState` with "No entities found in MuninnDB" message

**Wiring:**

- `onNodeClick` from GraphCanvas -> hook's `selectNode` (for individual nodes) or open sidebar with cluster info (for clusters)
- `onNodeDoubleClick` from GraphCanvas -> hook's `toggleCluster` (for cluster nodes) or no-op (for individual nodes)
- `onNodeHover` from GraphCanvas -> hook's `hoverNode`
- GraphControls zoom buttons -> ForceGraph2D ref methods (`zoom`, `zoomToFit`)
- GraphControls reset -> hook's `resetView`
- ClusterLegend toggle -> hook's `toggleCluster`
- GraphSidebar close -> hook's `selectNode(null)`
- GraphSidebar expand -> hook's `toggleCluster`
