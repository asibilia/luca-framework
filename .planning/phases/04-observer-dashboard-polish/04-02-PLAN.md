# Phase 4 Plan 02: Add React Error Boundaries to Observer Pages

## Objective

Complete error boundary coverage across all observer pages. Most pages already have both route-level error.tsx files and component-level `<ErrorBoundary>` wrappers. This plan fills the remaining gaps: missing route-level error.tsx files, JsonViewer crash protection for circular references, and focus-ring accessibility on the error boundary retry button.

## Context

@packages/luca-observer/components/shared/error-boundary.tsx
@packages/luca-observer/components/shared/page-error.tsx
@packages/luca-observer/components/shared/json-viewer.tsx
@packages/luca-observer/app/agents/error.tsx (pattern to follow)
@packages/luca-observer/app/cost/page.tsx
@packages/luca-observer/app/decisions/page.tsx

## Current State Assessment

After code review, error boundary coverage is extensive:

**Route-level error.tsx files (Next.js error boundaries):**

- Present: agents, harness, iterations, memory, notes, planning, tribunal, workflow, root (app/error.tsx)
- Missing: `app/cost/error.tsx`, `app/decisions/error.tsx`

**Component-level ErrorBoundary usage:**

- All pages wrap data-dependent sections in `<ErrorBoundary name="...">` -- this is already done comprehensively across agents, cost, decisions, harness, iterations, memory, notes, planning, tribunal, and workflow pages.

**Hook error handling:**

- No hooks have catch blocks at all -- they use SpacetimeDB's `useTable` which handles errors internally via React Suspense/Error Boundary patterns. This is correct; no silent catches to fix.

**JsonViewer crash risk:**

- `JsonViewer` uses `JSON.stringify(data, null, 2)` which throws on circular references. Needs a safe stringify wrapper.

### 3. Add circular reference protection to JsonViewer

**Type:** auto
**TDD:** false
**Depends on:** none

Wrap `JSON.stringify` in a try-catch to handle circular references and other stringify failures gracefully, displaying an error message instead of crashing.

**Files to edit:**

- `packages/luca-observer/components/shared/json-viewer.tsx`

**Changes:**
Replace the direct `JSON.stringify` call with a safe version:

```tsx
let json: string;
try {
  json = JSON.stringify(data, null, 2);
} catch {
  return (
    <div className="rounded border border-border bg-background p-2">
      <p className="font-mono text-xs text-destructive">
        Unable to display data (circular reference or non-serializable value)
      </p>
    </div>
  );
}
```

**Verification:**

- `JSON.stringify` is wrapped in try-catch in JsonViewer
- Component renders a descriptive error message instead of crashing on circular data
- TypeScript compiles: `bunx --bun tsc --noEmit`
