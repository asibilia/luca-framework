# Phase 155 Plan 1: Session Compact Restore Hook

## Objective

Create a SessionStart hook that detects post-compaction restarts and injects the checkpoint saved by the PreCompact hook as a systemMessage. This gives the LLM precise context about where it was and what to do next after compaction.

## Context

@src/hooks/scripts/session-start.sh
@src/hooks/scripts/pre-compact-checkpoint.sh
@src/hooks/\_\_helpers/hook-registry.ts
@.claude/settings.json

## Tasks

### 1. Create session-compact-restore.sh script

**Type:** auto
**TDD:** false
**Depends on:** none

Create `src/hooks/scripts/session-compact-restore.sh` following existing hook patterns.

**Detection strategy:** Check if `.planning/.context-checkpoint.json` exists. If it does, a compaction just happened — read and inject checkpoint. If it doesn't, this is a fresh session — exit silently.

The script must:

1. Standard hook header: `#!/usr/bin/env bash`, `set -euo pipefail`, source `_lib/common.sh`, `guard_dedup`
2. Read stdin (consume but don't parse — SessionStart has no useful payload for this)
3. Check if `.planning/.context-checkpoint.json` exists — if not, exit 0 silently
4. Read checkpoint from filesystem (primary — fastest, most reliable)
5. Attempt MuninnDB recall as backup: `curl -s --max-time 3 "${MUNINN_URL}/api/engrams?vault=luca-framework&concept=session:checkpoint&limit=1"`
6. Format checkpoint as structured systemMessage (~1KB max) using `bun -e` with `process.env`:

```
[Context Restored] Resuming after compaction.

Position: Phase {phase}, Complexity: {complexity}, Milestone: {milestone}
Trigger: {trigger} compaction

Recent work:
{completed_summary}

MuninnDB vault: luca-framework
```

7. Output via `printf '{"systemMessage": "..."}'`
8. Clean up: remove `.planning/.context-checkpoint.json` after successful restore
9. Run synchronously (NOT async — must inject before LLM responds)

**Files to create:**

- `src/hooks/scripts/session-compact-restore.sh` (make executable)

**Verification:**

- Script exits silently when no checkpoint exists
- Script outputs systemMessage when checkpoint exists
- Checkpoint file is cleaned up after restore
- No jq — only bun -e with process.env

### 2. Register hook in canonicalHookRegistry

**Type:** auto
**TDD:** false
**Depends on:** 1

Add `"session-compact-restore"` entry to `canonicalHookRegistry` in `src/hooks/__helpers/hook-registry.ts`:

```typescript
"session-compact-restore": () => ({
  event: "session_start",
  script: "session-compact-restore.sh",
  timeout: 10,
  async: false,
  status_message: "Restoring context...",
}),
```

Note: This is a separate hook from `session-start`. Both fire on `session_start` event. `session-compact-restore` is synchronous and checks for checkpoint existence.

**Files to edit:**

**Verification:**

- Entry exists in canonicalHookRegistry
- Event is `"session_start"`
- `async: false` (must inject before LLM responds)
