# Plan 128-03: Session lock cleanup, template verification, and dual-write hardening

## Objective

Address three build/reliability items: (1) automatic stale session lock cleanup (#51), (2) verify harness-aware update templates (#60), and (3) harden dual-write with divergence detection (#62).

## Tasks

### Task 1: Add automatic stale session lock cleanup (#51)

- Read `src/hooks/pi-extensions/__helpers/session-init.ts` and `src/hooks/pi-extensions/__helpers/hook-handlers.ts` for current lock handling
- Add a stale lock detection mechanism: if a session lock file exists but the process that created it is no longer running, automatically clean it up
- The check should run at session start (in session-init or hook-handlers)

### Task 2: Verify harness-aware update command template collection (#60)

- Read `src/skills/` to find the update command skill
- Verify that templates referenced by the update command are correctly collected
- If everything is correct: document as verified and close
- If gaps found: fix them

### Task 3: Harden dual-write with divergence detection (#62)

- Read `packages/luca-framework/src/state/bridge.ts` for the dual-write mechanism (writes to both state machine JSON and STATE.md)
- Add a lightweight divergence check: after writing both, optionally compare key fields to detect drift
- Log a warning if STATE.md and state.json diverge on critical fields (phase, plan, status)
- This should NOT throw errors — just log warnings for observability
