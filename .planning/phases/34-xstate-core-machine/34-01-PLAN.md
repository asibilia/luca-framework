# Plan 34-01: Core Workflow State Machine with Types, Guards, and Actions

## Objective

Define the foundational XState v5 state machine that models the full Luca workflow lifecycle. This plan creates the type system (Zod schemas for context and events), implements all guard functions encoding complexity gating and gate config, implements action functions for context mutations, and wires them together into the main `workflowMachine` definition. The machine is the deterministic backbone that replaces LLM-driven STATE.md parsing with validated state transitions.

This plan covers XSTATE-01 (full workflow lifecycle machine) and XSTATE-04 (transition guards encoding complexity gating, oversight levels, and gate config).

## Context

@src/complexity/index.ts -- Public API for complexity gating module. Exports `ComplexityLevel`, `meetsThreshold`, `getTier`, `COMPLEXITY_LEVELS`, `COMPLEXITY_ORDER`. Guards import `meetsThreshold` from here.

@src/complexity/types.ts -- Type definitions: `ComplexityLevel`, `ComplexityGate`, `ComplexityMatrix`, `VerificationMode`, `StepActivation`. The `ComplexityGate` interface has all gating fields (`research`, `discussion`, `harnessFixIterations`, `verifyFixIterations`, `verificationMode`, `uat`, `learningCapture`).

@src/complexity/defaults.ts -- `DEFAULT_COMPLEXITY_MATRIX` with all 5 levels fully defined. The state machine loads this as the default complexity matrix for guards.

@src/iteration/types.ts -- Zod schemas for `BudgetState` (`budgetStateSchema`), `LoopType`, `IterationMode`. The machine context references `BudgetState` for iteration budget tracking.

@src/iteration/budget.ts -- `shouldStartIteration(state)` returns `{ allowed: boolean, reason: string }`. Guards call this for budget checks. `createBudgetState`, `advanceBudget`, `assessBudget` are also available.

@src/harness/types.ts -- `HarnessResult` interface with `status`, `checks`, `totalErrors`, `totalWarnings`, `duration`, `timestamp`. Referenced in event payloads.

@src/shared/types.ts -- `Result<T>` discriminated union (`{ success: true, data: T } | { success: false, error: string }`). Used as return type pattern.

@src/context/result-envelope.ts -- `ResultEnvelope` schema for agent outputs. Referenced in phase result tracking.

@.planning/config.json -- Runtime configuration with `gates`, `workflow`, `complexity.matrix`, `autopilot`, `harness`, `iteration` sections. The machine loads this at initialization to populate context.

@.claude/rules/complexity-gating.md -- The complexity gating matrix rule. Documents all 5 levels and which steps activate at each level. Guards encode this matrix programmatically.

### Task 3: Implement guard functions

**Goal:** Create `src/state-machine/guards.ts` with all named guard functions that encode the complexity gating matrix, gate config booleans, oversight levels, and safety checks. Guards are pure functions -- they receive context and optional params, return boolean.

**Files:** `src/state-machine/guards.ts` (create)

**Steps:**

1. Create `src/state-machine/guards.ts` with the following imports:

   ```typescript
   import { meetsThreshold } from "../complexity";
   import type { ComplexityLevel, StepActivation } from "../complexity/types";
   import { shouldStartIteration } from "../iteration/budget";
   import { budgetStateSchema } from "../iteration/types";
   import get from "lodash/get";
   ```

2. Implement a helper to look up the complexity gate for the current level:

   ```typescript
   /**
    * Look up a gating field from the complexity matrix for the current level.
    *
    * @param context - The workflow context containing complexity and complexity_matrix
    * @param field - The ComplexityGate field name to look up
    * @returns The field value, or undefined if not found
    */
   function getGateField(
     context: { complexity: string; complexity_matrix: Record<string, any> },
     field: string,
   ): any {
     return get(context.complexity_matrix, `${context.complexity}.${field}`);
   }

   /**
    * Check if a step activation value means the step should run.
    */
   function shouldActivate(activation: StepActivation | undefined): boolean {
     if (!activation) return false;
     return activation !== "skip";
   }
   ```

3. Define all guard implementations as a plain object (to be spread into `setup()`):

   ```typescript
   export const workflowGuards = {
     // --- Complexity gating guards ---

     /** Research step should run (required or run for this complexity) */
     shouldRunResearch: ({ context }: { context: any }) => {
       const activation = getGateField(context, "research") as
         | StepActivation
         | undefined;
       return activation === "required" || activation === "run";
     },

     /** Discussion step should run (not skipped for this complexity) */
     shouldRunDiscussion: ({ context }: { context: any }) => {
       const activation = getGateField(context, "discussion") as
         | StepActivation
         | undefined;
       return shouldActivate(activation);
     },

     /** UAT step should run */
     shouldRunUAT: ({ context }: { context: any }) => {
       const activation = getGateField(context, "uat") as
         | StepActivation
         | undefined;
       return activation === "required" || activation === "required+thorough";
     },

     /** Learning capture should run (not skipped) */
     shouldCaptureLearnings: ({ context }: { context: any }) => {
       const capture = getGateField(context, "learningCapture") as
         | string
         | undefined;
       return capture !== "skip" && capture !== undefined;
     },

     // --- Gate config guards ---

     /** A named gate is enabled in config.json gates section */
     gateEnabled: ({ context }: { context: any }, params: { gate: string }) => {
       return context.gates[params.gate] === true;
     },

     /** A named gate is disabled or absent in config.json gates section */
     gateDisabled: (
       { context }: { context: any },
       params: { gate: string },
     ) => {
       return context.gates[params.gate] !== true;
     },

     // --- Oversight guards ---

     /** Current oversight level requires human approval for this transition */
     needsHumanApproval: ({ context }: { context: any }) => {
       return context.oversight === "plan" || context.oversight === "phase";
     },

     /** Running in full-auto mode (no human gates) */
     isFullAuto: ({ context }: { context: any }) => {
       return context.oversight === "full-auto";
     },

     // --- Budget / iteration guards ---

     /** Iteration budget allows another attempt */
     withinBudget: ({ context }: { context: any }) => {
       if (!context.iteration_budget) return true;
       const parsed = budgetStateSchema.safeParse(context.iteration_budget);
       if (!parsed.success) return false;
       return shouldStartIteration(parsed.data).allowed;
     },

     /** Verification can be retried (attempts < max) */
     canRetryVerification: ({ context }: { context: any }) => {
       return context.verification_attempts < context.max_verification_attempts;
     },

     // --- Complexity threshold guards ---

     /** Current complexity meets or exceeds a minimum threshold */
     meetsComplexityThreshold: (
       { context }: { context: any },
       params: { min: ComplexityLevel },
     ) => {
       return meetsThreshold(context.complexity as ComplexityLevel, params.min);
     },

     // --- Workflow config guards ---

     /** A workflow config boolean is enabled */
     workflowConfigEnabled: (
       { context }: { context: any },
       params: { key: string },
     ) => {
       return get(context.workflow_config, params.key) === true;
     },

     /** Autopilot has more phases to execute */
     hasMorePhases: ({ context }: { context: any }) => {
       const maxPhases = get(
         context.autopilot_config,
         "max_phases_per_session",
         1,
       ) as number;
       return context.phase_results.length < maxPhases;
     },

     // --- State guards ---

     /** Machine has a current phase set */
     hasCurrentPhase: ({ context }: { context: any }) => {
       return (
         context.current_phase !== undefined && context.current_phase !== null
       );
     },

     /** Last phase completed successfully */
     lastPhaseSucceeded: ({ context }: { context: any }) => {
       if (!context.phase_results || context.phase_results.length === 0)
         return false;
       const last = context.phase_results[context.phase_results.length - 1];
       return last.status === "passed";
     },
   };
   ```

   ```typescript
   export const workflowActions = {
     /** Record the timestamp of the current transition */
     recordTransition: assign({
       last_transition_at: () => new Date().toISOString(),
     }),

     /** Set ticket_id and started_at from START event */
     initSession: assign({
       ticket_id: ({
         event,
       }: {
         event: Extract<WorkflowEvent, { type: "START" }>;
       }) => event.ticket_id,
       started_at: () => new Date().toISOString(),
       last_transition_at: () => new Date().toISOString(),
     }),

     /** Store intuition flags from preflight */
     recordIntuitionFlags: assign({
       intuition_flags: ({
         event,
       }: {
         event: Extract<WorkflowEvent, { type: "PREFLIGHT_COMPLETE" }>;
       }) => event.intuition_flags,
       last_transition_at: () => new Date().toISOString(),
     }),

     /** Set complexity level from routing */
     setComplexity: assign({
       complexity: ({
         event,
       }: {
         event: Extract<WorkflowEvent, { type: "ROUTE_COMPLETE" }>;
       }) => event.complexity,
       last_transition_at: () => new Date().toISOString(),
     }),

     /** Record phase completion result */
     recordPhaseResult: assign({
       phase_results: ({
         context,
         event,
       }: {
         context: WorkflowContext;
         event: Extract<WorkflowEvent, { type: "PHASE_COMPLETE" }>;
       }) => [
         ...context.phase_results,
         {
           phase_id: event.phase_id,
           status: "passed" as const,
           summary: event.summary ?? "",
           errors: [],
           duration_ms: 0,
           timestamp: new Date().toISOString(),
         },
       ],
       last_transition_at: () => new Date().toISOString(),
     }),

     /** Record phase failure */
     recordPhaseError: assign({
       phase_results: ({
         context,
         event,
       }: {
         context: WorkflowContext;
         event: Extract<WorkflowEvent, { type: "PHASE_FAILED" }>;
       }) => [
         ...context.phase_results,
         {
           phase_id: event.phase_id,
           status: "failed" as const,
           summary: "",
           errors: [event.error ?? "Unknown error"],
           duration_ms: 0,
           timestamp: new Date().toISOString(),
         },
       ],
       last_error: ({
         event,
       }: {
         event: Extract<WorkflowEvent, { type: "PHASE_FAILED" }>;
       }) => event.error,
       last_transition_at: () => new Date().toISOString(),
     }),

     resetVerificationAttempts: assign({
       verification_attempts: () => 0,
       harness_result: () => undefined,
       last_transition_at: () => new Date().toISOString(),
     }),

     /** Increment verification attempt counter */
     incrementVerificationAttempts: assign({
       verification_attempts: ({ context }: { context: WorkflowContext }) =>
         context.verification_attempts + 1,
       last_transition_at: () => new Date().toISOString(),
     }),

     /** Record skip reason */
     recordSkip: assign({
       skip_reason: ({
         event,
       }: {
         event: Extract<WorkflowEvent, { type: "SKIP" }>;
       }) => event.reason,
       last_transition_at: () => new Date().toISOString(),
     }),

     /** Record abort reason and clear current phase */
     recordAbort: assign({
       last_error: ({
         event,
       }: {
         event: Extract<WorkflowEvent, { type: "ABORT" }>;
       }) => event.reason,
       current_phase: () => undefined,
       last_transition_at: () => new Date().toISOString(),
     }),

     /** Reset machine context for a new session */
     resetContext: assign({
       current_phase: () => undefined,
       current_plan_ids: () => [],
       phase_results: () => [],
       harness_result: () => undefined,
       verification_attempts: () => 0,
       iteration_budget: () => undefined,
       intuition_flags: () => [],
       skip_reason: () => undefined,
       last_error: () => undefined,
       last_transition_at: () => new Date().toISOString(),

     /** Record halt reason for paused state */
     recordHalt: assign({
       last_error: ({
         event,
       }: {
         event: Extract<WorkflowEvent, { type: "VERIFY_HALTED" }>;
       }) => event.reason,

       last_error: ({
         event,
       }: {
         event: Extract<WorkflowEvent, { type: "VERIFY_FAILED" }>;
       }) => `Verification gaps: ${event.gaps.join(", ")}`,
       last_transition_at: () => new Date().toISOString(),
     }),
   ```

   ```typescript
   import { initializeContext } from "./types";

   import { workflowActions } from "./actions";
   ```

2. Define the machine using `setup()` + `createMachine()`:

   ```typescript
   /**
    * The Luca workflow state machine.
    *
    * Models the full workflow lifecycle from idle through execution,
    * verification, learning, and commit. Guards encode complexity
    * gating and gate config. Actions mutate context immutably.
    *
    * States:
    * - idle: Waiting for a START event
    * - preflight: Cognitive pre-flight (BRAIN.md, MEMORY.md recall)
    * - routing: Complexity classification via lu-router
    * - discussing: Phase discussion (optional, gated by complexity)
    * - planning: Plan creation and verification
    * - executing: Phase execution (plan waves)
    * - verifying: Harness + verifier checks
    * - learning: Pattern/decision/pitfall capture
    * - committing: Git commit
    * - complete: Terminal success state
    * - paused: Waiting for human intervention
    * - failed: Terminal error state
    */
   export const workflowMachine = setup({
     types: {
       context: {} as WorkflowContext,
       events: {} as WorkflowEvent,
     },
     guards: workflowGuards,
     actions: workflowActions,
   }).createMachine({
     id: "luca-workflow",
     initial: "idle",
     context: ({ input }) => initializeContext(input as any),

     states: {
       idle: {
         on: {
           START: {
             target: "preflight",
             actions: ["initSession", "recordTransition"],
           },
         },
       },

       preflight: {
         on: {
           PREFLIGHT_COMPLETE: {
             target: "routing",
             actions: ["recordIntuitionFlags", "recordTransition"],
           },
           SKIP: {
             target: "routing",
             actions: ["recordSkip", "recordTransition"],
           },
         },
       },

       routing: {
         on: {
           ROUTE_COMPLETE: [
             {
               target: "discussing",
               guard: "shouldRunDiscussion",
               actions: ["setComplexity", "recordTransition"],
             },
             {
               target: "planning",
               actions: ["setComplexity", "recordTransition"],
             },
           ],
         },
       },

       discussing: {
   ```

   ```typescript
   import { createActor } from "xstate";

   /**
    * Get the list of event types that are valid in the current state.
    *
    * Useful for CLI `status` command and LLM prompt construction.
    *
    * @param snapshot - The current machine snapshot
    * @returns Array of event type strings that the machine will accept
    */
   export function getAllowedEvents(
     snapshot: ReturnType<
       ReturnType<typeof createActor<typeof workflowMachine>>["getSnapshot"]
     >,
   ): string[] {
     const state = snapshot.value as string;
     const stateConfig = workflowMachine.config.states?.[state];
     if (!stateConfig || !stateConfig.on) return [];
     return Object.keys(stateConfig.on);
   }
   ```
