### 1. Create contradiction-card component

**Type:** auto
**TDD:** false
**Depends on:** none

```typescript
interface ContradictionCardProps {

```

**Layout:**

Each contradiction card is a horizontal card with three sections:

```
+------------------+----------+------------------+
|   Memory A       | Conflict |   Memory B       |
|                  |  Reason  |                  |
|  concept_a       |          |  concept_b       |
|                  |          |                  |
|  [Forget A]      |          |  [Forget B]      |
|  [View A]        |          |  [View B]        |
+------------------+----------+------------------+
```

**Left column (Memory A):**

- Concept name (`concept_a`) in bold (`text-sm font-semibold`)
- "Forget" button -- calls `onForget(contradiction.id_a)`, shows "Forgetting..." while in progress, disabled when another forget is in progress
- "View in Memory" link -- `<a href={/memory?entity=${encodeURIComponent(contradiction.concept_a)}}>View in Memory</a>`

**Center column (Conflict Reason):**

- The `reason` field displayed in a visually distinct style
- Use `text-sm text-muted-foreground italic` for the reason text
- Optional: a small warning icon (AlertTriangle from lucide-react, already imported via sidebar) above the reason

**Right column (Memory B):**

- Same layout as Memory A but for `concept_b` and `id_b`

**Responsive behavior:**

- On narrow screens (below md breakpoint), stack vertically: Memory A, then Reason, then Memory B
- Use `flex flex-col md:flex-row` pattern

**Forget button states:**

- Default: "Forget" (`text-xs text-destructive hover:underline`)
- Loading (forgettingId matches this engram): "Forgetting..." (disabled)
- After successful forget: the card should be removed by the parent (hook filters it out)

**Styling:**

- Card: `border border-border rounded-lg p-4 bg-card`
- Columns: `flex-1` for left/right, `flex-shrink-0 px-4` for center reason
- Divider between columns: `border-l border-border` on center and right columns (desktop only)

### 2. Create contradiction-list container component

**Type:** auto
**TDD:** false
**Depends on:** 1

Create `packages/luca-observer/components/contradictions/contradiction-list.tsx`.

**Props:**

```typescript
interface ContradictionListProps {
  contradictions: ContradictionPair[];
  onForget: (engramId: string) => Promise<boolean>;
}
```

**Layout:**

- Summary line at top: "{count} contradictions found" (`text-sm text-muted-foreground`)
- Vertical list of ContradictionCard components
- Gap between cards: `space-y-4`
- Track `forgettingId` in local state to pass down to cards (only one forget at a time)
- On forget success, the hook removes the pair from the list (optimistic update from hook)
- If contradictions is empty: show EmptyState with message "No contradictions found -- your knowledge base is consistent"

**Forget flow:**

1. User clicks "Forget A" or "Forget B" on a card
2. Set `forgettingId` to the engram ID being forgotten
3. Call `onForget(engramId)` (from hook)
4. On success (returns true): clear `forgettingId` (hook already removes the pair from state)
5. On failure (returns false): clear `forgettingId`, optionally show a brief inline error
