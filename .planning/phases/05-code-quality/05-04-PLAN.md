# 05-04: Content Files Cleanup

## Objective
Fix systematic naming issues and improve consistency in content files (agents, skills, rules).

## Tasks

### Task 1: Fix Class Naming Convention
**Issue:** Kebab-to-PascalCase conversion drops casing between words.
**Examples:** `CodelintSkill` → `CodeLintSkill`, `LucodebasemapperAgent` → `LuCodebaseMapperAgent`

**Approach:**
1. Write a script to scan all `*.agent.ts`, `*.skill.ts`, `*.rule.ts` files
2. For each, derive correct PascalCase from the kebab-case filename
3. Rename the exported class and update the config object's class reference
4. Update barrel files (`src/skills/index.ts`, etc.)
5. Update build script imports

**Scope:** ~27 files in `src/agents/general/`, `src/skills/general/`, `src/rules/general/`

### Task 2: Add `import type` for Type-Only Imports
**Issue:** Content files use `import { AgentConfig }` instead of `import type { AgentConfig }`

**Approach:**
- Scripted replacement across all content files
- Only change imports that are type-only (not runtime values)

### Task 3: Verify
- `bun test` passes
- Build scripts still work

## Exit Criteria
- All exported classes follow proper PascalCase naming
- Type-only imports use `import type`
- Build scripts and tests pass
