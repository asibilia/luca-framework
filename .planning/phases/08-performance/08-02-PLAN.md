# Plan 08-02: Dependency Cleanup and Utility Deduplication

## Frontmatter
- **ID**: 08-02
- **Title**: Dependency Cleanup and Utility Deduplication
- **Wave**: 1
- **Depends on**: none

## Objective
Remove the unnecessary `fs-extra` production dependency by replacing all `ensureDir()` calls with native `mkdir(path, { recursive: true })` from `fs/promises`. Also deduplicate the `getAllFiles()` and `isTemplateFile()` functions that are identically defined in both `template.ts` and `update.ts`, and fix the unnecessary dynamic import of `readdir` inside `update.ts`.

## Context
- `packages/luca-framework/src/utils/files.ts` -- Imports `ensureDir` from `fs-extra` (line 4), only usage in this file is line 141
- `packages/luca-framework/src/utils/template.ts` -- Imports `ensureDir` from `fs-extra` (line 4), used at line 210; defines `getAllFiles` (lines 104-118) and `isTemplateFile` (lines 129-147)
- `packages/luca-framework/src/commands/update.ts` -- Imports `ensureDir` from `fs-extra` (line 6), used at lines 217, 239, 257, 318; duplicates `getAllFiles` (lines 21-36) and `isTemplateFile` (lines 41-59); has unnecessary dynamic import of `readdir` at line 22
- `packages/luca-framework/package.json` -- Lists `fs-extra` in dependencies (line 16) and `@types/fs-extra` in devDependencies (line 24)

## Tasks

### Task 1: Replace `ensureDir` with native `mkdir` in `files.ts`
**Goal**: Remove the `fs-extra` import from `files.ts` and use the native `mkdir` from `fs/promises` instead.
**File:** `packages/luca-framework/src/utils/files.ts`
**Changes:**
1. Remove `import { ensureDir } from 'fs-extra'` (line 4).
2. Add `mkdir` to the existing `fs/promises` import on line 1.
3. Replace `await ensureDir(dir)` with `await mkdir(dir, { recursive: true })` at line 141.

**Before (lines 1, 4, 141):**
```ts
import { rm } from 'fs/promises';
// ...
import { ensureDir } from 'fs-extra';
// ...
        await ensureDir(dir);
```

**After:**
```ts
import { rm, mkdir } from 'fs/promises';
// (remove fs-extra import entirely)
// ...
        await mkdir(dir, { recursive: true });
```

**Verification:**
- `bun test` passes
- `luca init` still creates directories correctly
- No `fs-extra` import remains in this file
