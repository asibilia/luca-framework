<task type="auto">
  <name>Task 3: Create Troubleshooting guide</name>
  <files>
    docs/troubleshooting.md
  </files>
  <action>
    Create docs/troubleshooting.md with common issues and solutions:

    Structure:
    1. "# Troubleshooting Luca"
    2. Quick diagnostic: "Run `npx luca doctor` first"
    3. Common Issues (FAQ style):

    **Issue: "command not found: luca"**
    - Solution: Use `npx luca <command>` or install globally `npm install -g luca-framework`

    **Issue: "Cursor IDE not detected"**
    - Solution: Ensure Cursor is in /Applications (macOS) or PATH. Install from cursor.com if missing.

    **Issue: "Node.js version too old"**
    - Solution: Upgrade to Node.js 18+. Use nvm: `nvm install 20`

    **Issue: "Config validation failed"**
    - Solution: Check .planning/config.json syntax. Run `npx luca init` to regenerate.

    **Issue: "Work tracker not connecting"**
    - Solution: Check adapter config in config.json. Verify env vars (JIRA_TOKEN, etc.).

    **Issue: "Update failed with conflicts"**
    - Solution: Conflicts written to .cursor/luca/conflicts/. Review and merge manually.

    **Issue: "Agent commands not appearing in Cursor"**
    - Solution: Ensure .cursor/ directory is at project root. Restart Cursor IDE.

    4. Getting Help:
       - Run `npx luca doctor` for diagnostics
       - Check GitHub Issues for similar problems
       - Include `npx luca doctor` output in bug reports

    Keep each issue/solution pair brief. Focus on actionable fixes.
    Include commands users can copy-paste.
  </action>
  <verify>
