# Plan 06-05: Dependency Audit

## Frontmatter
- **ID**: 06-05
- **Title**: Dependency Audit
- **Wave**: 5
- **Depends on**: none (can run at any point, but best after 06-04 adds js-yaml)

## Objective

Run a dependency audit to identify and remediate any known vulnerabilities (CVEs) in project dependencies. This is an explicit success criterion in the roadmap: "Dependency audit clean (no high/critical CVEs)."

## Context

- `package.json` (root) -- workspace root with Zod, TypeScript, Bun types
- `packages/luca-framework/package.json` -- CLI framework with citty, consola, execa, ejs, pathe, etc.
- `packages/create-luca/package.json` -- thin scaffolder
- After 06-04: `js-yaml` will be added as a new dependency

## Tasks

### Task 1: Run dependency audit

**Goal**: Identify all known vulnerabilities in project dependencies.

**Commands:**
```bash
# Try bun audit first (may not be available in all Bun versions)
bun audit 2>/dev/null || npm audit --json 2>/dev/null || echo "No audit tool available"

# Also check for outdated dependencies with known issues
bun outdated 2>/dev/null || npm outdated 2>/dev/null
```

**If `bun audit` is not available:**
- Use `npm audit` (npm is available alongside Bun)
- Or use `npx audit-ci --high` for CI-compatible audit

**Output**: Document findings -- number of vulnerabilities by severity (low, moderate, high, critical).

### Task 2: Remediate high/critical vulnerabilities

**Goal**: Fix any high or critical CVEs found in the audit.

**Changes (conditional on findings):**
1. For direct dependencies with fixes available: update to patched version
   ```bash
   bun add <package>@latest
   ```
2. For transitive dependencies: check if updating the parent dependency resolves it
3. For unfixable vulnerabilities: document the risk and add to known issues if the vulnerability does not apply to our use case (e.g., server-only CVE in a CLI tool)

### Task 3: Verify clean audit

**Goal**: Confirm no high/critical vulnerabilities remain after remediation.

**Verification:**
```bash
# Re-run audit
bun audit 2>/dev/null || npm audit 2>/dev/null

# Verify all tests still pass after any dependency updates
bun test
```

## Exit Criteria

- Dependency audit has been run (bun audit or npm audit)
- No high or critical vulnerabilities remain (or documented as non-applicable with rationale)
- Any dependency updates do not break existing tests
- `bun test` exits cleanly
