# Plan 131-01: Hook portability, plugin marketplace, and post-init tour

## Objective

Implement hook portability abstraction (#09), plugin marketplace foundation (#17), and post-init interactive tour (#20).

## Context

Existing infrastructure:

- `src/hooks/__helpers/platform-adapters.ts` — already has platform adapter patterns
- `src/hooks/__schemas/hook.schemas.ts` — hook schemas with platform support

## Tasks

### Task 1: Hook portability abstraction layer (#09)

- Read `src/hooks/__helpers/platform-adapters.ts` for existing adapter code
- Read `src/hooks/__schemas/hook.schemas.ts` for current schema
- Enhance the platform adapter to be a proper abstraction layer:
  - `createPortableHook(config: PortableHookConfig): PlatformHooks` — generates hooks for all supported platforms (Claude Code, Cursor, Pi) from a single config
  - `PortableHookConfigSchema` — unified config format
  - `detectPlatform(): Platform` — detects current runtime platform
- If the abstraction is already sufficient, document it and enhance tests
- Export from `src/hooks/index.ts`

### Task 2: Plugin marketplace foundation (#17)

- Create `src/skills/__helpers/marketplace.ts` with:
  - `PluginRegistrySchema` — schema for a plugin registry entry (name, version, author, description, skills[], rules[], hooks[])
  - `searchRegistry(query: string, registry: PluginEntry[]): PluginEntry[]` — search plugins by keyword
  - `validatePlugin(plugin: PluginEntry): ValidationResult` — validate a plugin meets requirements
  - `installPlugin(plugin: PluginEntry, projectDir: string): InstallResult` — copy plugin files into project
- This is the foundation — no remote registry yet, just local schema and operations
- Export from `src/skills/index.ts`

### Task 3: Post-init interactive tour (#20)

- Create `src/skills/general/post-init-tour.skill.ts` with:
  - Tour steps explaining key concepts: BRAIN.md, MEMORY.md, skills, agents, phases
  - Each step outputs a message and waits for acknowledgment
  - Uses the existing skill definition format
- Register in skill registry
- Add tests

## Verification Criteria

- [ ] Post-init tour skill registered and testable
- [ ] `bunx --bun tsc --noEmit` passes
