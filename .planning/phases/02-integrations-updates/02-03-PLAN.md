**Environment variables (read inside adapter):**
- `JIRA_BASE_URL` — e.g., "https://yourcompany.atlassian.net"
- `JIRA_USER_EMAIL` — Atlassian account email
- `JIRA_API_TOKEN` — API token from Atlassian security settings

**Implementation details:**

1. **name property:** `'jira' as const`

2. **getTicket(ticketId: string):**
   - Check env vars exist, return error if missing
   - Build URL: `${baseUrl}/rest/api/3/issue/${ticketId}?fields=summary,description,issuetype,priority,status,assignee`
   - Build auth header: `Basic ${Buffer.from(`${email}:${token}`).toString('base64')}`
   - Execute fetch with headers: Authorization, Accept: application/json
   - Handle response codes:
     - 401 → `{ success: false, error: 'Jira authentication failed. Check API token.' }`
     - 404 → `{ success: false, error: 'Ticket ${ticketId} not found.' }`
     - Other non-OK → `{ success: false, error: 'Jira API error: ${response.status}' }`
   - Parse response and map to WorkTicket:
     - id: ticketId
     - title: `data.fields.summary`
     - description: extract from ADF content or empty string (Jira uses ADF format)
     - type: map via `mapJiraType(data.fields.issuetype?.name)`
     - status: `data.fields.status?.name || 'Unknown'`
     - priority: map via `mapJiraPriority(data.fields.priority?.name)`
     - assignee: `data.fields.assignee?.displayName`
     - url: `${baseUrl}/browse/${ticketId}`

3. **validate():**
   - Check env vars exist
   - Hit `${baseUrl}/rest/api/3/myself` with auth headers
   - Return success if 200, error otherwise

**Helper functions:**

```typescript
function mapJiraType(type: string): WorkTicket['type'] {
  const typeMap: Record<string, WorkTicket['type']> = {
    'Bug': 'bug',
    'Story': 'story',
    'Task': 'task',
    'Epic': 'epic',
    'Sub-task': 'subtask',
  };
  return typeMap[type] || 'task';
}

function mapJiraPriority(priority: string): WorkTicket['priority'] {
  const priorityMap: Record<string, WorkTicket['priority']> = {
    'Highest': 'highest',
    'High': 'high',
    'Medium': 'medium',
    'Low': 'low',
    'Lowest': 'lowest',
  };
  return priorityMap[priority] || 'medium';
}
```

**ADF Description Extraction:**
Jira's description field uses Atlassian Document Format. Extract text:
```typescript
function extractAdfText(adf: unknown): string {
  if (!adf || typeof adf !== 'object') return '';
  const content = (adf as { content?: Array<{ content?: Array<{ text?: string }> }> }).content;
  if (!Array.isArray(content)) return '';
  return content
    .flatMap(block => block.content || [])
    .map(node => node.text || '')
    .join(' ')
    .trim();
}
```
