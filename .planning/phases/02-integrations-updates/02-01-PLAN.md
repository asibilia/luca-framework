<task type="auto">
  <name>Task 2: Create WorkTrackerContract Interface</name>
  <files>packages/luca-framework/src/contracts/work-tracker.ts</files>
  <action>
Create new file `packages/luca-framework/src/contracts/work-tracker.ts` with:

1. **WorkTicket interface** — Ticket details returned from any tracker:
   - id: string (e.g., "PROJ-1234" or "#123")
   - title: string
   - description: string
   - type: 'bug' | 'story' | 'task' | 'epic' | 'subtask'
   - status: string
   - priority: 'highest' | 'high' | 'medium' | 'low' | 'lowest'
   - assignee?: string
   - url: string

2. **AdapterResult&lt;T&gt; type** — Discriminated union for results:
   - `{ success: true; data: T }`
   - `{ success: false; error: string }`

3. **WorkTrackerContract interface**:
   - `readonly name: 'jira' | 'github' | 'none'`
   - `getTicket(ticketId: string): Promise<AdapterResult<WorkTicket>>` (REQUIRED)
   - `createBranch?(ticketId: string, branchName: string): Promise<AdapterResult<string>>` (OPTIONAL)
   - `linkPR?(ticketId: string, prUrl: string): Promise<AdapterResult<void>>` (OPTIONAL)
   - `validate?(): Promise<AdapterResult<boolean>>` (OPTIONAL)

Include JSDoc comments explaining:
- Required vs optional methods
- How adapters should handle unsupported operations
- Expected error messages for configuration issues

Follow existing patterns from `src/types.ts` for interface style.
  </action>
  <verify>
`bun build` succeeds. TypeScript can import the contract: `import type { WorkTrackerContract } from './contracts/work-tracker'`
  </verify>
  <done>
Contract file exists with WorkTicket, AdapterResult, and WorkTrackerContract exported. TypeScript compilation passes.
  </done>
</task>
