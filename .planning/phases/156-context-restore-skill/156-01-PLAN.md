# Phase 156 Plan 1: Context Restore Skill

## Objective

Create a `/context-restore` skill for on-demand deep context recovery. This is Layer 2 of the restore architecture — users invoke it when they want richer context than the automatic 1KB SessionStart injection.

## Context

@src/skills/general/session-resume.skill.ts
@src/skills/**schemas/skill.schemas.ts
@src/skills/**helpers/create-skill.ts

## Tasks

### 1. Create context-restore.skill.ts

**Type:** auto
**TDD:** false
**Depends on:** none

Create `src/skills/general/context-restore.skill.ts` following the `session-resume.skill.ts` pattern.

The skill config should:

1. Use `createSkill()` factory from `~/skills/__helpers/create-skill`
2. Set frontmatter: `name: "context-restore"`, description of context recovery
3. Define a `main` section with the skill prompt content

The skill prompt should instruct the LLM to:

1. **Read checkpoint from filesystem**: Read `.planning/.context-checkpoint.json` if it exists
2. **Recall from MuninnDB**: Use `mcp__muninn__muninn_recall(vault: "luca-framework", context: ["session:checkpoint", "context recovery"])`
3. **If no checkpoint exists**: Inform user and offer to read `.planning/STATE.md` and recent git log instead
4. **Hub-and-spoke expansion**: Extract keywords from checkpoint (phase, goal) and perform semantic recall from both vaults:
   - Repo vault: `mcp__muninn__muninn_recall(vault: "luca-framework", context: [keywords])`
   - Default vault: `mcp__muninn__muninn_recall(vault: "default", context: [keywords])`
   - Cap at 5-7 related engrams
5. **Present structured output**:

```markdown
## Context Restored

### Checkpoint

- Position: Phase {X}, Complexity: {level}
- Milestone: {milestone}
- Trigger: {trigger} compaction

### Recent Work

{completed_summary from checkpoint}

### Related Memory (semantic recall)

- [{concept}] {summary} (score: {score})
  ...

### Recommended Next Steps

Based on the checkpoint and recalled context, suggest next actions.
```

6. **Clean up**: Remove `.planning/.context-checkpoint.json` after presenting

**Files to create:**

- `src/skills/general/context-restore.skill.ts`

**Verification:**

- File follows createSkill() pattern
- Exports default skill config
- Includes MuninnDB recall instructions for both vaults
- Handles missing checkpoint gracefully
