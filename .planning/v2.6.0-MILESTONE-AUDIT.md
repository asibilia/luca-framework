### Gap Detail

**`src/skills/__helpers/milestone-debate.ts`** imports from `~/agents/__helpers/tribunal-detector`, `~/agents/__helpers/tribunal-rebuttals`, and `~/agents/__schemas/tribunal.schemas`. This violates:

- Rule 2 (Entity Isolation): T2 domains must never cross-import
- Rule 4 (**helpers/ Encapsulation): Never import from another domain's **helpers/

**Severity:** Medium — architecturally motivated (reuses tribunal infrastructure per functional-api-reuse rule instead of duplicating), causes no runtime or compilation failures.

**Recommended fix:** Either (a) document as an accepted exception in module-boundary.md, or (b) extract shared tribunal infrastructure to `src/shared/` (T0) so both agents and skills can import without violating entity isolation.
