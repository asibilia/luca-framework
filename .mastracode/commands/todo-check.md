name: todo-check
description: List all items in the development backlog
---
Use the manageTodos tool with action "list" to show all todos.

Display them as a numbered checklist grouped by status:
1. 🔄 In Progress
2. ⬜ Open  
3. ✅ Done

Include the priority level and creation date for each item. If the backlog is empty, let the user know and suggest using /todo-add to start building it.
