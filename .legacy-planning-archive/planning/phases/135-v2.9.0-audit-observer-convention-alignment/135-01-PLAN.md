### T1: Replace `space-y-3` with `flex flex-col gap-3` in LoadingSkeleton (M6)

**File:** `packages/luca-observer/components/shared/loading-skeleton.tsx`


2. **ChartSkeleton root div (line 103):**

   ```tsx
   // BEFORE:

     "flex flex-col gap-3 rounded-lg border border-border bg-card p-4";
   ```

3. **TextSkeleton root div (line 125):**

   ```tsx
   // BEFORE:
   className = "rounded-lg border border-border bg-card p-4 space-y-3";
   // AFTER:

     "flex flex-col gap-3 rounded-lg border border-border bg-card p-4";
   ```

**Verification:** `bunx --bun tsc --noEmit` passes. Zero instances of `space-y-3` remain.

### T3: Replace emoji theme toggle with text-based toggle in header (L4)

**File:** `packages/luca-observer/components/layout/header.tsx`

**Changes (line 55):**

```tsx
// BEFORE:
{
  theme === "dark" ? "☀️" : "🌙";
}
// AFTER:
{
  theme === "dark" ? "Light" : "Dark";
}
```

**Rationale:** No icon library is installed in luca-observer. Emoji rendering is inconsistent across OS/fonts and breaks the mono font stack. Text labels align with the existing text-based UI pattern.

**Verification:** `bunx --bun tsc --noEmit` passes. No emoji characters in `header.tsx`.
