# Phase 04 Plan 01: Session Explorer View

## Objective

Build the Session Explorer page — the first MuninnDB-native view in the observer app. This page displays past workflow sessions fetched from MuninnDB, organized as a filterable, expandable list. ### 2. Create the useSessionExplorer hook

**Type:** auto
**TDD:** false
**Depends on:** none

Create the data-fetching hook for the Session Explorer. Follows the exact `useMemory` pattern: fetchingRef, Promise.allSettled, manual refresh, no polling.

**What to do:**

1. Create `packages/luca-observer/hooks/use-session-explorer.ts` with:
   - A `SessionInfo` interface for parsed session data (session_id, workflow_type, phase, start_time, engram_count, branch, github_issue, status, concept, content — all derived from parsing the session:info engram content)
   - A `useSessionExplorer()` hook that:
     - Fetches session engrams via `GET /api/muninn/engrams?type=session&limit=200` (this filters by memory_type or concept prefix)
     - Also fetches via concept prefix filter: engrams whose concept starts with `session:` — use the existing engrams route
     - Parses `session:info` engrams to extract session metadata from their content field (the emitter writes structured text with workflow, phase, timestamp info)
     - Groups findings by session using concept naming convention
     - Returns `{ sessions: SessionInfo[], loading, error, refresh, lastUpdated }`
   - Follow the fetchingRef pattern to prevent double-fetch in React strict mode
   - Handle the case where MuninnDB is not configured (503 → empty results, not error)

2. The hook should sort sessions by start_time descending (most recent first).

3. For session detail expansion (findings), provide a `fetchSessionDetail(sessionConcept: string)` function that calls `/api/muninn/find-by-entity` with the session concept as the entity name. This returns related engrams for inline display.

**Files to create:**

- `packages/luca-observer/hooks/use-session-explorer.ts`

**Verification:**

- `bunx --bun tsc --noEmit` passes from `packages/luca-observer`
- Hook exports match the documented interface
- No imports from use-memory.ts (hooks are independent)
