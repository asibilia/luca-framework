# Phase 145 Plan 1: Extend Memory Metrics Schema and Helper with Historical Data

## Objective

Replace the two hardcoded-0 metrics (`stale_engram_pct` and `confidence_calibration`) in `computeMemoryPhaseMetrics()` with real computed values. Add a `HistoricalPhaseDataSchema` for the input type, extend `ComputeMetricsConfigSchema` with an optional `historicalData` field, and implement the computation logic.

This is the foundation for Wave 2 plans. The `historicalData` parameter is consumed by phase-execute (which already calls `computeMemoryPhaseMetrics()`) when it queries MuninnDB for the last 10 phases of feedback data. Milestone-complete's stale detection operates independently in skill prompt content, querying MuninnDB directly.

### 3. Implement stale_engram_pct computation

**Type:** auto
**TDD:** false
**Depends on:** 2

In `computeMemoryPhaseMetrics()`, replace the hardcoded `stale_engram_pct: 0` with real computation when `historical_data` is provided.

**Logic:**

1. If `historical_data` is not provided OR `historical_data.engram_feedback_history` is empty, return 0 (current behavior).
2. Count engrams where BOTH conditions are met:
   - `total_recalls >= 5` AND `positive_recalls === 0`
   - `milestones_with_no_positive >= 3`
3. Divide stale count by total engrams in history.
4. Clamp result to [0, 1].

Extract the computation into a private helper function `computeStaleEngramPct()` for readability. The function should:

- Accept `HistoricalPhaseData | undefined`
- Return 0 if no data or empty array
- Apply the BOTH-conditions-required threshold from CONTEXT.md

Update JSDoc on `computeMemoryPhaseMetrics()` to remove the "hardcoded 0" note for stale_engram_pct and document the new historicalData parameter and stale computation logic.

### 4. Implement confidence_calibration computation

**Type:** auto
**TDD:** false
**Depends on:** 2

In `computeMemoryPhaseMetrics()`, replace the hardcoded `confidence_calibration: 0` with real computation when `historical_data` is provided.

**Logic:**

1. If `historical_data` is not provided OR `historical_data.confidence_actuals` has fewer than 10 entries, return 0 (minimum sample size guard per research Pitfall 5).
2. For each confidence level (low, medium, high):
   - Expected usefulness: low=0.33, medium=0.66, high=0.90
   - Compute actual usefulness rate (count where actually_useful=true / total at that level)
3. Compute calibration score: `1 - average(|expected - actual| for each confidence level that has data)`
4. Clamp result to [0, 1].

Extract into a private helper function `computeConfidenceCalibration()` for readability. The function should:

- Accept `HistoricalPhaseData | undefined`
- Return 0 if no data or fewer than 10 entries
- Handle confidence levels that have no entries gracefully (skip them in average)

Update JSDoc on `computeMemoryPhaseMetrics()` to remove the "hardcoded 0" note for confidence_calibration and document the minimum sample size requirement (10+). Add an example showing usage with historical data. Remove any stale "set to 0" comments.
