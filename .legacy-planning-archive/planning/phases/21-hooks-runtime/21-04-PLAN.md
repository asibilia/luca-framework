# Plan 21-04: Context Monitor Adaptation

## Objective

Adapt the `context-monitor.sh` hook to work in plugin environments where `transcript_path` may not be available in the Stop event stdin. Add a WORKING.md file size fallback as a secondary proxy for context usage. When both signals are available, the higher severity level wins. This ensures plugin users get context usage warnings even without transcript access.

## Context

@src/hooks/scripts/context-monitor.sh -- Current implementation (93 lines). Extracts `transcript_path` from stdin (line 39-43), exits silently if not available (line 46-48), then checks file size against thresholds (lines 55-79). Outputs dual-format JSON (lines 84-91).

@.planning/phases/21-hooks-runtime/21-RESEARCH.md -- Section 6 (Context Monitor Adaptation) details the WORKING.md fallback approach, thresholds (20/40/60 KB), and severity comparison logic.

@.planning/phases/21-hooks-runtime/21-CONTEXT.md -- Decisions section specifies: primary = transcript_path, fallback = WORKING.md size, both run, higher severity wins.

@src/hooks/scripts/session-persist.sh -- Shows how other hooks access WORKING.md at `$PROJECT_DIR/.planning/WORKING.md` (line 29).

### Task 1: Refactor threshold check into severity level logic

**Goal:** Restructure the existing transcript_path check to produce a severity level variable instead of immediately outputting a message. This enables comparison with the WORKING.md fallback level.

**Files:** `src/hooks/scripts/context-monitor.sh` (modify)

**Steps:**

1. Read `src/hooks/scripts/context-monitor.sh`.
2. Replace the current exit-early-if-no-transcript pattern (lines 46-48) and the direct threshold check (lines 55-79) with a two-phase approach:

   **Phase 1: Transcript check (produces TRANSCRIPT_LEVEL and TRANSCRIPT_MSG):**

   ```bash
   # --- Primary check: Transcript file size ---
   TRANSCRIPT_LEVEL="NONE"
   TRANSCRIPT_MSG=""

   if [ -n "$TRANSCRIPT_PATH" ] && [ -f "$TRANSCRIPT_PATH" ]; then
     FILE_SIZE=$(wc -c < "$TRANSCRIPT_PATH" | tr -d ' ')

     WARN_THRESHOLD="${CONTEXT_WARN:-100000}"
     ALERT_THRESHOLD="${CONTEXT_ALERT:-200000}"
     CRITICAL_THRESHOLD="${CONTEXT_CRITICAL:-300000}"

     if [ "$FILE_SIZE" -ge "$CRITICAL_THRESHOLD" ]; then
       TRANSCRIPT_LEVEL="CRITICAL"
       TRANSCRIPT_MSG="Context usage is very high (~${FILE_SIZE} bytes transcript). Quality may be degrading. Consider running /compact to free context space, or start a new session."
     elif [ "$FILE_SIZE" -ge "$ALERT_THRESHOLD" ]; then
       TRANSCRIPT_LEVEL="HIGH"
       TRANSCRIPT_MSG="Context usage is high (~${FILE_SIZE} bytes transcript). Consider running /compact soon to maintain response quality."
     elif [ "$FILE_SIZE" -ge "$WARN_THRESHOLD" ]; then
       TRANSCRIPT_LEVEL="MODERATE"
       TRANSCRIPT_MSG="Context usage is moderate (~${FILE_SIZE} bytes transcript). No action needed yet, but be mindful of context limits."
     fi
   fi
   ```

3. Key change: Instead of `exit 0` when transcript_path is empty, the script now continues to the WORKING.md fallback check.

**Verification:**

- [ ] No longer exits early when `transcript_path` is empty (line 46-48 pattern removed)

### Task 2: Add WORKING.md size fallback check

**Goal:** Add a secondary context usage check based on `.planning/WORKING.md` file size. WORKING.md grows during sessions as the AI logs findings, hypotheses, and learnings.

**Files:** `src/hooks/scripts/context-monitor.sh` (modify, continuing from Task 1)

**Steps:**

1. After the transcript check block, add the WORKING.md check:

   ```bash

   WORKING_LEVEL="NONE"
   WORKING_MSG=""

   PROJECT_DIR="${CLAUDE_PROJECT_DIR:-.}"
   WORKING_MD="$PROJECT_DIR/.planning/WORKING.md"

   if [ -f "$WORKING_MD" ]; then
     WMD_SIZE=$(wc -c < "$WORKING_MD" | tr -d ' ')

     WMD_WARN="${CONTEXT_WMD_WARN:-20000}"
     WMD_ALERT="${CONTEXT_WMD_ALERT:-40000}"
     WMD_CRITICAL="${CONTEXT_WMD_CRITICAL:-60000}"

     if [ "$WMD_SIZE" -ge "$WMD_CRITICAL" ]; then
       WORKING_LEVEL="CRITICAL"
       WORKING_MSG="Context usage is very high based on WORKING.md growth (~${WMD_SIZE} bytes). Quality may be degrading. Consider running /compact to free context space, or start a new session."
     elif [ "$WMD_SIZE" -ge "$WMD_ALERT" ]; then
       WORKING_LEVEL="HIGH"
       WORKING_MSG="Context usage is high based on WORKING.md growth (~${WMD_SIZE} bytes). Consider running /compact soon to maintain response quality."
     elif [ "$WMD_SIZE" -ge "$WMD_WARN" ]; then
       WORKING_LEVEL="MODERATE"
       WORKING_MSG="Context usage is moderate based on WORKING.md growth (~${WMD_SIZE} bytes). No action needed yet, but be mindful of context limits."
     fi
   fi
   ```

3. Thresholds are configurable via environment variables following the existing pattern (`CONTEXT_WARN`, `CONTEXT_ALERT`).

4. Messages explicitly mention "WORKING.md growth" to distinguish from transcript-based warnings.

**Verification:**

### Task 3: Implement severity comparison logic

**Goal:** Compare the two severity levels (transcript and WORKING.md) and use the higher one for the final warning output.

**Files:** `src/hooks/scripts/context-monitor.sh` (modify, continuing from Task 2)

**Steps:**

1. Add a severity comparison function and resolution:

   ```bash
   # --- Resolve: take the higher severity ---
   # Severity ordering: NONE=0, MODERATE=1, HIGH=2, CRITICAL=3
   severity_rank() {
     case "$1" in
       CRITICAL) echo 3 ;;
       HIGH)     echo 2 ;;
       MODERATE) echo 1 ;;
       *)        echo 0 ;;
     esac
   }

   T_RANK=$(severity_rank "$TRANSCRIPT_LEVEL")
   W_RANK=$(severity_rank "$WORKING_LEVEL")

   if [ "$T_RANK" -ge "$W_RANK" ]; then
     FINAL_LEVEL="$TRANSCRIPT_LEVEL"
     FINAL_MSG="$TRANSCRIPT_MSG"
   else
     FINAL_LEVEL="$WORKING_LEVEL"
     FINAL_MSG="$WORKING_MSG"
   fi

   # Exit if both are NONE
   if [ "$FINAL_LEVEL" = "NONE" ]; then
     exit 0
   fi
   ```

2. The comparison selects the higher of the two severity levels. If both are the same, the transcript-based message takes priority (it is generally more accurate).

3. If both levels are `NONE`, the script exits silently with no output.

**Verification:**

- [ ] `severity_rank()` function maps NONE=0, MODERATE=1, HIGH=2, CRITICAL=3
- [ ] Higher severity wins between transcript and WORKING.md checks
- [ ] Equal severity prefers transcript message (more accurate signal)
- [ ] Exit 0 with no output when both signals are NONE
