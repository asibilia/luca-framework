# Phase 127 Plan 02: Sequence Number Race Condition Fix

## Task Objective

Fix the sequence number race condition in `LedgerEntries` table to ensure
atomic, unique sequence number generation under concurrent writes.

## Context

- Issue #43: Sequence number race condition in ledger
- `LedgerEntries` table likely uses non-atomic sequence generation
- Concurrent writes can result in duplicate sequence numbers
- This breaks ledger integrity and audit trail
