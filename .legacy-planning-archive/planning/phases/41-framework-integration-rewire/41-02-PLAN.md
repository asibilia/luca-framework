# Plan 41-02: Integration Tests, Old Test Rewire & Archive src/state-machine/

## Objective

Verify that the rewired framework works end-to-end, update the old `src/state-machine/__tests__/` test files to stop referencing the old bridge path, and archive `src/state-machine/` with a deprecation notice. This plan ensures the rewire from Plan 41-01 is fully validated and the codebase is in a clean state for future development.

This plan completes **PKG-08**: Internal framework updated to consume from `packages/luca-state/` instead of `src/state-machine/`.

## Context

Read these files to understand the current state after Plan 41-01:

- @packages/luca-state/src/bridge.ts -- The canonical bridge implementation. After Plan 41-01, all source files point here.
- @packages/luca-state/src/**tests**/bridge.test.ts -- Package-level bridge tests that already use the correct `packages/luca-state/src/bridge.ts` path.
- @packages/luca-state/src/**tests**/bridge-integration.test.ts -- Package-level integration tests with correct paths.
- @packages/luca-state/src/**tests**/hook-integration.test.ts -- Package-level hook integration tests with correct paths.
- @src/state-machine/**tests**/bridge.test.ts -- OLD test file still referencing `src/state-machine/bridge.ts` as BRIDGE constant. Needs rewire.
- @src/state-machine/**tests**/bridge-integration.test.ts -- OLD integration test still referencing old path. Needs rewire.
- @src/state-machine/**tests**/hook-integration.test.ts -- OLD hook test still referencing old path. Needs rewire.
- @src/state-machine/bridge.ts -- The original bridge file that should be preserved but marked as deprecated.
- @.planning/MEMORY.md -- Long-term memory file where migration decisions should be recorded.

### Key Insight

The `packages/luca-state/src/__tests__/` directory already contains test files with the correct `packages/luca-state/src/bridge.ts` path. The old `src/state-machine/__tests__/` files are essentially duplicates that still reference the old path. The decision is whether to (a) update them to point to the new path, or (b) mark them as deprecated stubs. Option (a) is preferred for continuity until the old directory is fully removed.

## Tasks

**Goal:** Confirm that the extracted `packages/luca-state/` package can be used as a standalone CLI entry point. This is the smoke test that validates Phase 40's extraction was successful and the bridge functions correctly from its new location.

**Implementation:**

Run each core subcommand and verify valid JSON output:


### T2: Rewire old src/state-machine/ test files to delegate to package

**Goal:** Update the 3 test files in `src/state-machine/__tests__/` that still hardcode the old bridge path. These files define a `BRIDGE` constant pointing to `"src/state-machine/bridge.ts"` and some also define a `CLI` constant pointing to `"src/state-machine/cli.ts"`. Update both constants to reference the package paths.

**Files:**

- `src/state-machine/__tests__/bridge.test.ts` -- BRIDGE constant on line 9, CLI constant on line 10
- `src/state-machine/__tests__/bridge-integration.test.ts` -- BRIDGE constant on line 9, CLI constant on line 10
- `src/state-machine/__tests__/hook-integration.test.ts` -- BRIDGE constant on line 9

**Implementation:**

In each file, update the path constants:

```typescript
// Before
const BRIDGE = "src/state-machine/bridge.ts";
const CLI = "src/state-machine/cli.ts";

// After
const BRIDGE = "packages/luca-state/src/bridge.ts";
const CLI = "packages/luca-state/src/cli.ts";
```

Add a comment above each constant noting the migration:

```typescript
// Canonical tests live in packages/luca-state/src/__tests__/
// These tests are kept during transition and point to the package path.
const BRIDGE = "packages/luca-state/src/bridge.ts";
```

- `grep 'src/state-machine/bridge.ts' src/state-machine/__tests__/*.ts` returns zero matches

### T6: Archive src/state-machine/ with deprecation notice

**Goal:** Add clear documentation to `src/state-machine/` indicating it has been superseded by the extracted package. This prevents future contributors from making changes in the wrong location.

**Files:** `src/state-machine/README.md`

**Implementation:**

Create `src/state-machine/README.md`:

```markdown
# DEPRECATED: src/state-machine/

> This directory has been superseded by `packages/luca-state/`.
> All new development should target the package.

## Migration

As of Phase 40-41, the state machine source code has been extracted to a
standalone package at `packages/luca-state/`. The bridge CLI path has changed:

| Before                                      | After                                             |
| ------------------------------------------- | ------------------------------------------------- |
| `bun run src/state-machine/bridge.ts <cmd>` | `bun run packages/luca-state/src/bridge.ts <cmd>` |

## Why files are still here

Files in this directory are preserved during the transition period for backward
compatibility. Source files in `src/hooks/`, `src/skills/`, `src/agents/`, and
`src/rules/` have been updated to reference the new package path.

## Canonical locations

- **Package source:** `packages/luca-state/src/`
- **Package tests:** `packages/luca-state/src/__tests__/`
- **Bridge CLI:** `packages/luca-state/src/bridge.ts`
- **Bin entry:** `packages/luca-state/bin/luca-state.js`

## When to remove this directory

This directory can be fully removed once:

1. All external consumers have been verified to use the package path
2. No CI/CD pipelines reference `src/state-machine/` directly
3. The team confirms no tooling depends on this path
```

**Verification:**

- File contains deprecation notice
- All original source files in `src/state-machine/` are preserved (none deleted)
