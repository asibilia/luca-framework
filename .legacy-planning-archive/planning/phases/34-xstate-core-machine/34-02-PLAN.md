# Plan 34-02: State Persistence and CLI Interface

## Objective

Implement file-based state persistence and a CLI interface for the XState workflow machine created in Plan 34-01. The persistence layer serializes/deserializes machine state to `.planning/state.json` using XState's built-in `getPersistedSnapshot()` and snapshot rehydration. The CLI provides a `bun run src/state-machine/cli.ts <subcommand>` interface for querying state, sending events, initializing sessions, resuming from disk, and resetting -- following the existing `budget.ts` CLI pattern.

This plan covers XSTATE-02 (callable CLI functions for state transitions) and XSTATE-03 (state persistence -- serialize/deserialize machine state to/from disk for session resume).

## Context

@src/state-machine/machine.ts -- The workflow state machine from Plan 34-01. Exports `workflowMachine` and `getAllowedEvents`. This is the machine that gets persisted and rehydrated.

@src/state-machine/types.ts -- Zod schemas for `WorkflowContext`, `WorkflowEvent`, `workflowEventSchema`, `initializeContext`. The CLI validates event payloads with `workflowEventSchema`.

@src/state-machine/index.ts -- Public API surface for the state machine module.

@src/iteration/budget.ts -- Reference implementation for the CLI pattern. Uses `if (import.meta.main)` with `Bun.argv` parsing, `getArg()` helper, and `switch/case` on subcommands. The state machine CLI follows this exact pattern.

@src/iteration/checkpoint.ts -- Existing checkpoint persistence using `Bun.write()` and `Bun.file()`. The persistence layer follows the same Bun file APIs.

@.planning/config.json -- Configuration file loaded during `init` subcommand to populate machine context with gates, workflow config, complexity matrix, and autopilot config.

@src/complexity/defaults.ts -- `DEFAULT_COMPLEXITY_MATRIX` used as fallback when config.json has no complexity section.

### Task 1: Implement the persistence layer

**Goal:** Create `src/state-machine/persistence.ts` with functions to serialize machine state to `.planning/state.json`, load persisted state, and clear persisted state. Uses XState's `getPersistedSnapshot()` for deep serialization including child actors.

**Files:** `src/state-machine/persistence.ts` (create)

**Steps:**

1. Create `src/state-machine/persistence.ts` with imports:

   ```typescript
   import { createActor } from "xstate";
   import type { Actor, AnyActorRef, Snapshot } from "xstate";
   import { workflowMachine } from "./machine";
   import { initializeContext } from "./types";
   import type { Result } from "../shared/types";
   ```

2. Define the state file path constant:

   ```typescript
   /** Path to the persisted state file */
   export const STATE_FILE_PATH = ".planning/state.json";
   ```

3. Implement `persistActor()`:

   ```typescript
   /**
    * Persist the current machine state to disk.
    *
    * Uses XState's `getPersistedSnapshot()` which returns a JSON-serializable
    * representation of the machine state including child actors. The snapshot
    * is written to `.planning/state.json` with pretty-printed JSON for
    * debuggability.
    *
    * @param actor - The running actor to persist
    * @returns Result indicating success or failure with error message
    */
   export async function persistActor(
     actor: AnyActorRef,
   ): Promise<Result<string>> {
     try {
       const snapshot = actor.getPersistedSnapshot();
       const serialized = JSON.stringify(snapshot, null, 2);
       await Bun.write(STATE_FILE_PATH, serialized);
       return { success: true, data: STATE_FILE_PATH };
     } catch (error) {
       return {
         success: false,
         error: `Failed to persist state: ${error instanceof Error ? error.message : String(error)}`,
       };
     }
   }
   ```

4. Implement `loadPersistedActor()`:

   ```typescript
   /**
    * Load a persisted machine state from disk and create a running actor.
    *
    * If `.planning/state.json` exists and contains valid JSON, the actor
    * is created with the persisted snapshot for rehydration. If the file
    * does not exist or is invalid, returns an error result.
    *
    * @returns Result containing the running actor or an error message
    */
   export async function loadPersistedActor(): Promise<
     Result<Actor<typeof workflowMachine>>
   > {
     try {
       const file = Bun.file(STATE_FILE_PATH);
       const exists = await file.exists();

       if (!exists) {
         return {
           success: false,
           error: `No persisted state found at ${STATE_FILE_PATH}. Run 'init' first.`,
         };
       }

       const raw = await file.text();
       if (!raw.trim()) {
         return {
           success: false,
           error: `State file ${STATE_FILE_PATH} is empty. Run 'init' to create a new session.`,
         };
       }

       const snapshot = JSON.parse(raw);
       const actor = createActor(workflowMachine, { snapshot });
       actor.start();
       return { success: true, data: actor };
     } catch (error) {
       return {
         success: false,
         error: `Failed to load persisted state: ${error instanceof Error ? error.message : String(error)}`,
       };
     }
   }
   ```

5. Implement `createFreshActor()`:

   ```typescript
   /**
    * Create a fresh actor with optional config and persist it.
    *
    * Loads `.planning/config.json` if it exists and uses it to populate
    * the machine context (gates, workflow config, complexity matrix, etc.).
    * Falls back to defaults if config.json is not found.
    *
    * @param configPath - Path to config.json (default: ".planning/config.json")
    * @param overrides - Optional context overrides
    * @returns Result containing the running actor or error message
    */
   export async function createFreshActor(
     configPath: string = ".planning/config.json",
     overrides?: Record<string, any>,
   ): Promise<Result<Actor<typeof workflowMachine>>> {
     try {
       const configFile = Bun.file(configPath);
       let config: Record<string, any> = {};

       if (await configFile.exists()) {
         const raw = await configFile.text();
         config = JSON.parse(raw);
       }

       const input = {
         config,
         ...overrides,
       };

       const actor = createActor(workflowMachine, { input });
       actor.start();
       return { success: true, data: actor };
     } catch (error) {
       return {
         success: false,
         error: `Failed to create actor: ${error instanceof Error ? error.message : String(error)}`,
       };
     }
   }
   ```

6. Implement `clearPersistedState()`:

   ```typescript
   /**
    * Remove the persisted state file.
    *
    * Used by the `reset` CLI subcommand to clear state and start fresh.
    *
    * @returns Result indicating success or failure
    */
   export async function clearPersistedState(): Promise<Result<void>> {
     try {
       const file = Bun.file(STATE_FILE_PATH);
       if (await file.exists()) {
         const { unlinkSync } = await import("node:fs");
         unlinkSync(STATE_FILE_PATH);
       }
       return { success: true, data: undefined };
     } catch (error) {
       return {
         success: false,
         error: `Failed to clear state: ${error instanceof Error ? error.message : String(error)}`,
       };
     }
   }
   ```

7. Implement `stateExists()`:

   ```typescript
   /**
    * Check if a persisted state file exists on disk.
    *
    * @returns true if state.json exists and is non-empty
    */
   export async function stateExists(): Promise<boolean> {
     const file = Bun.file(STATE_FILE_PATH);
     if (!(await file.exists())) return false;
     const raw = await file.text();
     return raw.trim().length > 0;
   }
   ```

   ```typescript
   /**
    * Extract a --name=value argument from the CLI args.
    */
   function getArg(
     args: string[],
     name: string,
     defaultValue: string = "",
   ): string {
     const prefix = `--${name}=`;
     const arg = args.find((a) => a.startsWith(prefix));
     return arg ? arg.slice(prefix.length) : defaultValue;
   }

   /**
    * Check if a --flag (boolean) argument is present.
    */
   function hasFlag(args: string[], name: string): boolean {
     return args.includes(`--${name}`);
   ```

4. Implement the `get` subcommand:

   ```typescript
   async function handleGet(args: string[]): Promise<void> {
     const loadResult = await loadPersistedActor();
     if (!loadResult.success) {
       console.error(loadResult.error);
       process.exit(2);
     }

     const actor = loadResult.data;
     const snapshot = actor.getSnapshot();
     const field = getArg(args, "field");

     if (field) {
       const value = get(snapshot.context, field);
       console.log(JSON.stringify(value));
     } else {
       console.log(
         JSON.stringify(
           {
             state: snapshot.value,
             context: snapshot.context,
           },
           null,
           2,
         ),
       );
     }

     actor.stop();
   }
   ```

5. Implement the `send` subcommand:

   ```typescript
   async function handleSend(args: string[]): Promise<void> {
     const eventType = getArg(args, "event");
     if (!eventType) {
       console.error("Missing --event argument. Example: --event=START");
       process.exit(2);
     }

     const dataRaw = getArg(args, "data");
     let eventPayload: Record<string, any> = { type: eventType };

     if (dataRaw) {
       try {
         const parsed = JSON.parse(dataRaw);
         eventPayload = { type: eventType, ...parsed };
       } catch {
         console.error(`Invalid JSON in --data: ${dataRaw}`);
         process.exit(2);
       }
     }

     // Validate event against schema
     const validation = workflowEventSchema.safeParse(eventPayload);
     if (!validation.success) {
       console.error(
         "Invalid event:",
         JSON.stringify(validation.error.issues, null, 2),
       );
       process.exit(2);
     }

     const loadResult = await loadPersistedActor();
     if (!loadResult.success) {
       console.error(loadResult.error);
       process.exit(2);
     }

     const actor = loadResult.data;
     const previousState = actor.getSnapshot().value;

     actor.send(validation.data);

     const snapshot = actor.getSnapshot();
     const persistResult = await persistActor(actor);

     if (!persistResult.success) {
       console.error(persistResult.error);
       actor.stop();
       process.exit(2);
     }

     console.log(
       JSON.stringify(
         {
           previous_state: previousState,
           current_state: snapshot.value,
           event: eventType,
           context: snapshot.context,
         },
         null,
         2,
       ),
     );

     actor.stop();
   }
   ```

   ```typescript
   async function handleStatus(): Promise<void> {

           state: snapshot.value,

           complexity: snapshot.context.complexity,
           oversight: snapshot.context.oversight,
   ```

7. Implement the `init` subcommand:

   ```typescript
   async function handleInit(args: string[]): Promise<void> {
     const exists = await stateExists();
     if (exists && !hasFlag(args, "force")) {
       console.error(
         "Session already exists. Use --force to overwrite, or 'reset' first.",
       );
       process.exit(2);
     }

     const configPath = getArg(args, "config", ".planning/config.json");
     const createResult = await createFreshActor(configPath);

     if (!createResult.success) {
       console.error(createResult.error);
       process.exit(2);
     }

     const actor = createResult.data;
     const persistResult = await persistActor(actor);

     if (!persistResult.success) {
       console.error(persistResult.error);
       actor.stop();
       process.exit(2);
     }

     const snapshot = actor.getSnapshot();
     console.log(
       JSON.stringify(
         {
           initialized: true,
           state: snapshot.value,
           session_id: snapshot.context.session_id,
           config_path: configPath,
         },
         null,
         2,
       ),
     );

     actor.stop();
   }
   ```

    ```typescript
    if (import.meta.main) {
      const subcommand = Bun.argv[2];
    ```
