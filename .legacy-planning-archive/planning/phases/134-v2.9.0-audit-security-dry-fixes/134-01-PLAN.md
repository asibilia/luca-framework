# Plan 134-01: Fix double SQL escaping and DRY improvements in audit-findings.ts

## Objective

Fix a HIGH-severity security concern (H1) where `validateFilterString()` already escapes single quotes via `escapeSqlString()` internally, but callers in `audit-findings.ts` apply a second `.replace(/'/g, "''")` -- turning a correctly-escaped `''` into `''''`. Also address two MEDIUM DRY improvements (M2, M3) in the same file.

## Context

`validateFilterString()` in `sql-sanitize.ts` (line 99) returns `escapeSqlString(value)`, which already performs `.replace(/'/g, "''")`. Every caller in `audit-findings.ts` then redundantly applies the same `.replace(/'/g, "''")` again, double-escaping any legitimate single quotes.

## Tasks

### T3: Extract `createEnumMap()` helper (M3)

**Goal:** DRY the repeated `Object.fromEntries(ARRAY.map((s) => [s, 0]))` pattern used in `createEmptySummary()`.

**Files:** `packages/luca-framework/src/state/__helpers/audit-findings.ts`

**Changes:**

Add a small helper function before `createEmptySummary()`:

```typescript
/**
 * Create a zeroed-out map from a readonly enum array.
 *
 * @param keys - The enum values to use as keys
 * @returns Record mapping each key to 0
 */
function createEnumMap<T extends string>(
  keys: readonly T[],
): Record<T, number> {
  return Object.fromEntries(keys.map((k) => [k, 0])) as Record<T, number>;
}
```

Then refactor `createEmptySummary()`:

```typescript
// BEFORE:
function createEmptySummary(): FindingsSummary {
  return {
    total: 0,
    by_severity: Object.fromEntries(
      FINDING_SEVERITIES.map((s) => [s, 0]),
    ) as FindingsSummary["by_severity"],
    by_category: {},
    by_status: Object.fromEntries(
      FINDING_STATUSES.map((s) => [s, 0]),
    ) as FindingsSummary["by_status"],
  };
}

// AFTER:
function createEmptySummary(): FindingsSummary {
  return {
    total: 0,
    by_severity: createEnumMap(FINDING_SEVERITIES),
    by_category: {},
    by_status: createEnumMap(FINDING_STATUSES),
  };
}
```

Also update `SEVERITY_ORDER` (from T2) to use the helper:

```typescript
const SEVERITY_ORDER: Record<string, number> = Object.fromEntries(
  FINDING_SEVERITIES.map((s, i) => [s, i]),
);
```

Note: `SEVERITY_ORDER` maps to indices (0,1,2...) not zeros, so `createEnumMap` (which maps to 0) is not appropriate for it. Leave `SEVERITY_ORDER` as-is.

**Verification:** `bunx --bun tsc --noEmit` passes. The `createEmptySummary()` function returns identical output.
