# Plan 134-02: Extract shared circuit breaker utility and clean up duplication

## Objective

Extract the duplicated circuit breaker pattern from `observer-emitter.ts` and `spacetimedb-client.ts` into a shared `createCircuitBreaker()` factory function (H2). Then clean up the repeated circuit breaker state update code within `callReducer()` in `observer-emitter.ts` (M1), where `_emitterLastFailureAt = Date.now()` and `_emitterLastFailureAt = 0` are written in 5 separate locations across the initial `.then()`, retry `.then()`, and retry `.catch()` blocks.

## Context

Both files implement the same circuit breaker pattern independently:

**observer-emitter.ts:**

- Module-level `_emitterLastFailureAt` timestamp (line 34)
- `_resetEmitterCircuitBreaker()` export (lines 40-42)
- Open check: `_emitterLastFailureAt > 0 && Date.now() - _emitterLastFailureAt < EMITTER_COOLDOWN_MS` (lines 165-168)
- Trip: `_emitterLastFailureAt = Date.now()` at lines 194, 215, 222
- Reset: `_emitterLastFailureAt = 0` at lines 197, 214
- Cooldown: 30,000ms (line 27)

**spacetimedb-client.ts:**

- Module-level `_lastFailureAt` timestamp (line 30)
- `isCircuitOpen()` function (lines 37-40)
- `_resetCircuitBreaker()` export (lines 46-48)
- Trip: `_lastFailureAt = Date.now()` at lines 134, 140
- Reset: `_lastFailureAt = 0` at line 147
- Cooldown: 30,000ms (line 21)

Both use identical logic: a timestamp that records the last failure, a cooldown window check, and a reset on success.

## Tasks

### T1: Create `createCircuitBreaker()` factory in `circuit-breaker.ts`

**Goal:** Extract the shared circuit breaker pattern into a reusable factory function.

**Files:** Create `packages/luca-framework/src/state/__helpers/circuit-breaker.ts` (new file)

**Changes:**

````typescript
/**
 * Lightweight circuit breaker for fire-and-forget SpacetimeDB connections.
 *
 * Tracks a single failure timestamp and skips operations during a cooldown
 * window after failure. Resets on success. This is intentionally minimal --
 * no open/half-open/closed states, no counters, no events.
 *
 * Used by both observer-emitter.ts (reducer calls) and spacetimedb-client.ts
 * (SQL queries) to avoid hammering an unreachable SpacetimeDB instance.
 *
 * @module luca-state/circuit-breaker
 */

/**
 * Circuit breaker instance returned by createCircuitBreaker().
 */
export interface CircuitBreaker {
  /** Returns true if the circuit is open (should skip operations). */
  isOpen: () => boolean;
  /** Record a failure -- opens the circuit for the cooldown period. */
  trip: () => void;
  /** Record a success -- closes the circuit. */
  reset: () => void;
}

/**
 * Create a lightweight circuit breaker with timestamp-based cooldown.
 *
 * After a failure (trip), subsequent isOpen() calls return true until
 * the cooldown period expires, at which point the next attempt is allowed
 * through (and will either reset or re-trip the breaker).
 *
 * @param cooldownMs - Cooldown period in milliseconds (default: 30000)
 * @returns CircuitBreaker instance with isOpen, trip, and reset methods
 *
 * @example
 * ```typescript
 * const breaker = createCircuitBreaker(30_000);
 *
 * if (breaker.isOpen()) return; // skip during cooldown
 *
 * try {
 *   await doWork();
 *   breaker.reset();
 * } catch {
 *   breaker.trip();
 * }
 * ```
 */
export function createCircuitBreaker(
  cooldownMs: number = 30_000,
): CircuitBreaker {
  let lastFailureAt = 0;

  return {
    isOpen(): boolean {
      if (lastFailureAt === 0) return false;
      return Date.now() - lastFailureAt < cooldownMs;
    },
    trip(): void {
      lastFailureAt = Date.now();
    },
    reset(): void {
      lastFailureAt = 0;
    },
  };
}
````

**Verification:** `bunx --bun tsc --noEmit` passes. File follows kebab-case naming, functional pattern (factory, no class), and JSDoc conventions.

### T2: Refactor `observer-emitter.ts` to use shared circuit breaker (H2 + M1)

**Goal:** Replace the inline circuit breaker state with the shared utility, and clean up the 5 duplicated state update sites in `callReducer()`.

**Files:** `packages/luca-framework/src/state/__helpers/observer-emitter.ts`

**Changes:**

1. **Add import** at top of file:

   ```typescript
   import { createCircuitBreaker } from "./circuit-breaker";
   ```

2. **Replace module-level state** (lines 27-42). Remove:
   - `const EMITTER_COOLDOWN_MS = 30_000;`
   - `let _emitterLastFailureAt = 0;`
   - The `_resetEmitterCircuitBreaker()` function

   Replace with:

   ```typescript
   /** Circuit breaker for reducer calls -- skips attempts during cooldown. */
   const emitterBreaker = createCircuitBreaker(30_000);

   /**
    * Reset the emitter circuit breaker.
    * Exported for testing only.
    */
   export function _resetEmitterCircuitBreaker(): void {
     emitterBreaker.reset();
   }
   ```

3. **Refactor `callReducer()`** to use `emitterBreaker` and eliminate duplicated state updates.

   Replace the circuit breaker check (lines 164-170):

   ```typescript
   // BEFORE:
   if (
     _emitterLastFailureAt > 0 &&
     Date.now() - _emitterLastFailureAt < EMITTER_COOLDOWN_MS
   ) {
     return;
   }

   // AFTER:
   if (emitterBreaker.isOpen()) {
     return;
   }
   ```

   Replace the 5 state update sites in the fetch chain. The current code has:
   - `.then(res => { if (!res.ok) _emitterLastFailureAt = Date.now(); else _emitterLastFailureAt = 0; })`
   - `.catch(async (err) => { ... retry ... .then(res => { if (!res.ok) _emitterLastFailureAt = Date.now(); else _emitterLastFailureAt = 0; }) .catch(retryErr => { _emitterLastFailureAt = Date.now(); ... }) })`

   Refactor to use `emitterBreaker.trip()` and `emitterBreaker.reset()`:

   ```typescript
   fetch(reducerUrl, opts)
     .then((res) => {
       if (!res.ok) {
         emitterBreaker.trip();
       } else {
         emitterBreaker.reset();
       }
     })
     .catch(async (err) => {
       if (process.env.LUCA_DEBUG) {
         console.error(
           `[observer-emitter] Reducer ${reducerName} failed, retrying:`,
           (err as Error).message,
         );
       }
       await new Promise((r) => setTimeout(r, 1000));
       return fetch(reducerUrl, {
         ...opts,
         signal: AbortSignal.timeout(2000),
       })
         .then((res) => {
           if (!res.ok) {
             emitterBreaker.trip();
           } else {
             emitterBreaker.reset();
           }
         })
         .catch((retryErr) => {
           emitterBreaker.trip();
           console.error(
             `[observer-emitter] Reducer ${reducerName} retry failed (data loss):`,
             (retryErr as Error).message,
           );
         });
     });
   ```

   This is a direct substitution (M1 cleanup is achieved by replacing raw assignments with method calls -- the structural duplication of trip/reset in multiple branches is inherent to the retry logic and acceptable).

**Verification:** `bunx --bun tsc --noEmit` passes. `_resetEmitterCircuitBreaker()` still exported with same signature (no breaking change). No direct references to `_emitterLastFailureAt` remain.
