# Plan 04-04: Utility Tests

## Frontmatter
- **ID**: 04-04
- **Title**: Utility Tests (branding, detect, wizard, files, template, manifest)
- **Wave**: 2
- **Depends on**: 04-01

## Objective

Write unit tests for the six utility modules in `packages/luca-framework/src/utils/`. These modules are the workhorses of the CLI -- they handle branding validation, project detection, interactive prompts, file generation, template processing, and manifest management. Tests cover both pure logic (branding, template processing) and I/O operations (filesystem, prompts) with appropriate mocking.

## Context

- `packages/luca-framework/src/utils/branding.ts` -- pure logic: `defaultBranding`, `validateBrandingField()`, `validateBranding()`, `createBrandingContext()`, `mergeBranding()`
- `packages/luca-framework/src/utils/detect.ts` -- I/O: `detectProjectContext()`, pure: `formatStack()`
- `packages/luca-framework/src/utils/wizard.ts` -- I/O: `runWizard()`, pure: `createConfigFromArgs()`, I/O: `loadConfigFromFile()`
- `packages/luca-framework/src/utils/files.ts` -- I/O: `generateFiles()`, `cleanupFiles()`, `setupCleanupHandler()`
- `packages/luca-framework/src/utils/template.ts` -- mixed: `processTemplate()` (pure), `processFilename()` (pure), `copyTemplates()` (I/O), `getTemplatesDir()` (I/O-adjacent)
- `packages/luca-framework/src/utils/manifest.ts` -- mixed: `hashContent()` (pure), `hashFile()` (I/O), `readManifest()`, `writeManifest()`, `createManifest()`, `compareFiles()`
- `packages/luca-framework/src/types.ts` -- type definitions for all config/manifest types
- `__tests__/utils/temp-dir.ts` -- helpers for filesystem tests (from 04-01)
- `__tests__/utils/fixtures.ts` -- shared fixtures (from 04-01)
- `__tests__/utils/mock-clack.ts` -- @clack/prompts mock (from 04-01)

33. **Full override**: `mergeBranding({ frameworkName: 'X', commandPrefix: 'x', ticketPattern: '.*', placeholderTicket: 'X-0' })` -- Assert all fields overridden.

**Test for `defaultBranding` constant:**

### Task 6: Files Utility Tests
**Goal**: Test file generation and cleanup with real temp directories.
**Files**: Create `__tests__/packages/luca-framework/src/utils/files.test.ts`

- Mock `getTemplatesDir()` to point to a temp directory with test templates, OR
- Mock the entire `template` module

Use `mock.module()` to control `getTemplatesDir`, `copyTemplates`, and `@clack/prompts`:

```typescript
import { describe, test, expect, mock, beforeEach, afterEach } from 'bun:test';

import { validLucaConfig } from '../../../../utils/fixtures';
```

**Test cases for `generateFiles()`:**

1. **Creates expected directories**: Mock `copyTemplates` to return `{ copied: [], processed: ['file1.md'] }`. Call `generateFiles({ config: validLucaConfig, cwd: tempDir })`. Verify `.planning/`, `.cursor/luca/`, `.cursor/agents/`, `.cursor/rules/`, `.cursor/skills/` directories created.

2. **Copies base templates**: Verify `copyTemplates` mock was called with sourceDir ending in `'base'`.

3. **Copies stack templates for non-custom stack**: Config with `stack: 'react-ts'`. Verify second `copyTemplates` call includes `'stacks/react-ts'` in sourceDir.

4. **Skips stack templates for custom stack**: Config with `stack: 'custom'`. Verify `copyTemplates` called only for base (no stack call).

5. **Creates manifest on success**: Assert `result.success === true`, `result.manifest` is defined.

6. **Returns error on failure**: Mock `copyTemplates` to throw. Assert `result.success === false`, `result.error` is set.

7. **Cleanup on error**: Mock `copyTemplates` to throw on second call. Verify cleanup was attempted (directories removed).

**Test cases for `setupCleanupHandler()`:**

8. **Does not throw**: Call `setupCleanupHandler()`. Assert no error. (Testing the actual SIGINT behavior is not practical in unit tests.)

**Verification**: `bun test __tests__/packages/luca-framework/src/utils/files.test.ts` -- all tests pass.
