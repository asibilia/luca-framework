# Plan 04-05: Base Class, Compiler, and Shared Utility Tests

## Frontmatter
- **ID**: 04-05
- **Title**: Base Class, Compiler, and Shared Utility Tests
- **Wave**: 3
- **Depends on**: 04-01

## Objective

Write unit tests for the pure logic layer: the three base classes (`BaseAgentImpl`, `BaseSkillImpl`, `BaseRuleImpl`), the three compilers (`BaseCompiler`, `CursorCompiler`, `ClaudeCompiler`), and the shared utilities (`formatFrontmatter`, `escapeMarkdown`, `generateFileName`, validation utils). These modules have zero I/O dependencies and need no mocking -- they are fast, deterministic, and straightforward to test.

## Context

- `src/agents/base/base-agent.ts` -- `BaseAgentImpl` abstract class (constructor validates via Zod, `toCursorFormat()`, `toClaudeFormat()`)
- `src/agents/types/agent.schemas.ts` -- `agentConfigSchema`, `agentFrontmatterSchema`, `agentSectionSchema`
- `src/skills/base/base-skill.ts` -- `BaseSkillImpl` abstract class (identical structure to agents)
- `src/skills/types/skill.schemas.ts` -- `skillConfigSchema`, `skillFrontmatterSchema` (has `disable-model-invocation` optional boolean)
- `src/rules/base/base-rule.ts` -- `BaseRuleImpl` abstract class (different `name` getter: truncated description with dashes)
- `src/rules/types/rule.schemas.ts` -- `ruleConfigSchema`, `ruleFrontmatterSchema` (has `globs` and `alwaysApply` optionals)
- `src/compilers/base.compiler.ts` -- `BaseCompiler` abstract class with `validateFormat()`
- `src/compilers/cursor.compiler.ts` -- `CursorCompiler` extends `BaseCompiler`
- `src/compilers/claude.compiler.ts` -- `ClaudeCompiler` extends `BaseCompiler`
- `src/shared/utils.ts` -- `formatFrontmatter()`, `escapeMarkdown()`, `generateFileName()`
- `src/shared/validation-utils.ts` -- `validateAgentConfig()`, `validateSkillConfig()`, `validateRuleConfig()`, `safeValidateAgentConfig()`, `safeValidateSkillConfig()`, `safeValidateRuleConfig()`
- `src/shared/constants.ts` -- `SUPPORTED_FORMATS`, `FRAMEWORK_NAME`, etc.
- `__tests__/utils/fixtures.ts` -- `validAgentConfig`, `validSkillConfig`, `validRuleConfig`, etc.

## Tasks

### Task 1: Base Agent Tests
**Goal**: Test `BaseAgentImpl` constructor validation, getters, `toCursorFormat()`, and `toClaudeFormat()`.
**Files**: Create `__tests__/src/agents/base/base-agent.test.ts`
**Details**:

Since `BaseAgentImpl` is abstract, create a concrete test subclass:

```typescript
import { describe, test, expect } from 'bun:test';
import { BaseAgentImpl } from '../../../../src/agents/base/base-agent';
import { validAgentConfig, validAgentConfigWithOptionals } from '../../../utils/fixtures';

class TestAgent extends BaseAgentImpl {
  constructor(config: any) {
    super(config);
  }
}
```

**Test cases for constructor:**

1. **Valid config**: `new TestAgent(validAgentConfig)` -- does not throw.
2. **Valid config with optionals**: `new TestAgent(validAgentConfigWithOptionals)` -- does not throw.
3. **Missing frontmatter**: `new TestAgent({ sections: [] })` -- throws ZodError.
4. **Missing frontmatter.name**: `new TestAgent({ frontmatter: { description: 'x' }, sections: [] })` -- throws ZodError.
5. **Missing frontmatter.description**: `new TestAgent({ frontmatter: { name: 'x' }, sections: [] })` -- throws ZodError.
6. **Missing sections**: `new TestAgent({ frontmatter: { name: 'x', description: 'y' } })` -- throws ZodError.
7. **Sections not array**: `new TestAgent({ frontmatter: { name: 'x', description: 'y' }, sections: 'string' })` -- throws ZodError.
8. **Empty sections array**: `new TestAgent({ frontmatter: { name: 'x', description: 'y' }, sections: [] })` -- passes (empty array is valid).

**Test cases for getters:**

9. **config getter**: Assert `agent.config` returns the validated config object.
10. **name getter**: Assert `agent.name === 'Test Agent'`.
11. **description getter**: Assert `agent.description === 'A test agent for unit tests'`.

**Test cases for `toCursorFormat()`:**

12. **Contains frontmatter**: Output starts with `---\n` and contains another `---\n`.
13. **Contains name in frontmatter**: Output contains `name: "Test Agent"`.
14. **Contains sections with XML tags**: Output contains `<instructions>` and `</instructions>` (from section title "Instructions").
15. **Sections sorted by order**: Agent with sections `[{ order: 2, title: 'B', ... }, { order: 1, title: 'A', ... }]`. Assert 'A' appears before 'B' in output.
16. **Section without title**: Agent with `{ title: '', content: 'bare content' }`. Assert content appears without XML tags.

**Test cases for `toClaudeFormat()`:**

17. **Starts with name heading**: Output starts with `# Test Agent`.
18. **Contains description**: Output contains `A test agent for unit tests`.
19. **Contains section headings**: Output contains `## Instructions` and `## Context`.
20. **Sections sorted by order**: Same ordering test as Cursor format.

**Verification**: `bun test __tests__/src/agents/base/base-agent.test.ts` -- all tests pass.

### Task 5: Shared Utils Tests
**Goal**: Test `formatFrontmatter`, `escapeMarkdown`, and `generateFileName`.
**Files**: Create `__tests__/src/shared/utils.test.ts`
**Details**:

```typescript

```

**Note**: The import in `src/shared/utils.ts` references `'../types/agent.types'` which is a broken import path. If this causes an import error at test time, the test file should document this as a known issue. If Bun tolerates the broken import (because the types are unused at runtime), the tests can proceed.

**Test cases for `formatFrontmatter()`:**

1. **String value**: `formatFrontmatter({ name: 'Agent' })`. Assert output contains `name: "Agent"` wrapped in `---`.
2. **Boolean value**: `formatFrontmatter({ active: true })`. Assert contains `active: true`.
3. **Array value**: `formatFrontmatter({ tools: ['a', 'b'] })`. Assert contains `tools:\n  - a\n  - b`.
4. **Nested object**: `formatFrontmatter({ meta: { key: 'val' } })`. Assert contains `meta:\n  key: val`.
5. **Empty object**: `formatFrontmatter({})`. Assert output is `---\n---`.
6. **Mixed types**: `formatFrontmatter({ name: 'X', active: true, tools: ['t1'] })`. Assert all represented.
7. **Starts and ends with `---`**: Assert first line is `---` and last line is `---`.

**Test cases for `escapeMarkdown()`:**

8. **Returns input unchanged (no-op)**: `escapeMarkdown('# Hello **world**')` returns `'# Hello **world**'`.
9. **Empty string**: `escapeMarkdown('')` returns `''`.

**Test cases for `generateFileName()`:**

10. **Simple name**: `generateFileName('agent', 'md')` returns `'agent.md'`.
11. **With dots in name**: `generateFileName('my.agent', 'ts')` returns `'my.agent.ts'`.

**Verification**: `bun test __tests__/src/shared/utils.test.ts` -- all tests pass.
