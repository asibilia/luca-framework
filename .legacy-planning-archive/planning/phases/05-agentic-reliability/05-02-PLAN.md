# Phase 5 Plan 02: Enhance Tribunal Consensus Model

## Objective

Extend the existing majority-vote tribunal consensus with support for unanimous, expert-weighted, and threshold-based consensus modes (#55).

## Context

`src/shared/__helpers/tribunal-consensus.ts` implements `resolveMajorityVote()` for exactly 3 perspectives. Current behavior: count votes, find majority (2+), tiebreak on highest confidence, record dissenter.

Missing per #55:

- Unanimous mode (all must agree)
- Expert-weighted mode (some agents' votes count double)
- Configurable `requiredAgreement` threshold (e.g., 0.67)
- `fallbackResolver` for no-consensus cases

## Wave 1: Consensus Schema & Implementation

### Task 1.1: Create consensus config schema

**File:** `packages/luca-framework/src/shared/__schemas/consensus.schemas.ts`

Create Zod schemas:

- `ConsensusMode`: `"majority" | "unanimous" | "expert_weighted"`
- `ConsensusConfigSchema`: `mode` (default "majority"), `required_agreement` (0-1, default 0.67), `expert_agents` (string[], default []), `expert_weight` (number, default 2), `fallback_category` (string, optional)
- `ConsensusResultSchema`: extends existing `MajorityVoteResult` pattern with `mode_used`, `agreement_ratio`, `fallback_applied`

**Verification:** `bunx --bun tsc --noEmit` passes.

### Task 1.2: Implement resolveConsensus function

**File:** `packages/luca-framework/src/shared/__helpers/tribunal-consensus.ts`

Add `resolveConsensus()` alongside existing `resolveMajorityVote()` (keep backward compatible):

- **majority mode**: Delegates to existing `resolveMajorityVote()`
- **unanimous mode**: All perspectives must agree; if not, returns `fallback_category` or highest-confidence perspective
- **expert_weighted mode**: Expert agents' votes counted N times (per `expert_weight`); then majority resolution on weighted votes

Return `ConsensusResult` with `agreement_ratio` = (agreeing votes / total votes).

**Verification:** `bunx --bun tsc --noEmit` passes. Existing `resolveMajorityVote()` unchanged.

### Task 1.3: Export from shared barrel

**File:** `packages/luca-framework/src/shared/index.ts`

Add re-exports for the new consensus schemas and `resolveConsensus`.

**Verification:** `bunx --bun tsc --noEmit` passes. Barrel contains only re-exports.
