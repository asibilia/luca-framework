# Phase 4 Plan 04: Accessibility Pass on Observer Dashboard

## Objective

Improve keyboard navigation, screen reader support, and ARIA compliance across the observer dashboard. Focus on collapsible sections (missing `aria-expanded`), interactive buttons (missing `focus:ring-2`), icon-only/color-only elements (missing `aria-label`), and keyboard operability of toggle controls.

## Context

@packages/luca-observer/components/memory/memory-entries.tsx
@packages/luca-observer/components/memory/working-sections.tsx
@packages/luca-observer/components/decisions/decision-timeline.tsx
@packages/luca-observer/components/shared/json-viewer.tsx

@packages/luca-observer/app/page.tsx
@packages/luca-observer/components/tribunal/disagreements-panel.tsx

## Current State Assessment

**Already accessible (good patterns to maintain):**

- `header.tsx`: Sidebar toggle has `aria-label="Toggle sidebar"`, `aria-expanded={isOpen}`, `focus:ring-2 focus:ring-accent focus:ring-offset-2`. Theme toggle has `aria-label`, `aria-pressed`, `title`. Connection dot has `aria-hidden="true"`.
- `sidebar.tsx`: Navigation has `role="navigation"`, `aria-label="Main navigation"`. Links have `focus:ring-2 focus:ring-accent focus:ring-offset-2`. Skip-to-nav button has `aria-label`.
- `status-indicator.tsx`: Container has `role="status"`, `aria-label`. Color dots have `aria-hidden="true"`.
- `loading-skeleton.tsx`: Has `role="status"`, `aria-busy={true}`, `aria-label="Loading"`.
- `notes/page.tsx`: Form buttons already have `focus:ring-2 focus:ring-accent focus:ring-offset-2`.

**Missing accessibility attributes:**

1. **memory-entries.tsx CategorySection button (line 137-139)**: Missing `aria-expanded`, `focus:ring-2`, `focus:outline-none`
2. **working-sections.tsx SectionPanel button (line 114-116)**: Missing `aria-expanded`, `focus:ring-2`, `focus:outline-none`
3. **decision-timeline.tsx toggle button (line 69-70)**: Missing `aria-expanded`, `focus:ring-2`, `focus:outline-none`
4. **json-viewer.tsx expand/collapse button (line 28-29)**: Missing `aria-expanded`, `focus:ring-2`, `focus:outline-none`
5. **notes/page.tsx "Consumed" toggle button (line 169-172)**: Missing `aria-expanded`
6. **page-error.tsx "Try Again" button (line 53-56)**: Missing `focus:ring-2`, `focus:outline-none`
7. **page-error.tsx "Go Home" link (line 57-61)**: Missing `focus:ring-2`, `focus:outline-none`
8. **dashboard page.tsx connection status dot (line 32-33)**: Color-only indicator missing `aria-label` or `aria-hidden`
9. **disagreements-panel.tsx color-coded numbers**: Color-only values missing accessible text alternatives
