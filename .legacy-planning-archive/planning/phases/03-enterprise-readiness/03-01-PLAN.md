         * Lists failed checks with messages
         * Shows auto-fix suggestions when fixCommand exists
         * Returns exit code 0 if all pass, 1 if any fail
       - Export executeDoctor function

    Follow patterns from existing CLI commands (init.ts, update.ts). Use functional style, no classes. Single object argument with destructuring.
