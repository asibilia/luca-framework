# Plan 130-02: Cognitive profiles, meta-cognition, and interop scanner

## Objective

Implement portable cognitive profiles (#14), reflective meta-cognition (#15), and cross-agent interop scanner (#16).

## Tasks

### Task 1: Portable cognitive profiles (#14)

- Read `src/memory/__helpers/brain-parser.ts` and `brain-serializer.ts` for BRAIN.md handling
- Create `src/memory/__helpers/cognitive-profile.ts` with:
  - `exportCognitiveProfile(projectDir: string): CognitiveProfile` — exports project's BRAIN.md + MEMORY.md patterns into a portable profile
  - `importCognitiveProfile(profile: CognitiveProfile, targetDir: string): ImportResult` — imports a profile into a new project, merging with existing memory
  - `CognitiveProfileSchema` — Zod schema for profile format (project identity, patterns, preferences, conventions)
- Export from `src/memory/index.ts`
- Add tests

### Task 2: Reflective meta-cognition (#15)

- Create `src/memory/__helpers/meta-cognition.ts` with:
  - `assessPlanQuality(plan: PlanContent, context: ProjectContext): QualityAssessment` — evaluates plan against past execution outcomes
  - `generateReflection(executionSummary: string, outcome: string): Reflection` — produces a structured reflection on what worked/didn't
  - `ReflectionSchema` and `QualityAssessmentSchema`
- Export from `src/memory/index.ts`
- Add tests

### Task 3: Cross-agent interop scanner (#16)

- Read `src/agents/__schemas/agent.schemas.ts` for agent definition structure
- Create `src/agents/__helpers/interop-scanner.ts` with:
  - `scanAgentInterop(agents: AgentDefinition[]): InteropReport` — analyzes agents for compatibility issues (overlapping roles, missing handoff protocols, conflicting context requirements)
  - `InteropReportSchema` — findings, recommendations, compatibility matrix
- Export from `src/agents/index.ts`
- Add tests

## Verification Criteria

- [ ] Cognitive profile export/import works
- [ ] Meta-cognition reflection and quality assessment functions exist
- [ ] Interop scanner analyzes agent compatibility
- [ ] `bunx --bun tsc --noEmit` passes
