# Plan 130-03: Semantic memory and selective skill scaffolding

## Objective

Implement semantic memory embeddings with vector recall (#18) and selective skill scaffolding (#23).

## Tasks

### Task 1: Semantic memory embeddings with vector recall (#18)

- Create `src/memory/__helpers/semantic-search.ts` with:
  - `computeEmbedding(text: string): number[]` — computes a simple TF-IDF or character n-gram embedding (no external API dependency)
  - `cosineSimilarity(a: number[], b: number[]): number` — cosine similarity between vectors
  - `semanticRecall(query: string, memories: MemoryEntry[]): RankedMemory[]` — ranks memories by semantic similarity to query
  - `SemanticIndexSchema` — schema for the in-memory index
- This should be a lightweight local implementation (no OpenAI/external API calls)
- Use character n-grams or simple token overlap for embedding
- Export from `src/memory/index.ts`
- Add tests

### Task 2: Selective skill scaffolding (#23)

- Read `src/skills/__schemas/skill.schemas.ts` for skill definition structure
- Read `src/skills/index.ts` for skill registry
- Create `src/skills/__helpers/scaffolding.ts` with:
  - `classifySkill(skill: SkillDefinition): 'core' | 'extended'` — classifies skills as core (always available) or extended (loaded on demand)
  - `scaffoldSkillSet(profile: 'minimal' | 'standard' | 'full'): SkillDefinition[]` — returns the appropriate skill subset for the profile
  - `SkillScaffoldingConfigSchema` — config for which skills are core vs extended
- Core skills: git-commit, phase-execute, phase-plan, progress, lu
- Extended skills: everything else
- Export from `src/skills/index.ts`
- Add tests

## Verification Criteria

- [ ] Semantic search computes similarity without external APIs
- [ ] Skill scaffolding classifies and filters skills by profile
