## Objective
Add error handling to build scripts so they produce actionable error messages instead of raw stack traces, add comprehensive documentation headers explaining usage and prerequisites, and modernize the CJS `require.main === module` pattern to the Bun-native `import.meta.main`. After this plan, build scripts are documented, resilient, and follow project conventions.

## Tasks

### Task 1: Add error handling wrapper to `build-all.ts`
**Goal**: Wrap the entire build-all script in a try/catch so import failures and systemic errors produce actionable messages instead of raw stack traces.
**Findings**: DX-028 (HIGH), DX-025 (MEDIUM — documentation headers added as part of this task)
**File:** `scripts/build-all.ts`
**Changes:**
1. Wrap the entire script body (from line 19 onward — after imports) in an async main function with try/catch.
2. On error, print a user-friendly message with recovery guidance.
3. Exit with code 1 on failure.

**Approach:** Move all the execution logic (lines 19-161) into an async `main()` function wrapped in try/catch, then call it.

**Before (structure):**
```typescript
#!/usr/bin/env node
/**
 * Build script for generating both Cursor and Claude-compatible files
 */
import { ... } from '...';
// ... all logic at top level
const cursorCompiler = new CursorCompiler();
// ... rest of script
```

**After (structure):**
```typescript
#!/usr/bin/env node
/**
 * Build script for generating both Cursor and Claude-compatible files.
 *
 * Compiles TypeScript agent, skill, and rule definitions into both
 * Cursor (.mdc) and Claude (.md) formats.
 *
 * Usage:
 *   bun run build:all
 *   bun run scripts/build-all.ts
 *
 * Prerequisites:
 *   - TypeScript source files must be valid (agents, skills, rules, compilers)
 *   - Run from the repository root directory
 *
 * Output:
 *   - .cursor/agents/*.md     — Cursor agent definitions
 *   - .cursor/skills/*/SKILL.md — Cursor skill definitions
 *   - .cursor/rules/*.mdc     — Cursor rule definitions
 *   - .claude/agents/*.md     — Claude agent definitions
 *   - .claude/skills/*/SKILL.md — Claude skill definitions
 *   - .claude/rules/*.md      — Claude rule definitions
 */
import { ... } from '...';

async function main() {
  // ... all existing logic moved here
}

main().catch((error) => {
  console.error('\n✗ Build failed!\n');
  console.error(`Error: ${error instanceof Error ? error.message : String(error)}`);
  console.error('\nTroubleshooting:');
  console.error('  1. Ensure you are running from the repository root');
  console.error('  2. Check that all TypeScript source files compile: bun run tsc --noEmit');
  console.error('  3. Verify agent/skill/rule class exports are correct');
  if (error instanceof Error && error.stack) {
    console.error('\nStack trace:');
    console.error(error.stack);
  }
  process.exit(1);
});
```

**Verification:**
- `bun run build:all` succeeds when source files are valid
- When an import is broken, the script shows an actionable error instead of a raw stack trace
- Exit code is 1 on failure, 0 on success
- `bun test` passes

### Task 4: Replace CJS `require.main === module` with `import.meta.main` in generate scripts

**Changes (each file):**

**Before:**
```typescript

```

**After:**

### Task 5: Convert build scripts from `node:fs` to Bun APIs (DX-026 LOW)
**Goal**: Replace `fs.writeFileSync`, `fs.existsSync`, and `fs.mkdirSync` with Bun-native APIs per project conventions in CLAUDE.md.
**Findings**: DX-026 (LOW) — bundled with build script improvements
**Files:** `scripts/build-all.ts`, `scripts/build-claude.ts`, `scripts/build-cursor.ts`
**Changes:**
1. Remove `import fs from 'fs'` from all three files.
2. Replace `fs.existsSync(dir)` with `await Bun.file(dir).exists()` — note: for directories, use `import { existsSync } from 'fs'` since `Bun.file()` is for files. Alternatively, use `mkdir` with `{ recursive: true }` which is idempotent and does not need an existence check.
3. Replace `fs.mkdirSync(dir, { recursive: true })` with `await mkdir(dir, { recursive: true })` from `fs/promises` (since the script is now async via the `main()` wrapper).
4. Replace `fs.writeFileSync(path, content)` with `await Bun.write(path, content)`.

**Pattern replacement summary:**
```
fs.existsSync(dir) + fs.mkdirSync(dir, { recursive: true })
  → await mkdir(dir, { recursive: true })    // idempotent, no check needed

fs.writeFileSync(path, content)
  → await Bun.write(path, content)
```

Add to imports:
```typescript
import { mkdir } from 'fs/promises';
```

Remove:
```typescript
import fs from 'fs';
```

**Verification:**
- No `import fs from 'fs'` in any build script
- All build scripts use `Bun.write()` for file output
- `bun run build:all` produces identical output files
- `bun test` passes
