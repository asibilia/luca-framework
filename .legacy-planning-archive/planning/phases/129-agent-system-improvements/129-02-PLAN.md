# Plan 129-02: Stall detection, health checks, and verification loop limits

## Tasks

### Task 1: Add agent health check system (#52)

- Create `src/agents/__helpers/health-check.ts`
- Implement a lightweight health check function that verifies:

  - Required template references resolve

- Export `checkAgentHealth(agentName: string): HealthCheckResult`

### Task 2: Add stall detection and retry limits to verification loop (#53)

- Read `src/iteration/__helpers/convergence.ts` or similar for existing convergence detection

- Add explicit stall detection: if the same errors appear 3+ consecutive iterations with no code changes, flag as stalled
- Add a `maxRetries` field to iteration config with a default of 3
- Ensure the stall detection integrates with the existing convergence assessment
