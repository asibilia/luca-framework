## Key Accomplishments

1. **XState state machine extensions** — Added appetite enum, token budget fields, cooldown state, and 4 new guards (shouldCheckAppetite, shouldRunPremortem, shouldRunProcessData, shouldStartCooldown) with full bridge CLI exposure
2. **Appetite declaration system** — Fixed vs variable scope with Small/Medium/Large/XL levels, token budgets (30k-200k), wave-boundary budget guard with graceful handoff, planner awareness
3. **Pre-mortem agent (lu-premortem)** — Domain-specific failure scenario generation with DEEP_ANALYSIS routing preset, Tier 1 (advisory) and Tier 2 (formal PREMORTEM.md) risk briefs, developer approval checkpoint
4. **Process data agent (lu-process-data)** — 5 per-phase metrics (appetite accuracy, rework ratio, signal rate, lead time, change failure rate) + 4 aggregate running averages, wired into phase-execute with gate control
5. **Outcome tracking** — /outcome skill for contextual goal achievement recording, lu-cognition outcome_check step for automatic nudges, MuninnDB-backed persistence
6. **Self-tuning governance** — Graduation criteria for auto-skipping pre-mortem (signal rate < 10% over 20 samples) and retrospective questions (response rate < 30% over 10 samples), process retrospective dashboard at milestone boundaries, divergent mode advisory after 8+ consecutive milestones
