### Integration Gap Details

**HIGH — Drift gate bypasses oversight-gate.ts evaluator**
The drift response block in lu.skill.ts uses a raw string comparison against an undefined `OVERSIGHT_LEVEL` variable instead of calling `evaluateOversightGate("drift_detected", ...)`. The 8×4 oversight gate matrix and profile-aware rules (budget→auto_apply, quality→pause) are never invoked for drift decisions.

**MEDIUM — Budget matrix CLI never invoked by orchestrator**
`budget-matrix.ts` exports `resolveBudgetMatrix()` and has a working CLI entry point, but lu.skill.ts only documents the multiplier application as pseudocode comments. HARNESS_FIX_ITERATIONS, VERIFY_FIX_ITERATIONS, and MAX_IMPL_ITERATIONS are never initialized from the 5×5×3 budget matrix.

## Cross-Phase Patterns

The root cause of most DRY findings is the **package boundary** between `src/` and `packages/luca-framework/src/`. Because the state machine package cannot import from `src/complexity/`, shared primitives (complexity levels, token profiles, model tiers, CLI utils) are copied with "self-contained copy" comments.

**Highest-priority remediation:** Export `COMPLEXITY_LEVELS`, `TOKEN_PROFILES`, and `MODEL_TIER_TO_MODEL` from the luca-framework package index. This single action eliminates DRY-001, DRY-002, DRY-006, and reduces DRY-007/DRY-008.
