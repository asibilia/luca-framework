## Goal

Address all remaining tech debt from the v1.3.2 audit. Deprecate redundant build scripts, decompose monolithic functions, migrate remaining tests to Bun APIs, and enforce no-classes rule in registries.

## Key Accomplishments

1. **Build scripts consolidated**: Deprecated `build-claude.ts` and `build-cursor.ts` (~400 lines removed), moved `generateClaudeHooksConfig` from `scripts/` to `src/hooks/` to fix boundary violation.
2. **Pipeline decomposed**: Split 212-line `generateAllOutputs()` monolith into focused sub-functions. Registered all Luca-specific entities (LuExecutorAgent, LuPlannerAgent, etc.) in main registries — eliminated special-casing.
3. **Registries refactored to factories**: All registries now store `() => Entity` factory functions instead of `new Class()` constructors, enforcing the no-classes rule. Category staleness test added to prevent silent category drift.
4. **Drift tests DRY'd up**: Extracted `detectDrift()`, `detectOrphanFiles()`, `detectOrphanDirs()` helpers — reduced `check-drift.test.ts` by 90 lines. Removed stale `LUCA_SPECIFIC_*` exclusion sets.
5. **Plugin spec tests migrated to async Bun APIs**: All 3 plugin spec test files (`plugin-spec-structure.test.ts`, `plugin-spec-hooks-format.test.ts`, `plugin-spec-e2e.test.ts`) converted from sync `node:fs` to async `Bun.file()` and shared test helpers.
6. **Shared test entities extracted**: `TestAgent`/`TestSkill`/`TestRule` consolidated from duplicated compiler test fixtures into shared module. Stale error messages referencing deleted classes updated.
